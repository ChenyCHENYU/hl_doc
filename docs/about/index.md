## 站点边界

- 不收录挂机脚本、辅助工具、私服内容（仅在[资源库](/resources/)编目登记）
- 游戏实体图片存 OSS 图床（内容 hash 命名），不引用官方站热链
- 欢迎玩家投稿：[幻灵英雄墙](/heroes/) 入驻、攻略勘误与资料补充
