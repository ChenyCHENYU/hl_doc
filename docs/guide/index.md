## 宠物综述

> 以下内容整理自游戏内帮助 help06.htm，文字尽量保留原意。

在幻灵世界里，自始自终陪伴你的就是宠物。它具有和人类类似的基本属性，而且也有思想和感情，
它们需要你的尽心呵护，进而会忠心耿耿，帮你打败野外潜伏的怪物。

- **宠物状态**：显示宠物属性面板，可更换出征宠物或查看宠物属性
- **宠物摆摊 / 管理摆摊**：让宠物替你摆摊售卖
- **宠物吆喝口号**：把广告宣传口号写在宠物身上吸引买家
- **宠物逛街**：带出征宠物出来逛街，PK 大赛时配合障眼法可迷惑对手
- **宠物展示**：向其他玩家展示宠物级别、名字与三围（与逛街互斥）
- **宠物留言**：设置宠物格言，其他玩家右键宠物即可查看

其余专题将按分类逐步录入，原文档均已在本地归档，不做外部热链。
