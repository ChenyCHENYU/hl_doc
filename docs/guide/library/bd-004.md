# 极速练宠法

<TopicHeader cat="玩家文库 · 宠物练级" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

练宠有一段时间了，说些经验让大家分享

一、人物属性

```
练宠的人属性点要分配好，所以人的装备也很重要，特别是练0幻的宠物，想要练宠快，人就得有攻，一般来说人的攻有2400防有3700敏有2000就能很好的进行练宠了，一般我练宠时是人宠齐升级的，就是人1级宠也1级就开始练，当然这样练需要有装备辅助，我练宠时换的装备如下：加攻2400的剑，加防2700的衣服，加敏1000的鞋，盘龙桎，加防227的右佩，人边升级边调整属性点，可以练宠练人二不误。
```

二、关注宠物的三围

要熟知宠物的分布及相应地区怪物的三围，随着宠物级数提高敏和防到一定的时候就换地方。

另外要注意宠物的相克，一般打相克的怪物，宠物的防只需与怪物的攻相等即可。

三、宠物煅造

为了能打更高级的怪物就需要改变宠物的三围，这样就需要煅造宠物了。

**相关资料**：http://bbs.tx51.com/viewthread.php?tid=16085

四、宠物装备

有好的宠物装备能让你练宠的速度加快很多，店里有卖的装备我不多说了，现大家看一看比较少见的装备吧。另宠物进化前建议带个防敏各加120的御[天宝](/pets/28)环，在山城有售的。

装备的取得方法如下

**梦之链**：中秋的任务取得，现已绝版，但还有些玩家手上有出售。

**极品宠装**：是自己煅造出来的，具体方法见：http://bbs.tx51.com/viewthread.php?tid=71668

**疾风之环等**：是在兄弟天关拿的，详见http://bbs.tx51.com/viewthread.php?tid=67324

五、吃九转丹

九转是吃后人宠都升**20级**的药，吃一个宠物的成长也加**0.00**5左右，虽比较贵。但仍建议练宠的朋友酌情使用，因宠物练到**1000级**后练到1200成长大概只加**0.05**，而且每升一级所花时间较长，所以**1000级**后使用九转丹也是值得的。

六、幻灵的速度

现在的幻灵版本很多，而最快的方法我介绍一下，先说明一下，我家里有三台电脑，公司有一台，分别装有WIN98和WIN2K，所以运行的速度，我想有一定的发言权。

经实践得出的结论如下的配合是最快的：

**幻灵的版本**：2208

**操作系统**：WIN98

具体方法：

1. 把附件中的HL_Client.exe和Version.dat二个文件覆盖你幻灵安装目录中相应的这二个文件（注意你的幻灵一定要是2208）
2. 先开三个push窗口（附件中有一个叫按点加速的压缩文件，内有PUSHX,PUSHXX.PUSHXXX三个文件分别打开。
3. 打开变速齿轮开到256速进入幻灵
4. 进入后看到记录点的NCP不停的点头后把变速齿轮关掉，不要关那三个PUSH（这个PUSH作用就等于加速网页但效果比加速网页好。
5. 开机器人（附件内已有相应版本的机器人）去试试吧，战斗速度绝对的快，我也是因这样才把我的W2K单系统改为W2K&WIN98双系统的。
6. 幻灵**2.5**的加速方法用0距离及无动作补丁，操作系统用w2k,若使用win98请使用加速网页

『系统&杀毒工具、加速、免动作、0距离补丁总汇』：http://bbs.tx51.com/viewthread.php?tid=90512

1. 若出现无法打开附件的话，请把文件的后缀名改为*.rar，这样就能用winrar把开附件了。或按shift+右键选择打开方式，然后选择用winrar打开。

七、请把以上的方法合理混用，掌握一个平衡点，极速打造自己极品宠吧
