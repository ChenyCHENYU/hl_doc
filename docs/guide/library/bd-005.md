# 盘龙尊锻造宠物装备的数据

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

盘龙尊锻造宠物装备的数据(**300级** +230防、10敏)

**声明**：制作思路和数据由 云淡风也轻 提供给我，我本人验证并整理了一下

\->因论坛升级导致图片丢失，由本人最后进行编辑－－柳之剑

**1**：制作材料

盘龙尊

水城买到最便宜草鞋×1

水城买到最便宜头饰×1

极限头饰（血佩）×4

极限身饰（内带）×3

极限鞋子若干

**2**：制作步骤

①盘龙尊6点，水城最便宜鞋子3点

此步锻造降其敏捷为0

②盘龙尊6点，水城最便宜头饰5点

此步锻造降其生命为0

③给盘龙尊加内至3339左右、加第1个极限头饰，得到-333血 +3339内

**位置**：盘龙尊7点、极限头饰5点

④使用第1个极限身饰给盘龙尊加内，得到-333血 +5268内

**位置**：盘龙尊7点、极限身饰1点

⑤使用第2个极限头饰给盘龙尊减血，得到-501血 +5268内

**位置**：盘龙尊7点、极限头饰5点

⑥使用第2个极限身饰给盘龙尊加内，得到-501血 +5811内

**位置**：盘龙尊7点、极限身饰1点

⑦使用第3个极限头饰给盘龙尊减血，得到-579血 +5811内 <此步可不用极限头饰>

**位置**：盘龙尊7点、极限头饰5点

⑧使用第3个极限身饰给盘龙尊加内，得到-579血 +5889内

**位置**：盘龙尊7点、极限身饰1点

⑨使用第4个极限头饰给盘龙尊减血，得到-588血 +5889内 <此步可不用极限头饰>

**位置**：盘龙尊7点、极限头饰5点

**3**：用极限鞋子给盘龙尊加敏捷

**300级**是+10敏

**500级**是+40敏

**600级**是+55敏

用草药降到你的级别就ok了
