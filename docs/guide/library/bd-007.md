**第二次**：后悔可惜的一次

实验对象：[小霸王](/pets/318)

46。9000→手动多练**39级**到**50级**3围成长：46。4082→吃60个9转后**1250级**成长46。8847，太后悔了，为什么要多练那**39级**呢？要是和南宫猪一样吃62个到**1250级**会不会也加**1.15**到48。05呢？！

尽管有点不太可能，但是谁也说不准，呵呵，自我安慰！这60个9转失去了参考价值，而且和正常满血练出来成长所加点数基本一样，故个人认为没必要挂帖！

最后，发表一些我的个人观点，仅供参考

1. 0幻宠以及1幻宠和2幻宠没必要吃9转，我吃过很多次，和正常练出来的一样都是加0。55左右。
2. 3幻宠波动幅度有些特别大，建议和我第一次的吃法一样，一般都是**11级**是吃9转的最佳时机，如果能做到人宠吃9转同步升级，估计效果要好。
3. 幻化用只加内力的腰带会有减血的效果，没必要非要做减血的宠装，宠没内力可言，然而加内力减血，所以血会转移到3围上一部分，这个也许是我的“猪王”贫血成长超正常的片面原因吧，建议进化也带内力腰带，普遍认为对3围没影响，但是，为了多赚点3围成长，最好还是宁可信其有不可信其无，反正我是带了，而且还带的加敏捷的内力腰带，这个猪敏捷比例也超了4%多，高兴，我养猪的目的就是高敏，对付小黑，呵呵！
4. 地点要选择无属性区吃9转，比如你家里或者帮派总坛等，我就遇到一个很邪的问题，在第2次吃60个9转的时候，由于是星光送的货，我直接在总坛外面吃了15个，发现3围还是46。40，急忙改变策略，带星光到我总坛给我吃，成长利马反弹上来了，是不是很邪啊~
