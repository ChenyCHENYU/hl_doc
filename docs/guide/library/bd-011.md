# 三级房屋宠物医生攻略

<TopicHeader cat="玩家文库 · 宠物养成" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到皇城的太和殿里跟陈大人(32,20)对话,选择去家庭物品店,在物品店(59,53)的地方有个宠物医生,带30万，跟她说话,就可以得到"医生邀请函"了,回到家里(必须三级房屋才可以),使用邀请函,家里就出现了一个宠物医生...

设置好医生的第二天开始,每天可以在医生那里拿三颗丹药治疗宠物的受伤度一颗天灵丹可以减少宠物受伤度30,两颗地灵丹,分别减少宠物受伤度10....
