# 云锦天衣任务攻略

<TopicHeader cat="玩家文库 · 锻造-防具" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

梅花钩`子母环`龙纹扇`青玉腿甲、云锦天衣任务攻略

此任务是永久的，对于钩男、拿环女、公主、书生来说极品装备等着你拿

得到赤刃后，到守望林场来 樵夫乌苏 ，得到紫竹蓑衣

去西码头找猎人李进（PS：身上带着紫竹蓑衣和升级药），可换得子母环、梅花钩、龙纹扇、青玉腿甲 任一件武器

**在晚上的18**：00――22：00，到单人天关第77关找侍女小霞，用子母环、梅花钩、龙纹扇、青玉腿甲中的任意一件和她交换，就会获得当年由织女亲手编织的云锦天衣

子母环、梅花钩等物品属性：+100攻 +50防 -140敏（极品煅造材料）

**云锦天衣属性**：+100生命 +150防 -70攻 -80敏 **300级**使用

（先练个将近1000血的血饰，把云锦的血加到300以上；这时把衣服降修，防能到0，然后水纹坠5点，衣服12点主练血就没了/只有这个方法才可以清掉+100血）
