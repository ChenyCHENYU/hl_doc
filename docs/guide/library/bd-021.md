# 二转飞升全攻略

<TopicHeader cat="玩家文库 · 任务与飞升" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

二转之转地仙

条件满足散仙**800级**以上, 到武当山(95,57)找张三丰对话后进入战斗(3只**1000级**的[刚雷狒](/pets/74)), 打赢后得到“仙道飞升药”, 吃了就飞升为地仙

飞升后得到一只1级[蛋蛋鱼](/pets/141)

二转之转夜叉

条件满足散仙**800级**以上, 到盘龙洞窟2 (43,59)找地狱守护魔女对话后进入战斗(3只**1000级**的[堕落天狼](/pets/203)), 打赢后得到“魔道飞升药”, 吃了飞升为夜叉

飞升后得到一只1级[伏地龙](/pets/271)
