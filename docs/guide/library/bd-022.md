# 三转仙魔飞升任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

三转仙魔飞升任务(天仙及阿修罗的飞升)

三转之转天仙

在沙洞4层－古铜洞窟2打出玉露丹，然后到天堂－仙客厅找到青云仙子（16，27），会得到一颗天仙飞升药。

地仙**1000级**以上，内和血全满，出征宠物是一只800－**1250级**、**忠诚100**的[绿衣仙子](/pets/139)，吃下天仙飞升药后，绿衣仙子将进化为[地藏兽](/pets/153)。

提供几个打玉露丹的坐标（24，24）

三转之转阿修罗

在华山顶打到天魔散，然后到地狱16层－天灯地狱找地狱飞龙（49，37），得到一颗阿修罗飞升药。

夜叉**1000级**以上，内和血全满，出征宠物是一只**800级**－**1250级**、**忠诚100**的[黄龙使](/pets/280)。吃下阿修罗飞升药，黄龙使将进化为白发蛇姬。
