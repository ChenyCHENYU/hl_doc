# 仙魔互转

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

仙魔互转(限制**800级**以上)

“由道入魔”任务攻略

到 华山腰道 (68,19)找 采药人朱启照 拿到两颗无极草,再到武当炼丹房找元元真人,进入战斗(5只**800级**的[刚雷狒](/pets/74)),打赢后得到无极天魔丹(循环2次、打两颗)

再到 逆之往事 找到魏无崖(64,38),对话后得到魏无崖的信,前往吓死人洞窟2找到天机真人(38,64),可以获得兵解所需要的凝神丹(只换1颗)

带着1颗无极天魔丹和1颗凝神丹到地焰洞找地狱守护MM对话,得到神魔丹

打入地狱, 在钉床地狱找到噬魔女(14,30), 对话后就由道入魔了

1 天仙入魔后变为夜叉、阿修罗入道后变为地仙、大罗金仙入魔后变为阿修罗、魔神入道后变为天仙(五转不能仙魔互转)

2 仙魔互转需要300W银两

3 由道入魔如同飞升一样,身上除任务物品外其他物品都会丢失

“由魔入道”任务攻略

到 华山腰道 (68,19)找 采药人朱启照 拿到两颗无极草,再到武当炼丹房找元元真人,进入战斗(5只**800级**的刚雷狒),打赢后得到无极天魔丹(循环2次、打两颗)

再到 逆之往事 找到魏无崖(64,38),对话后得到魏无崖的信,前往吓死人洞窟2找到天机真人(38,64),可以获得兵解所需要的凝神丹(只换1颗)

带着1颗无极天魔丹和1颗凝神丹到武当练功房内找无极真人,对话后得到脱胎换骨丹

打入天堂, 在武神殿找擎天子(31,23) ,对话后就由魔入道了

1 天仙入魔后变为夜叉、阿修罗入道后变为地仙、大罗金仙入魔后变为阿修罗、魔神入道后变为天仙(五转不能仙魔互转)

2 仙魔互转需要300W银两

3 由魔入道如同飞升一样,身上除任务物品外其他物品都会丢失
