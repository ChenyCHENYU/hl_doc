# 五转飞升详细攻略仙道

五转飞升详细攻略（整理中）

严重感谢§八度￠空间￡提供屠血魔尊详细任务攻略、图解

仙道

① 善锻仙家神兵：飞锻造（做的装备少10%修）

② 开创绝世好招：飞创招（可以出**2.2**以上的招）

③ 培育绝世幻兽：飞养宠（1级宠一抓必中，抓来的宠至少85忠，可以把宠多练**50级**，可以超进化）

④ 坚持刻苦修行：飞修行（可以练到1400，点数多了400点）

⑤ 但求照福众生：飞公德（买三级房子8000W、进新山城免费）

**殿廊**：天残子（11，18）

**1**：火淬天神（煅造）

如果炼化经验≥2万，从天残子处得到火淬之令

受命到衡天台找空融子（23，42），对话后得到星君名贴

回到山城武器谱旁边找到“巧匠凌风”，交谈后得到“凤凰战靴”的配方。

**煅造凤凰战靴**：鳄鱼骨11点、鳄鱼骨12点 凤羽9点 布鞋3点 布鞋主练得到凤凰战靴（-280攻 +500敏 **800级**）

再煅造一件 **1000级**以内、防2000+的衣服（含**1000级**、含+2000防）

回到衡天台找到空融子，可以得到“火淬守护佩”

**相关主题**：http://bbs.tx51.com/viewthread.php?tid=231429

**2**：尚武天神（创招）

如果创招经验≥20万，从天残子处拿到武德之令

到御风台找朝阳子（42，25），对话后得到调查令

跑去敕勒川大蓬找族长（25，14），接受族长的委托

去沉没的城市找欧霸天（45，59），对话后战斗打霸王卸甲（3只**2000级**的大象、估计有17000+血），

打赢后得到强者之剑；打输降创招经验5000点

回到敕勒川大蓬找族长，对话后得到感谢信

再去御风台找朝阳子交差，得到“武德守护佩”

**相关主题**：http://bbs.tx51.com/viewthread.php?tid=239999

**3**：巡游天神（修行）

如果修行等级≥2W，从天残子处拿到巡天之令

到翔云台找空冥子（13，39）拿救援令

再去武当后院找传真道人（17，9），对话后，降**300级**，得到青枫剑

重练到**1300级**后，再找传真道人对话，降**200级**，收走青枫剑得到真武靴

再次练到**1300级**，再去找传真道人对话，降**100级**，收走真武靴得到太乙珠

最后再一次练到**1300级**，回去找空冥子复命，得到“巡天守护佩”

**4**：通灵天神（养宠）

如果养宠经验≥20万，就可以要求考验养宠技能。从天残子那里得到“圣兽之令”，受命到降尘台找精通禽眼兽语的圣兽星君御灵子（73，47）。接受御灵子委托，先打败被混沌魔尊施法作乱的五行使者，再去按照御灵子的要求重新寻找五行使者的接班人。找到五行使者的接班人，完成御灵子的委托就可以得到“圣兽守护佩”。

**5**：功德天神（功德）

如果功德值≥1万，可以从天残子处得到道德之令

受命到圣泉台找心漩子（12，18），对话后得到普渡令

到雪城城堡找到城主（30，21），对话后得到龙涎丹

收集材料，制作紫阳丹“点击这里查看制作方法”

带着紫阳丹到雪融谷找银花婆婆（7，31），对话后收走紫阳丹得到“丹凤钗”

再与雪城城主对话，收走丹凤钗得到天蚕衣

带着天蚕衣回圣泉台找心漩子复命，就可得到“道德守护佩”
