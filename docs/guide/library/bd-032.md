# 红利的算法以及攻防去血量的计算公式

红利的算法以及攻防去血量的计算公式

红利算法：

地仙投一次加10，天仙15，大罗20，五转25。外加系统送的20

飞升后的红利=凡人红利+投胎次数×10

大家可以根据自己的投胎情胎。在凡人时和散仙时按此公式算一下

以下是58－61投的一些数据

58投时红利是，凡人780+58×10=1360

59五转投。凡人红利是805+59×10=1395

60地仙投。凡人红利是815+60×10=1415

61地仙投。凡人红利是825+61×10=1435

攻防去血量的计算公式：

人的情况：

不论出征宠物是否与怪物属性是否相克或者相生

怪物打人去血公式为：人去血=怪攻击 ×2 －人防御

宠的情况：

**1**：宠物与怪物属性不相克

怪物打宠去血公式为：宠掉血=怪攻击 ×2 － 宠防御

**2**：宠物克怪物

怪物打宠去血公式为：宠去血=怪攻击 ×2 － 宠防御 ×2

**3**：宠物天敌克怪物

怪物打宠去血公式为：宠去血=怪攻击 ×2 － 宠防御 ×4

**4**：宠物被怪物克

怪物打宠去血公式为：宠去血=怪攻击 ×2 － 宠防防 ÷2

**5**：宠物被怪物天敌克

怪物打宠去血公式为：宠去血=怪攻击 ×2 － 宠防御 ÷4

::: info 玩家提示
- PS：如果宠物在上述情况下都采取防御状态。那么上面宠物的防御力就为上述的防御再乘以2然后套入公式。
:::
