# 修行、创招、养宠条件的几点释疑

修行、创招、养宠条件的几点释疑

1：飞修行

大罗金仙练到**1300级**后，将接受三次考验；第一次掉**300级**、第二次掉**200级**、第三次掉**100级**

魔神则第一次掉**100级**、第二次掉**200级**、第三次掉**300级**

**魔界法器合成**：金光刀9点 堕天甲12点 龟背靴3点 甲为主锻造

2：飞创招

打3只**2000级**的超防大象，初步估计每只约17000+血，人2700混防就够了

3：飞养宠

**大罗金仙**：[蓝发魔姬](/pets/285)**100级**、[绿妖](/pets/208)**200级**、[傲雪兽](/pets/152)**300级**、[至尊林](/pets/81)**400级**、[蓝鸟龙](/pets/22)**500级**

**魔神**：蓝鸟龙**100级**、至尊林**200级**、傲雪兽**300级**、绿妖**400级**、蓝发魔姬**500级**

宠物等级必须适合，超过1级都无法接任务的；飞升后掉20万的养宠经验！
