新人练级详细路线

龙的成长不在高而在成长分布！（一般**6.5**以上的就可以了）

最好的分配是功防型的功防高敏低，这样练级好！

练级带的宠最好是克制自己所打的怪物而不是被克，这样练比较好！

金克木

木克土

土克水

水克火

火克金

新人1级带的装备

采云衣0级+150防

端午节的香朗+50防20敏50功50内或者+20防50敏50功50内

恋之守护+30敏

人宠合一

先发制人-----要么人和宠的敏都低于自己打的怪物

后发制人-----要么就都高于自己打的怪物

人的敏只要能跟宠加一样高，在无好的防衣前还是以加防为主

练金龙====当人和宠都有300敏就可以在悬台跟的到500的象了！到华山打的时候就可以不要敏了因为人和龙的敏一般都不会高于猴子和蹊跷鼠（龙的敏成长最好在**1.0**左右）

简单的说偶自己要是开小号从一级练的话

①首先开号再带上装备真爱鞋+菜云衣服+香朗+恋之守护

②带一只金龙（成长**6.5**左右功**2.5**左右防**3.0**左右敏**0.8**左右敏）

```
③开始练级了（从开始1级到打500级的象加的点数全部加防，要是人和宠不合的话就稍做调整，人敏高了就脱下鞋，人敏低了就加一些，但不要太多了。鞋和香斓可以加250敏了所以点数加敏最多+50左右，当可以去华山打 山脚 720陶陶 740蹊跷的时候可以不要加敏了！因为怪物的敏很高，人和宠都跟不上！人带装备之后的敏可以跟上悬台的500级象就可以不再加其他的，都加防！）
```

新人练苦行归和蝴蝶的路线（新人练级一般不会加功，因为没有极品装备所以点数要是加功就会很难练宠，蝴蝶和归的功成长一般不会很高要是功成长高了就不好练！

所以新人一般不要练蝴蝶和归，但系统规定要练一只**300级**的苦行归才可以飞仙，下面给出练级路线。

本人奉劝新人一般归练到**300级**可以飞就够了，没必要练到很高级别，因为飞仙后的归最多成长也只10+左右，成长好坏等级高低并不影响多大）
