**新手必读**：新手任务攻略

现发表我半年来玩幻灵新手各种快速升级的任务

一。先做个0级用的药王佩任务[防+20敏+20]

在山城药店门口可以遇见药王（27，35），从他那里听说了乾坤五行炉的情况，了解到武当的元元真人正是当今世上少数懂得使用乾坤五行炉的人。找到药王炼丹所需要的无极草与药王交换可以得到药王佩。[无极草在华山腰道左下角的NPC那的到答：无极天魔丹]

二。1-**15级**做丑剑客升级任务

这个任务只限于新手，到水城郊外找到丑剑客（打**20级**蝴蝶的地方）她会让你买一瓶甘露酒给他！如果你有300元就去药典买一瓶！她会给你升**10级**

三。50-**69级**做修剑传功任务

水城的楚狂人[楚狂人在青风原]前些天在幻兽的大战中受了重伤，心爱的宝剑也损坏了。他现在伤重不便行走，希望有人能帮他把他的剑送到山城铁匠张三那去修修。

如果玩家和他对话，并选择帮助他，他会告诉你行走的路线，并将他的"松纹残剑"交给你。带着"松纹残剑"，找到山城的铁匠张三，得知他无法修复此剑，必须找树城的铁匠李四才可以修复。

带着"松纹残剑"，找到迷雾榕城的李四，他会将"松纹残剑"修复为"松纹金钢剑"。 带着"松纹金钢剑"，回到水城的楚狂人处，将"松纹金钢剑"还给他，你的等级将得到提升**20级**

四。70-**200级**做送物得甲任务

华山脚的修行者一直在用乾坤五行炉炼制毒药，可是现在一些材料用完了，如果回城取，非常的费工夫。

如果玩家和他对话，得知乾坤五行炉的作用和获取方法，并选择乐意帮他去买银蜂针和缝影烈毒散这两样东西，他会告知玩家在哪里买到这两样东西，并给玩家一张"购物单"。

买到需要的两样东西后，带着"购物单"再次来到华山脚，交予修行者，他会将自己做的铠甲送给玩家。

五。到了**150级**做除小贼任务

和水城的怪老头对话，他会警告你要小心小偷。如果向他求助该怎么办，他会告诉你别把钱放在身上，都存起来，同时还要练偷。他还希望你能帮他夺回被逃到山城附近的小偷所偷走的东西。选择帮助他，你会得到物品"物证"。

带着"物证"，找到枯井原的笨小偷。他提出用武力解决，选择"我可不怕你"，就进入战斗。战斗胜利，失去物品"物证"，得到物品"贵重项链"，将"贵重项链"还给怪老头，等级提高**10级**。

六。**150级**左右做“佛珠”任务

在水城的船上的小云（22，54），她会给你一条佛珠。再到树城斗宠处下面，找云中子（69，107），他会帮你把佛珠祝福一下，成为“祝福过的佛珠”

七。现在可以做恋之守护任务

在美丽的栖月谷（28，40）[不到**300级**去要花3000块]，可以看到一个漂亮的mm可儿在呤诗，询问后得知她的恋人远在雪城，请玩家帮忙到雪城附近为她的恋人常枫送上一件可儿亲手做的“御雪暖服”（多才多艺，能诗，也能做家事）到了雪城附近，由西雪岭经寒井台,进入冰清桥往上就是玉洁桥，常枫会出现玉洁桥最深处（40，20），将衣服给他后，他会请玩家再帮忙带上一支“雪山人参”给可儿按原路回到栖月谷再与可儿交谈，可儿为了表示感谢，将自己儿时获得的一条有魔法的项链“恋之守护”赠送给玩家。

此项链据说有特别的魔法，只要佩戴上这条项链，爱情就能得到恋之女神的护佑。

做好这些任务新手只要4。5小时左右可以轻松到练**200级**左右了

建议新手先加帮可获赠幻币或0级用的一些新手防具或宠对你快速升级很有用的
