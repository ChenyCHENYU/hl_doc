# 关于地仙投胎和5转投胎的比较（修改）

关于地仙投胎和5转投胎的比较（修改）

现在转PK人的都知道。。要在PK方面有所发展只有2个方法：

**1**：就是兵解加修，修越高。。装备的属性点数就越高。当然带来的敏，血，内，攻等各方面的点数就越高了。

**2**：就是投胎了。因为投胎系统对针对不同的投胎级别给予不同的红利奖励（地仙是给10点。天仙15点，大罗20点。5转是25点最高）,(但是我们要注意.不管你是地仙投还是5转投.每次投胎系统会加10点的飞升奖励,)

这2个方法中，兵解当然是大家最熟悉的了。就不做研究。但是在第2种方法里面就有2个发展方向了。一个是地仙投胎；另一个是5转投胎。这里，我们先大致的讨论一下2个投胎方法的优劣，给大家一点参考意见。

**一**：地现投胎，特点：按**1200级**投胎算的话，每次投胎是10点红利+10点奖励=20点，1200+1200=**2400级**的修。

**优势**：1：不需要浪费时间练仙子（或是花钱买仙子和龙）。

**2**：基本上能保持1天3解的人都能做到每天一投。速度快。

**3**：前2个**800级**都不用过劫（凡人和散仙）。

**劣势**：红利加的少。修也少。

**二**：5转投胎， 特点：按**1300级**投胎算（一般5转投都选择飞的是尚武），每次投胎加红利点数是25点+10点奖励=35点. 加的修是**1000级**（地仙）+**1000级**（天仙）+**1300级**（大罗）+**1300级**5转+(1300现行等级)×**2.5**的奖励=**7850级**。

**优势**：红利多。加红利的同时修也加的不少，

**劣势**：1：需要时间和钱搞仙子或是黄龙。

**2**：由于到地仙开始一直到飞了5转前都是每**100级**要过劫。所以除非人守着机器.不然就耽误很多的时间。（5转是每**300级**过劫）

**3**：能保持1天3解的人，5转投胎估计3天每投。条件是有仙子或龙。

**4**：必要的时候需要一个做药的小号配合(带仙子或是黄龙吃药)

**比较**：我们分别拿99天和198天的时间来做一个比较（当然只是纯数字的，除开了人为和机器的因数）

**99天地仙投胎**：每天1投，99天就是能到最高的99投，奖励红利是(10点红利+10点飞升奖励)×99=1980点，修按都是**1200级**投胎算是( 1200+1200)×99=23**7600级**。

**99天五转投胎**：每3天一投（多少借助九转一点），99天就是33投，奖励红利是(25点+10点)×33=1150点。按每次**1300级**投胎算，修是7850×33=25**9050级**。

**第一结论**：地仙99天比5转多1980-1150=830点红利(优势明显)，而5转比地仙多的修是259050-237600=2**1450级**(没有什么优势)，

**198天地仙投胎**：还是每天1投,99天到99投,红利是1980,修是237600,因为不能再投胎了.剩下的99天兵解加修,一天3解**800级**为例 ,修是**3600级**/天×99天=356400,加上前99天的修=594000.

**198天5转投胎**：还是每3天一投,198天是66投.红利是35×66=2310点.修是518100.

**第二结论**：5转198天66投比地仙多2310-1980=330点.修比地仙少594000-518100=75900(只要懂锻造的人都知道,对于这个修行级别来说,这点修不算差距),由此可见,到此时5转投胎的优势就显示出来了.而且越往后面,优势越明显.

**最后总结一下**：地仙投胎是在短期内看效果，而5转投胎则是着眼将来，可以说，选择地仙投胎的人，在自己99投以前的时间内都是比较风光的。因为速度快。能在短时间内加N多的红利，相比较而言，5转投胎一直比较被动。。但是5转投到60投以上的话。效果就出来了。
