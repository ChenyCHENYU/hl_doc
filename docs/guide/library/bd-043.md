装备新理论

**by**：robin1108

先要说明这个是我自己到现在对锻造的理解所写，可能有不对的地方，不是权威．

再就是这个帖子研究的是做最高极限状态的属性填加，不是在第１次极限以前的属性填加．

先说下装备有属性相生，相克，被克，相离这４个状态．以武器做列：

武器属火，相克金，相生土，被克水，相离木．

于是武器要减属性只可以减金，可以加土水木．

这里以下部分是我自己的总结了，希望可以得到补充和批评．

相生＝可以吧正属性点全部加上去，１００％

相克＝这个就不说了，全世界都是，减多少属性的现在数据全有了．

被克＝（３１６８＋减的副属性）＊**０.３**＊**０.７４**４

相离＝正属性点的７０％可以转过去．

**以武器醉剑为实例**：武器醉剑极限加攻击6361,锻造基础里就有锻造只可以转正属性的30%

于是6361×**0.3**=1908

相生=1908×100%=1908 由于是血还要×3 1908×3=5724

相克=1908 于是减攻击1908

被克=(3168+1910)×**0.3**×**0.74**4=1133 于是加敏捷1133

相离=1908×**0.7**=1**335.6** 由于是内还要×3 1**335.6**×3=4007

再说下加属性的办法:

相生=直接往上加极限,相生状态下加极限正属性点是不变的.

相克=个各帖子离都有,就是加负极限加正极限加副极限......

被克=这个是最难的,被克状态下加副属性后正属性的修行会往下掉,要计算出合适的点才可以加到.

相离=把正属性降修后加副属性,副属性极限加上去后正属性修行也会提高,这个加起来也简单,不停的往上加就可以.

最后要说的是所有状态下,相生是个很特别的情况,只要正属性的纯点在那,就可以加极限,加到那个点为止.

有实际例子可以证明,1把加1134的武器,加了血以后状态是+血4620+功5134-防1910+敏1134.

可能新手看不懂,锻造高手可以一起来研究下.

再就是不要去死盯着那几个点的出入,这个是理论性的东西,误差不是太大就可以.

帖子里的加属性方法很实用,这个是锻造高手要知道的.
