**一**：基本知识

**1**：练造成装备对应属性：

武器（火） 防具（金） 鞋（水） 身饰（木附加内） 头饰（土附加血）

**2**：装备误区

装备常会在练到属性点4300左右时到达第一次假极限，其实这时候可以通过多加一个同样的装备得到更大的属性

双加得到的正属性极限装备效果是一样的，上述只适合有负属性的装备

**3**：位置误区

请留意装备对应属性，尽可能的不要放在相克的位置

**二**：装备间煅造主炼加副炼效果对照图

**三**：计算公式

**1**：材料计算

**公式**：副练＊30%＋主练**１０００级**纯属性点+副**１０００级**纯属性点＝主练需要属性点（适用鞋子/兵器/衣服 ）

**公式**：副练/３乘90%＋副练**１０００级**纯属性点＝主练需要的属性点（适用头饰/身饰）

**注**：公式计算的值是至少初步值，可用毒微调到最合适的可利用值

**2**：各种装备的**1000级**纯属性点计算方法

衣服 ： 防+敏+攻+内/3+血/3=499

**鞋子/兵器**：防+敏+攻+内/3+血/3=399

**头饰/身饰**：防+敏+攻+内/3+血/3=149

**3**：点数换算

敏，攻，防点互换是一比一

敏，攻，防点换血点内点是一比三

**四**：PK装备之衣服篇

纯敏衣

**主材料**：500元轻布衣

**副材料**：680元的草鞋

位置 ：衣服金位（11和12点） 鞋子水位（三点）

具体做法：

第一步：

计算所需材料

**副材料**：假设副材料使用加敏3168的极限鞋

**主材料**：3168×30%+499=1449（按公式1计算得出主材料衣服需加防1449）

**第二步**：在衣服加防为1449的基础上一个个毒慢慢调节得到下面数据

极限鞋功+3168，甲防+1501甲11点鞋3点甲做主炼出来甲敏+446

**第三步**：反复用公式计算衣服的初步所需防点

**第四步**：按个人等级计算最高可加敏点，计算方法如下

用毒练一个你能穿的等级的加敏鞋子得到其纯点，鞋子的纯点就是你的衣服可加的敏点

**第五步**：用草药或银子降级，注意位置

纯血衣

**主材料**：500元轻布衣

**副材料**：水城1200元的水纹坠

位置 ：衣服金位（11和12点） 血佩土位（五点和六点）

**具体做法**：请参看纯敏衣。佩加衣同时升防和血，衣服的防点关系的能减的血点，可用毒草再加防

纯攻衣

**主材料**：500元轻布衣

**副材料**：水城200元的乌云剑 草鞋

位置 ：衣服金位（11和12点） 攻剑火位（三点）鞋子水位（三点）

**具体做法**：请参看纯敏衣，剑加衣有降级作用，请注意用毒草加衣服的防，以免衣服的防不足以得到攻

血攻衣

主材料：轻布衣

**副材料**：乌云剑 水纹坠

位置 ：衣服金位（11和12点） 攻剑火位（9点）血佩土位（五点和六点）

**具体做法**：请参看纯敏衣，先把需要的血加够，再用刀来降级得到攻

血敏衣

主材料：轻布衣

**副材料**：水纹坠 草鞋

位置 ：衣服金位（11和12点） 鞋子水位（3点） 血佩土位（五点和六点）

**具体做法**：请参看纯敏衣，请先把需要的血加够，降级后就是可用的敏点。

**五**：PK装备之兵器篇

纯攻剑

**主材料**：自己适用的武器

副材料：轻布衣

位置 ：衣服金位（11和12点） 攻剑火位（9点）

公式 ：**1000级**的攻击=399+减去的防御

具体做法：

**第一步**：兵器放在火位 +毒药=炼化武器

衣服放在金位 +毒药=炼化衣服

**第二步**：炼化武器（火位）+炼化衣服（金位）=减防御的刀

**第三步**：减防御的武器+毒药=减防御的武器2（有更高的攻）

**第四步**：减防御的武器2+锻造衣服=见防御的武器3

**第五步**：循环下去 最后得到最高可减到1867的防 加攻6300的兵器

**第六步**：用草药降等级，注意位置，兵器属火，按五行相生相克 的原理，兵器不要放在火位

**第七步**：注意问题当你无法再进一步减攻时请再多加一把兵器

攻内剑

**主材料**：自己适用的武器

**副材料**：轻布衣 水城珠宝店的黄绵带

位置 ：衣服金位（11和12点） 攻剑火位（9点） 内佩木位（1 点）

**具体做法**：参看纯攻兵器，计算好个人等级的纯点，内点换攻是一比一，敏点换血点是一比三得到最好的兵器

攻血剑

**主材料**：自己适用的武器

**副材料**：轻布衣 水城珠宝店的水纹坠

位置 ：衣服金位（11和12点） 攻剑火位（9点） 血佩土位（5点）

**具体做法**：参看纯攻兵器

纯内剑

**主材料**：自己适用的武器

位置 ：衣服金位（11和12点） 攻剑火位（9点） 内佩木位（1点）

**具体做法**：参看纯攻兵器，请先把剑减防到最尽后加内

纯血剑

**六**：PK装备之饰物篇

纯血饰

**主材料**：水纹坠（右边装备）

**副材料**：减5000毒

**血内剑**：先内后血，用攻剑和加内佩作，再加血

**敏攻剑**：攻剑加鞋
