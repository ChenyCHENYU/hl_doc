用最快的速度锻造极限!

特别感谢会员snyjw提供原始资料

大家知道用变速齿轮对幻灵加速太快的话，幻灵就会掉线

但是有没有想过对HLHL进行加速呢?

HLHL为什么比RWX锻造极限的速度慢呢,就因为HLHL在买银蜂针的时候速度太慢,不像RWX一样,买同样的物品是速度很快，所以大家可以使用变速齿轮对HLHL进行加速,但是具体加到多少HL不会掉我还没实验过,不过的确速度比以前快了不少!

还有要注意的就是,一定要选择HLHL进行加速,而不要把所有程序都加速,尤其是不要对幻灵加速哦~

只要你的网速够快的话,嘿嘿,不多说了，自己去体验吧

**附**：使用说明

1,先打开幻灵,买好一个原材料，然后用草锻造一次,最小化幻灵窗口

2,打开HLHL**0.79**9,选择相应的极限脚本，开始工作

3,打开变速齿轮(98系统不可用,2000或者XP用NT版)

4,在变速齿轮左下的任务框里选中HLHL(不要隐藏HLHL,否则任务框里就显示不出来了),然后点加入,就可以看到在右边的要加速程序框里，有了HLHL了

5,调节加速速度,根据个人网速和机子配置不同,自己调节就OK了~
