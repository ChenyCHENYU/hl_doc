# 正气战衣清血敏的方法

<TopicHeader cat="玩家文库 · 锻造-防具" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

正气战衣清血敏的方法（ ye华 提供）

**清防**：直接买个草，衣服9点草随便放锻造下``衣服防就变0了

**清内**：然后直接买个最便宜的内带锻造和衣服锻造,内就0了

**清血**：血也一样,再买一个最便宜的头饰(银丁耳环或者水纹坠)血也就清0了

**清敏**：要清敏再买个最便宜的鞋子和衣服锻造

这个时候衣服就变-100攻,其他数据0了

::: info 玩家提示
- PS:只要衣服的防降为0了,要清什么属性就加其对应的原材料
:::
