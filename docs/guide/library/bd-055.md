**公开咯**：金光刀+1140敏的数据。(旧数据)

先将 金光刀 练成极品攻刀：+6438攻-1931防-150敏

在不降修的情况下：

砸第1个极限鞋 得到 +3663攻 -1931防 +250敏 (刀12点 鞋3点)

砸第2个极限鞋 得到 +3011攻 -1931防 +815敏 (刀6点 鞋3点)

**加毒炼话至**：+4284攻 的时候砸第3个极限鞋 得到 +1005敏的刀

**加毒炼话至**：+4094攻 的时候砸 +1822敏的鞋 得到 +1053敏的刀

**加毒炼话至**：+4046攻 的时候砸 +1575敏的鞋 得到 +1086敏的刀

**加毒炼话至**：+4013攻 的时候砸 +1368敏的鞋 得到 +1109敏的刀

**加毒炼话至**：+3990攻 的时候砸 +1191敏的鞋 得到 +1125敏的刀

**加毒炼话至**：+3974攻 的时候砸 +713敏的鞋 得到 +1130敏的刀

**加毒炼话至**：+3969攻 的时候砸 +997敏的鞋 得到 +1140敏的刀
