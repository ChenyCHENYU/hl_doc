1140敏刀+血+内数据(旧数据)

首先要一把金光锻的1140敏刀（好象是废话，除了金光没有别的刀可以到1140敏）

**http**：//bbs.tx51.com/viewthread.php?tid=234150<------1140敏锻造数据

加血内步骤：

加内

刀降攻到926，加 第1根 极限腰带（刀9带7）内699

刀降攻到734，加 第2根 极限腰带（刀9带7）内1392

刀降攻到1025，加 第3根 极限腰带（刀9带7）内1974

★下面直接加极限腰带

第4根极限腰带 得到2745攻2280内（刀7带2）

第5根极限腰带 得到3134攻2496内（刀7带2）

第6根极限腰带 得到3423攻2670内（刀7带2）

第7根极限腰带 得到3366攻2844内（刀7带2）

第8根极限腰带 得到3308攻2976内（刀7带2）

第9根极限腰带 得到3404攻3063内（刀9带7）

★还可以继续加内，加一个极限武器（刀9极限武器7），然后加极限腰带，具体位置自己尝试，我没有做过，跟大家说声对不起了

加血

上面的刀降攻到1352，加极限头饰，+1200血（刀9饰6）

加攻到1875（可取HLHL锻造到1875前一个数值，我找最佳点多锻了一下，发现一样），加极限头饰，+1680血（刀9饰6）

加攻到2238（可能过头了），加极限头饰，+2007血（刀9饰6）

加一个极限武器（刀9极限武器7）

接着就加极限头饰了，一个加150左右，忘记了，反正按照自己的修加就可以了
