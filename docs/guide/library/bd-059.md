# PK血内药的最佳炼法

<TopicHeader cat="玩家文库 · 战斗与PK" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

PK血内药的最佳炼法

人在水城珠宝店,用任我行做以下记录:

1. 买1个锦腰带,再买4个银蜂针,1个蒙汗药,腰带7点主炼毒12点针位置任意,炼成一个加内144的炼化内力带
2. 买一个止血草11点,炼化内力带1点,止血草主炼得到一个2W内的PK药.
3. 再买银蜂针1个放9点,药11点主炼就得到18500血,2W内的药.

这种方法不必跑华山拿无极草换佩,省时省力,1000炼化经验就够,PK人进PK场前必备的药就此炼成.

**补充**：a.必须加入延迟，才能确保全速炼而不掉线，在第2步和第3步加多一些延迟，因为炼的物品较少。加多少延迟看各位网速而言。

b.第2步再炼一次或加两个镖就可以得2W血2W内的药。

c.可在最后加入炼完的药给另外一个号的记录，更为方便。
