# 彪左饰

<TopicHeader cat="玩家文库 · 锻造-饰品" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**新标左饰**：+1000血，+3936内，+186攻击，+75防， +94敏

**材料**：原始暗神，+1000血，-200攻击 6件内极限 9把极限武器 1件极限衣2件半极限 2件极限鞋

**第一步**：直接砸2件内带 得到：1000血 5601内 -200攻（暗神1点，极限内带7点）

**第二步**：直接加一个银针 得到：1000血 5601内 -186攻

**第三步**：直接加极限武器9把 得到：1000血 5601内 186攻（武器9点，暗神1点）

**第四步**：直接加极限衣 得到：1000血 5601内 186攻 48防（衣12点，暗神1点）

**第五步**：砸极限内带后加件半极限衣+1366 得到：1000血 5601内 186攻 70防（衣12点，暗神1点）

**第六步**：砸极限内带后加件半极限衣+836 得到：1000血 5601内 186攻 75防（衣12点，暗神1点）

**第七步**：降内到1551 加极限鞋 得到：1000血 5601内 186攻 70防 76敏（鞋3点，暗神1点）

**第八步**：直接加极限鞋子 得到：1000血 5601内 186攻 70防 94敏（鞋3点，暗神1点）

**第九步**：直接砸2见极限内带 即可！（暗神1点，极限内带7点）

**想省极限的注意**：第5，6步可以不用加极限内，自己把内练上去浏览看有加到适合的防就OK！

**新标左饰**：+200血，+4512内，+150攻击，+230防， +200敏

**材料**：一个盘龙，2件极限内带，4把极限武器

**第一步**：直接砸2件极限内（盘龙1点，极限内带7点）

**第二步**：直接砸极限武器4把（盘龙1点，武器9点）即可！

有钱的可以弄个云淡风清瓶.

第70关，如果队长出征宠物成长率超过50，和守关npc说话，则进入隐藏关，并且如果宠物满足条件，完成地图上npc要求的简单任务，除了战斗中可以抓到新宠物[强盗](/pets/101)，还可得到20000修行可装备的＋300攻的身饰“云淡风清瓶”奖励。而且无论任务完成与否，都可以得到一颗锻造用的水晶。

换取云淡风清瓶需要一只1级100忠的强盗.

有云淡风清瓶后.直接砸2-3个极限内.把内砸到极限即可.(风清瓶1.极限内7点.这2个位置随意)
