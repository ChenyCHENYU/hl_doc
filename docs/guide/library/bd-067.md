# 防衣

<TopicHeader cat="玩家文库 · 锻造-防具" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**云锦天衣**：-70攻 -80敏 +100血 +150防

**消耗材料**：堕天甲或云锦天衣1件 极限内带17条 极限甲7件 半成品内带4条

(堕天甲、云锦天衣煅造防衣**1000级**的属性：-5940内 +2629防)

云锦天衣清血的方法：

炼化一个+1200血的头饰，衣服12点、头饰5点、主练衣服；再把衣服的防降到0，在水城饰物店买个水纹坠和衣服炼化、血就清0了
