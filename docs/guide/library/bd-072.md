# 防右饰[恋之守护材料]

<TopicHeader cat="玩家文库 · 锻造-防具" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**材料**：恋之守护（或其他右佩也可以）、极限鞋子5双、极限血佩3个、极限衣服5件、草鞋1双

1. 先将头饰（右佩）炼到加血3798（头饰5点，药9点）用极限鞋子减敏（头饰5点 鞋子3点）
2. 再炼头饰到加血4620（位置同上），用极限鞋子减敏 （位置同上）
3. 然后边用极限4251头饰加血（原头饰5点 极限头饰6点）边用极限鞋子减敏（位置同上），循环3次头饰炼至减敏222
4. 用极限3168衣服加防（头饰5点 极限衣服11点），重复5次 一直加到222防
5. 最后用草降修行（头饰7点 草1点），微降（头饰11点 草9点）
6. 把修行降到**100级**，+9血+222防御-222敏的时候，应该降不下去了
7. 买一个水城最便宜的鞋子，鞋子3点，佩6点，得到一个+血9点，+防御222，得到16000修的右佩
8. 继续用草降一次（头饰7点 草1点），得到一个+防御222，修行1W5的右佩，不减任何属性
