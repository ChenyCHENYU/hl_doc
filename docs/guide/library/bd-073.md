# 防左饰

<TopicHeader cat="玩家文库 · 锻造-饰品" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

玄金镯震木、人鱼之泪坎水、狼爪离火、龟壳乾金、龙鳞艮土,主炼玄金镯,即可得到磐龙樽

**(磐龙樽属性为**：+生命200 +防御230 +敏捷200 2万修行用)

极限内2个.极限武器4把左右.

第一步.连续砸个极限内.得到+4512内.其他属性不变.磐龙樽和极限内位置1点或7点.2个随意放.

第二步.直接砸武器到+150攻就可以了.磐龙樽7点或者1点.极限武器9点.
