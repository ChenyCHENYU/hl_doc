# 招右饰

<TopicHeader cat="玩家文库 · 锻造-饰品" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

丹凤为最好的材料.

丹凤钗(飞功德时的任务物品)

**1**：减敏过程

第一步,加血到4017,加第一个极限鞋.===>减敏133.(丹凤6点.极限鞋3点)

第二步,加血到5010,加一个加敏2096的半成品鞋子.===>减敏167.(丹凤6点.极限鞋3点)

第三步,加第一个极限血饰.加第二个极限鞋子.====>减敏218.(丹凤6点.极限鞋3点)

第四步,加第二个极限血饰.加一个加敏1812的半成品鞋子.===>减敏233.(丹凤6点.极限鞋3点)

第五步,加第三个极限血饰.加一个加敏1010左右的半成品鞋子.===>减敏235.(丹凤6点.极限鞋3点)

2:加防

加血到极限7065,然后连续砸上6个极限衣,加防235.(丹凤6点.极限衣12点)

全极限数据.

原始丹凤1个.极限血5个.极限鞋5双.6件极限衣.

第一步.丹凤6点.极限血5点.得到+4683血.主练丹凤

第二步.止血草12点.丹凤9点.连续降2次.降第一次+4386血.降第二次+4182血.主练丹凤

第三步.丹凤6点.极限鞋3点.得到+4182血.-123敏.

第四步.丹凤6点.极限血5点.得到+6198血.-123敏.

第五步.丹凤6点.极限鞋3点.得到+6198血.-183敏.

第六步.丹凤6点.极限鞋3点.得到+6198血.-206敏.

第七步.丹凤6点.极限血5点.得到+6978血.-206敏.

第八步.丹凤6点.极限鞋3点.得到+6978血.-232敏.

第九步.丹凤6点.极限血5点.得到+7056血.-232敏.

第十步.丹凤6点.极限鞋3点.得到+7056血.-235敏.

加血到极限7065,然后连续砸上6个极限衣,加防235.(丹凤6点.极限衣12点)

::: info 玩家提示
- PS:招人不需要加那235防.也可直接用挂机的来做招右.没什么影响.
:::
