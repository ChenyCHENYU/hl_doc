# 内衣

<TopicHeader cat="玩家文库 · 锻造-防具" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

正气甲乾金、正气甲兑金、象牙震木、龙鳞坎水、鳄鱼骨离火、霸王钳艮土,主炼乾位正气甲,即可得到正气战衣

**正气战衣属性**：+生命400 +内力2000 -攻击100 +防御300 +敏捷100 2万修行等级用(此处用到2件正气甲,不是错误)

正气战衣作血内衣生命+2139 内力+2000 攻击-100 防御+3193 敏捷+957

在开始做之前,当然是先给正气战衣清不需要的属性:

止血草12点、衣服7点，给衣服清防,衣服12点、草鞋3点，给衣服清敏, 得到+400血、+2000内、-100攻的正气战衣

**1**：衣服加防到221,加第一个极限血饰,========>加血1020.

**2**：衣服降防到868,加第二个极限血饰,========>加血1362.

**3**：衣服降防到1341,加第三个极限血饰,=======>加血1605.

**4**：衣服降防到1513,加第四个极限血饰,=======>加血1818.

**5**：衣服降防到1889,加第五个极限血饰,=======>加血1986.

**6**：直接加第六个极限血饰,==========>加血2139.

看清楚哦,第一步是加防,其它几步可是降防哦..

接着砸极限衣服..直到 3193 防御

再接着砸极限鞋子..直到 957 敏捷
