# 内左饰

<TopicHeader cat="玩家文库 · 锻造-饰品" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

普通材料

1. 锦腰带为原料

**1**：把一般的内带加内到3780，加个极限血，得到-378血+3780内的左饰（内1点血5点）。

**2**：把内加到4629，加个极限血，得到-462+4629内的左饰（位置同上）。

**3**：给-462+4629内的左饰加个内带（内7点，减血内带1点），在加个极限血得到-612+6408内的左饰。

**4**：再加极限内带，用极限血佩减血，方法如（3） 得到-660血+6612内的左饰。 5：最后在加个极限内带加内，用半成血减血（注：这里不用极限血了,+900血的就可以了）。

**6**：然后就用极限内带把减好血的身饰的内加到极限，最后直接用极限武器砸，攻的极限是222。

当然了,其实要不要把攻加到极限是根据个人的红利点和所用招的大小而定的. 没必要一定要把攻加到极限.

全极限数据

步骤：

主炼 极限内 （7点）+ 极限血（5点） =主1 [-300+4251]

主1（1点） + 极限内（7点）=主2 [-300+6096]

主2（7点） + 极限血（5点）=主3 [-459+6096]

主3（7点） + 极限血（5点）=主4 [-609+6096]

主4（1点） + 极限内（7点）=主5 [-609+6609]

主5（7点） + 极限血（5点）=主6 [-660+6609]

主6（1点） + 极限内（7点）=主7 [-660+6660]

主7（7点） +900+血带（5点）=-666血内带 [-666+6660]

最后砸个极限内把内加到极限.

黯神戒指材料

减血732的数据..

清掉原来的1000血,把左饰放1点,水城珠宝店的水坠纹放6点,1点主炼.

**1**：直接加内到4170,加第一个极限血饰======>减血417.

**2**：直接加内到5268,加一个加血2580的半成品血饰.=====>减血525.

**3**：加第一个极限内带===>加内7053,然后加第二个极限血饰=====>减血678.

**4**：加第二个极限内带===>加内7278,加一个加血2415的半成品血饰===>减血726..

**5**：加第三个极限内带===>加内7326,加一个加血918的半成品血饰===>减血732..

90W修加攻的数据.. 加攻的极限是244,把做好减血732的左饰直接加极限内带把内加到极限. 然后加极限武器加攻到不能加为止.(不能降修加攻..)

当然了,其实要不要把攻加到极限是根据个人的红利点和所用招的大小而定的. 没必要一定要把攻加到极限.
