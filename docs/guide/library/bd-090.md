# 内彪右饰

<TopicHeader cat="玩家文库 · 锻造-饰品" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

\+5766血+465内+158攻+192防-192敏数据

材料.-235敏+465内的丹凤

1. 降血到1257左右.加把极限武器.得到+97攻.(武器9点.丹凤6点)
2. 直接加1582的半极限武器.得到+107攻.
3. 给丹凤砸个极限血.得到+5295血+107攻(丹凤6点.极限血5点)
4. 加个极限武器.得到+158攻.
5. 给丹凤砸个极限血.得到+5766血+158攻(丹凤6点.极限血5点)
6. 连续砸5件极限衣.得到+192防+5766血+158攻.最后买双草鞋降敏即可
