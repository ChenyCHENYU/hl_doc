# 防招武器

<TopicHeader cat="玩家文库 · 锻造-武器" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

防招武器（全极限）需要极限内9个，极限武器1个，极限血25个

首先买个情剑，用止血草减攻为0，再去水城买个草鞋将敏清0，这时候剑只加防120

剑11点，极限内1点砸3次

剑9点，极限内1点砸6次，这时候是加内2439，加防120，加攻多少忘记了

剑7点，极限武器9点，这时候是加攻3425，内还是2439，加防120

剑9点，极限血6点砸25次，这时候是加血3081，加内2439，加攻3425，加防120。完成。

比3081，2436，3426，120的数据有点出入，不介意的可以这样做
