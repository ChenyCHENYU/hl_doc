# 极品防鞋

<TopicHeader cat="玩家文库 · 锻造-防具" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

材料，满修敏鞋一双，极限衣16个

**第一步**：-1995敏鞋，降修至**200级**（更少也可以）

**第二步**：鞋子9点，极限衣服12点，连续砸9次。得到鞋子1

**第三步**：将做好鞋子1放在7点，草12点，降修一次，得到鞋子2

**第四步**：拿一个极限衣服，放在6点，草药12点，降修一次得到{极限衣服1}

**第五步**：将鞋子2放3点，极限衣服1放9点，炼化得鞋子3

**第六步**：鞋子3,放在5点降修2次，

**第七步**：买一个900毒药，鞋子3点，毒12点炼化

**第八步**：连续砸剩下的极限，鞋子3点，衣服12点
