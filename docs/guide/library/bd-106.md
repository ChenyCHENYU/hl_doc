# -666幻宠装备

<TopicHeader cat="玩家文库 · 宠物养成" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

\-666血+1017内**1000级**用幻化宠装备

买4个极限腰带 2个极限头饰,四个半极限头饰

其中一个极限腰带作为主料

往上面砸一个极限头饰 极限腰带7点 头饰5点

再放一个极限头饰，极限腰带7点 头饰5点(这里头饰不用极限，2510血以上，)

再往上面砸一个极限腰带 主练腰带7点 极限腰带1点

继续砸一个极限头饰 极限腰带7点 头饰5点

再放个极限极限头饰,极限腰带7点 头饰5点(这里头饰不用极限，只要1597血以上)

再砸个极限腰带 主练腰带7点 极限腰带 1点

再砸个极限头饰....(这里也不用极限，嗯，最好2445血以上)

再一个极限腰带...

最后一个极限头饰....(这个只要+990血以上就行)

得 -666血 +6660内

以上头饰的数,不是很精确,要试验方法很简单,

只要先拿个极限血预览下,再放数少的，减的数一样就行.

**降修数据**：草十二点，头饰十一或五点放七次，得九百级.

以下是我的降修方法:

草十二点，666五点

主练666

六次可以到6500

草十二点，666九点

四次可到1000

得-666血 1017内 **1000级**使用左饰 幻化前两只宠物都带上...能提高幻化预览的**0.67**...一只戴是**0.34**
