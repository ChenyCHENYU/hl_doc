# 1512进化宠装

<TopicHeader cat="玩家文库 · 宠物养成" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

1512全极限做法

**第一步**：丹凤6点，极限血5点，主练丹凤

**第二步**：丹凤6点，极限鞋3点，主练丹凤

**第三步**：丹凤6点，极限血5点，主练丹凤

**第四步**：丹凤6点，极限鞋3点，主练丹凤

**第五步**：丹凤6点，极限鞋3点，主练丹凤

**第六步**：丹凤6点，极限血5点，主练丹凤

**第七步**：丹凤6点，极限鞋3点，主练丹凤

**第八步**：丹凤6点，极限血5点，主练丹凤

**第九步**：丹凤6点，极限鞋3点，主练丹凤

降修 —— 最后用草12点、丹凤7点，降7次；

微调 —— 水药买无忧失心草（水药最贵的毒）2个，银蜂针4个，丹凤6点，毒12点，针放在毒的两边（各2个），筑炼丹凤；第二次丹凤6点，毒12点（注意没有银蜂针）

得到减修**900级**+1512血-235敏。完工。
