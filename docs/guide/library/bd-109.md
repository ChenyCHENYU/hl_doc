游戏时辰与标准时间对照

方便大家做任务

把古代的时辰和现在的时间贴出来下：0

**子时**：夜11点至1点

**丑时**：凌晨1点至3点

**寅时**：凌晨3点至5点

**卯时**：凌晨5点至7点

**辰时**：上午7点至9点

**已时**：上午9点至11点

**午时**：中午11点至1点

**末时**：下午1点至3点

**申时**：下午3点至5点

**酉时**：下午5点至7点

**戌时**：傍晚7点至9点

**亥时**：晚上9点至11点
