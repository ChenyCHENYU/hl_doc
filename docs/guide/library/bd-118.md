关于宠物三围的锻造

练宠人如果不会锻造宠。那么你不算是一个会练宠的人。下面是我的一些心得。跟大家一起分分。

1。首先：宠物锻造后是不会改变宠物成长，不会改变宠物忠诚度，不会改变宠物三围总的属性点的，也不影响锻造后宠物三围的实际成长（例如：你的宠物防成长是3，锻造后还是3），它只影响幻化后的三围分配。

2。其次：下面就是按照您的需要来进行炼化

**（1）加攻**：买把武器来炼上去，然后同宠物炼

只+攻击的武器， 炼出的是把宠的防和敏加到攻上去 敏防都减

\+攻+敏的武器， 炼出的是把宠的防主要加到攻上去，敏随着武器加的敏点数高而变高。

\+攻+防的武器， 炼出的是把宠的敏主要加到攻上去，防随着武器加的防高而变高。（2）加防：买件衣服来把炼化上去，然后同宠物炼

只+防的衣服。炼出的是把宠物的攻和敏加到防上去，攻和敏都减

\+防+敏的衣服，炼出的是把宠的攻主要加到防上去，宠的敏随着衣服加的敏点数变高而变高。

\+防+攻的衣服，炼出的是把宠的敏主要加到防上去，攻随着衣服加的攻击点数变高而变高。

**（3）加敏**：买双鞋子来炼化上去，然后同宠物炼

只+敏的鞋子，炼出的是把宠的攻和防加到敏撒去，攻和防都减

\+敏+防的鞋子，炼出的是把宠的攻加到敏上去，鞋子加的防越高。宠加的防也越高。

\+敏+攻的鞋子，炼出的是把宠的防加到敏上去，攻随着鞋子加的攻击变高而变高。

关于炼化的位置

（1）装备都按属性放

武器放火位（9点）；衣服金位（11点或12点）；鞋子水位（3位）

（2）宠物也按属性放调整的最多

不过如果你用鞋加水系宠的敏，那把宠放水位，装备自己看吧

土系（5点）木系（1点或7点）
