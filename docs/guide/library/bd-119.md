# 巧用三化——塑造极品高防宠

巧用三化 —— 塑造极品高防宠

幻灵从开放幻化，进化，炼化后。许多爱宠之人把爱宠或进化，或幻化，或二者合一。但只有少数人，想到用炼化来提高宠物的某项成长（如防成长）。

以我的一幻[苦行龟](/pets/118)为例（我是散仙）

**宠物**：**5.8**苦行龟1只防成长为**3.2**

1. 5宝洞[露露鸟](/pets/11)1只

**物品**：极限甲1件

3000修行防衣3件

般若镇魂佩2个

过程：

A.**5.8**苦行龟满血升**301级**，用极限甲炼化一次，炼化后成长为**6.2**。装备般若镇魂佩

B.**5.5**成长露露鸟满血升到**101级**，练到**501级**用3000修行防衣炼化一次，进化为[觅雾鸠](/pets/16)，人升级到**801级**-兵解。觅雾鸠满血升到**101级**，练到**501级**用3000修行防衣炼化一次，进化为凤凰。凤凰满血升到**101级**，练到**301级**用3000修行防衣炼化一次，成长为**9.7**。 装备般若镇魂佩

苦行龟（主宠）和凤凰（副宠）幻化，得到成长为**10.5**的苦行龟防成长为**6.2**。

解释：

1. 主宠被副宠的五行生，幻化后成长比用别的宠做副宠高（副宠相同的成长的情况下）
2. 宠物和防衣练，只是提高防长，减低敏和攻。不加总成长(调整三围属性)_

**又附**：宠物和防衣练，如果防衣等级高的话，加1~2点属性是有的

1. 副宠选可进化的宠物，是为了提高副宠的成长
2. 练**101级**满血是为了保证成长不掉，如果你有时间的话就都满血吧
3. 宠物进化后不要急着练，人练到801再兵解，既可带忠又可赚钱。练宠最好还是散仙，可以兵解又不用过劫
4. 有人说10成长的乌龟是※※※※，可我不这样认为，高防的宠就是极品，至少宠不会比低防的极品宠死得快，[哈哈](/pets/41)

::: info 玩家提示
- PS：你有只高防的宠总比低防高攻，高敏的强吧
:::
