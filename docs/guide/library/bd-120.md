# 利用五行相生做高成长宠

利用五行相生做高成长宠

有许多网友和我联系，讨论利用五行相生做高成长宠的问题

主要有以下几个缺陷

1。材料的收集困难，天关[琳琳](/pets/131)成长要找只**6.5**+的不是难事，

但要找只**6.5**+的[旺旺](/pets/197)和露露，恐怕有些困难。

2。紋地龍 、琳琳可以四进，而旺旺和露露不能四进（现在已经

可以了旺旺可以用火任务进到[紫衣](/pets/209)，露露可以用养宠换龙）。

虽然3进宠利用五行相生幻化的成长和4进宠的成长相差不多，但

少了一进毕竟会少点成长，因此我把利用五行相生做高成长宠稍

微修正了一下，全部改为4进宠幻化，这样成长会高点。

1。宠物幻化时带减血装备，成长会稍微加一[点点](/pets/88)，

2。宠物应该在五行生它的地图进化和幻化

琳琳应该在金的地图进化和幻化

露露应该在土的地图进化和幻化

[纹地龙](/pets/272)应该在火的地图进化和幻化

旺旺应该在木的地图进化和幻化

3。有了爱宠[精灵](/pets/231)，可以99%的满血练宠

4。所有进化和幻化后的宠先带几点忠再去练级

5。做主宠的都要练到**1000级**，旺旺练到**800级**可以去做火任务加**200级**，

2幻旺旺做火任务做到紫衣

利用五行相生高成长 妖姬 [地藏兽](/pets/153) 做法

妖姬 做法

材料 最低成长要求

紋地龍 1个 （土） **5.8**+

天关旺旺1个 （火） **5.6**+

天关琳琳6个 （水） **5.9**+

做法：

紋地龍 + 琳琳>地藏=1幻紋地龍

琳 琳 + 琳琳>地藏=1幻琳琳A

旺 旺 + 琳琳>地藏=1幻旺旺

琳 琳 + 琳琳>地藏=1幻琳琳B

1幻紋地龍 + 1幻琳琳A>地藏=2幻紋地龍

1幻旺 旺 + 1幻琳琳B>地藏=2幻旺 旺

2幻紋地龍 + 2幻旺 旺>紫衣=3幻紋地龍

3幻紋地龍 进化[黄龙使](/pets/280) 飞 [白发妖姬](/pets/283)

地藏兽做法

**材料**：最低成长要求

琳琳4只， 水 6+

露露或嘟嘟1只 金 6+

纹地龙2只 土 **5.8**+

旺旺1只 火 **5.5**+

做法：

琳琳 + 琳琳>地藏=1幻琳琳A

琳琳 + 琳琳>地藏=1幻琳琳B

露露 + 纹地龙>妖姬=1幻露露

紋地龍 + 旺旺>紫衣=1幻紋地龍

1幻琳琳A + 1幻琳琳 B>地藏=2幻琳琳

1幻露露B + 1幻紋地龍>妖姬=2幻露露

2幻琳琳 + 2幻露露>凤凰>=3幻琳琳

3幻琳琳 进化绿衣 飞 地藏兽

其实练其他属性的宠也可以按这样做

只要把主宠换成你要的宠，2幻副宠换成生主宠的宠就可以了

要是五行任务都开放的话，用纯五行生克来幻化宠物（也就是我以前发表的文章）

成长肯定比蝴蝶做副宠来得好，就是材料难找。
