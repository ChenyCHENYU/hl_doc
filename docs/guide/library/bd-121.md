利用五行相生高成长 妖姬 [地藏兽](/pets/153) 做法

妖姬 做法

材料

紋地龍 1个 （土）

[旺旺](/pets/197)（天关小狗）3个 （火）

魯魯（天关猴子）3个 （木）

[琳琳](/pets/131)（天关蝴蝶）1个 （水）

做法：

紋地龍 + 旺旺>天狼=1幻紋地龍

旺 旺 + 魯魯>神猿=1幻旺旺A

旺 旺 + 魯魯>神猿=1幻旺旺B

魯 魯 + 琳琳>地藏 =1幻魯 魯

1幻紋地龍 + 1幻旺旺A>天狼=2幻紋地龍

1幻旺旺B + 1幻魯 魯>神猿=2幻旺 旺

2幻紋地龍 + 2幻旺 旺>天狼=3幻紋地龍

3幻紋地龍进化[黄龙使](/pets/280) 飞 [白发妖姬](/pets/283)

地藏兽做法

**材料**：琳琳1只，

露露3只

[纹地龙](/pets/272)3只

旺旺1只

做法：

琳琳 + 露露>凤凰=1幻琳琳

露露 + 纹地龙>黄龙使>妖姬 =1幻露露A

露露 + 纹地龙>黄龙使>妖姬 =1幻露露B

紋地龍 + 旺旺>天狼=1幻紋地龍

1幻琳琳 + 1幻露露A>凤凰=2幻琳琳

1幻露露B + 1幻紋地龍>黄龙使>妖姬 =2幻露露

2幻琳琳 + 2幻露露>凤凰=3幻琳琳

3幻3幻琳琳 进化绿衣 飞 地藏兽
