宠物底章专区

1. **30级**以下斗宠`~~~~~~~~~~~
2. 组队打，5个人的对最容易得章。而且队伍不要锁，队伍里的人进出的频繁得章的机会就大！ 想要就去组队挂机~！最好是**1200级**的宠，而且要保证你的宠在队伍里是最优秀的机会才大，不然只会给别人做嫁衣`~~~~~~~~~~~
3. 全※※运气啊`~~~~~~~~~~~
4. 极品满血升级到101后得章机会大，我的143[金蝎龙](/pets/21)就是满血升级到101后1个小时得了2勇猛。2果敢,`~~~~~~~~~~~
5. 打被自己宠克的怪物
6. 组队时你的宠最后一击打死怪物（2人组队时，你的人宠敏低于对方）
7. 骂一下GM和系统，可能`~~~~~~~~~~
