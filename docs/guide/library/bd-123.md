我的极品之路

练了那么久的宠物我得出了几相结论

(一)极品宠一级属性有以下几特征

1. 超防超敏或超攻如[金蝎龙](/pets/21)防一般是超过很可能是极品
2. 宠物一级属性与图鉴上的平均属性接近
3. 身份牌尾数为0时
4. 宠物换一级宠物如[纹地龙](/pets/272)换[苦行龟](/pets/118)成长高的去换可能是极品
5. 宠物刚得到时生命与最大生命是相同而不是差一点如不是的可能是极品

(二)如何练好极品宠物

1. 宠物已登陆过图鉴再练过级
2. 练宠经验尾数最好是49或99
3. **30级**以下可以去斗宠物多得几相勋闪电章
4. 尽量不要让宠物死如果死了先不要练级让人物带别的宠出征先升十级让宠物加工点忠诚再去练级这样成长才不会掉太多
5. 宠物别送来送去夫妻除外即使不掉顾也不会加
6. 宠物最好去打被自己无的怪物在生自己的地图练级

(三)满血升级大家都注意到可是满血升级有两种一种是我要升级了第二种是每次战斗以前都补满血有人说要那么麻烦吗举个例子我有两只**5.2**的苦行一只升级前满血升级一只升级后满血升级到了级前一只成长**5.3**另一只长成**5.7**到了生命超过一千以后满血升级有新的意义有人说是5%算是怎么练的反正我用第二种方法到了级我成长一般加**0.5**以上到级我成长加左右

1. 被打自己宠克的怪物,在生自己宠的地图打除生已和克已外的怪物.第一句话比较好理解第二句话的意思是打怪物的地点和宠成长有很大关系为什么有个很普遍的现象同是终极宠物金蝎龙比其它如[绿衣仙子](/pets/139)[黄龙使](/pets/280)天狼还高其原因何在因为练一级宠的水城外郊五行属土而土生金因此金系的宠物在这时能练出很高的成长最高到而仙子龙等其它属性的宠物能超过的已经是极品了

（三）极品中的极品

顾名思议极品中的极品有一个很大的特征就是**11级**成长与**101级**成长一般都差了一点在练到后来还会升不象普通的极品尽管**11级**成长是8到了级成长还不超过**8.5**可以说是级品中的※※※※了如何知道你的宠物是极品中的极品

1. 每次升级点数变化大如我**11级****5.8**成长的苦行龟到了**12级**加了8点**13级**加了7点**14级**加了6点最少也是5点到了**21级**时已经变为**6.13**练到级变成了**7.2**
2. 随便加入一个队伍马上就能得章我一个朋友的兔子就是这种类型成长时才升到级就得了两个攻章两个敏章真是羡慕死人了得章快的宠物就是极品
3. 越级打怪不费力气这是极品的基本条件
4. 没有极品中的极品那你去幻化一条吧
