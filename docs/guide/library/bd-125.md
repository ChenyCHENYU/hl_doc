幻灵捉宠秘籍

什么时候宠物不可以抓：

1. 当你还没有飞升的时候（还是凡人），高出你的级别**150级**以上的宠物是抓不到的。散仙以上的没有这个限制。
2. 当宠物的等级超过**1200级**别，就没有办法抓了。
3. 别人的宠物不可以抓。
4. 身上宠物已经满了，就暂时不可以抓更多的宠物了。

如何提高抓宠的成功率：

1. 你的等级尽量比怪物高（飞升后的仙魔更好）；
2. 你的敏捷尽量比怪物高；
3. 出征宠物的等级比怪物低（出征宠物1级最好）；
4. 出征宠物和要抓的怪物是五行属性被克最好其次五行属性相生，相同五行属性再次之，相克最不好（宠物克怪物）；
5. 出征宠物的忠诚越高越好；
6. 怪物身上的血越少越好；
7. 怪物中了魔法更容易被抓；
8. 进化过的宠物比一般的宠物难抓；
9. 1级的怪物，生长率越高越难抓；
10. 怪物已经登录到宠物图鉴的，容易抓。
