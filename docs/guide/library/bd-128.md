(二)加敏过程

**1**：降攻到3434,加一个极限鞋..--------------加敏900的剑

**2**：加攻到4178,加一个加敏2155的鞋子-------加敏987的剑

**3**：加攻到4155,（4091）加一个加敏1846的鞋子--------加敏1038的剑

**4**：加攻到4149,（4040）加一个加敏1617的鞋子---------加敏1073的剑

**5**：加攻到4009,（4005）加一个加敏1296的鞋子---------加敏1093的剑

**6**：加攻到4010,（3985）加一个加敏1266的鞋子----------加敏1112的剑

**7**：加攻到3979,（3966）加一个加敏1129的鞋子-----------加敏1125的剑

**8**：加攻到4002,（3953）加一个加敏959的鞋子------------加敏到1135

前面的数据是用半成品武器加攻法,这个比较省时方便,但是有些朋友可能一时

明白不了.所以如果是直接用毒炼上去的请参照括号里的数据.
