内右配

丹凤钗(飞功德时的任务物品)

**1**：减敏过程

第一步,加血到4017,加第一个极限鞋.===>减敏133.

第二步,加血到5010,加一个加敏2096的半成品鞋子.===>减敏167.

第三步,加第一个极限血饰.加第二个极限鞋子.====>减敏218.

第四步,加第二个极限血饰.加一个加敏1812的半成品鞋子.===>减敏233.

第五步,加第三个极限血饰.加一个加敏1010左右的半成品鞋子.===>减敏235.

砸极限血..直到不能加血..

砸极限血到极限7065

\+465内的极品丹凤数据

加内

第一步,加一个加内3520左右的半成品内带.===>加内405.

第二步,加血到4914,加一个1989左右的内带,====>加内441.

第三步,加血到4878,加一个1236左右的内带.====>加内465.

砸极限血到极限 6600

最后砸极限衣服++防御到 220
