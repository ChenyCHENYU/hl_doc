# 800级+++300攻击的宠物装备

<TopicHeader cat="玩家文库 · 宠物养成" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**800级**+++300攻击的宠物装备：

第70关兄弟关，如果队长出征宠物成长率超过50[需要满忠诚满血]，和守关npc说话，则进入隐藏关，并且如果宠物满足条件，完成地图上npc要求的简单任务：抓 1 级的[强盗](/pets/101)，就可以换到20000修行可装备的＋++300攻的身饰“云淡风清瓶”奖励。而且无论任务完成与否，都可以得到一颗锻造用的水晶。

做法：

**材料**：20000修行可装备的＋++300攻的身饰“云淡风清瓶”、3条极限内带、4个极限血佩

**炼化数据**：血 内 攻 备注

\++3345内 300 直接加修

\---300 ++3345内 300 +极限血

\---300 ++5193内 300 +极限内

\---459 ++5193内 300 +极限血

\---459 ++5559内 300 +极限内

\---555 ++5559内 300 +极限血佩

\---555 ++5655内 300 +极限内

\---564 ++5655内 300 +极限血佩

**最后降修**：攻内瓶子12点，血药 11点，最后是 **800 级** ---564血 +++300攻击。 就可以给爱宠带上了

**幻化效果**：幻化看额外增加后代+++**0.28**成长。
