# 600级+++270防御的宠物装备

<TopicHeader cat="玩家文库 · 宠物养成" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**600级** +++270 防御 的 宠物装备：

**材料**：++270防御的项链[要求是++0敏捷的] 、5个极限鞋、4个极限血佩

**做法**：[ 270 项链 5 点，极限血 6 点，极限鞋 3 点]

**炼化数据**：敏 血 防御 备注

\+++ 0敏 ++3807血 270 直接加修

\--- 84敏 ++3807血 270 +极限鞋

\--- 84敏 ++5442血 270 +极限血

\---134敏 ++5442血 270 +极限鞋

\---134敏 ++5592血 270 +极限血

\---184敏 ++5592血 270 +极限鞋

\---184敏 ++5742血 270 +极限血

\---191敏 ++5742血 270 +极限鞋

\---191敏 ++5763血 270 +极限血

\---192敏 ++5763血 270 +极限鞋

**最后降修**：270项链 1 点，血药 11点，最后是 **600 级** ---192敏 +++270防御。 就可以给爱宠带上了，也可以装备在人物的右配
