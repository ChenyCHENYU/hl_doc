# 0防PK变态宠

<TopicHeader cat="玩家文库 · 宠物养成" src="奇幻侠客的葵花宝典.exe" />

> 来源：《新编幻灵宝典》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

怎么样炼出极品 0 防PK变态宠

**1**：先选一只你最喜欢的宠，一定要是 0 幻的，到满级炼到最低防。

**2**：炼化宠的方法：金宠 12 点，木 1 点，水 3 点，火 9 点，土 6 点，极限 3168武器 9点或 8 点，极限 3168鞋 3 点或 4 点，宠物++武器++鞋一起炼==最低防的状态。

**3**：再到山城装备店买 +120攻击的瓶，或者 +100攻击+150敏的戒指，或者+240敏的戒指给主宠带，带上这些装备能使到后代的防一出生就是最低防的状态。不带这些装备不行，到 3 幻降不到 0 防~特别注意~！~

**4**：副宠不用改三围，因为副宠的三围不能影响后代的三围分配，副宠带上减 666 血的装备加后代的成长。

**5**：主副宠带着装备幻化。得到 1 幻主宠，练满级，用极限减防。再按照 0 幻的做法幻化。

**6**：得到 2 幻主宠，练满级，用极限减防。再按照 0 幻的做法幻化。

**7**：得到 3 幻主宠，练满级，用极限减防。这样这只宠绝对是~[高攻击~高敏捷~ 0 防御]~的极品变态PK宠~！~。
