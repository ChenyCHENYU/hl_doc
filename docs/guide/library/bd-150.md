# 防鞋子

1303防鞋和1304防鞋修改1305防鞋的具体数据

我也好几次遇到过~防鞋1303防和1304防~就是到不了1305防~下面是我自己改的时候弄的数据~可能有点麻烦,仅供参考

1303防的鞋修改成1305防的数据：

1. 首先把防鞋的敏用毒药练到极限~
2. 1303防的敏鞋最高是3860敏
3. 加一个2648防的衣服~
4. 把防御一定要降到1251防~这个时候鞋的敏是4171敏~
5. 然后再加个极限鞋子~到5102敏 ←此步要保证敏在4900敏以上
6. 最后加个极限衣服就可以到1305防了~

这是我试了2次~拿了2双鞋子实验过~

没有失误~都成功到达1305防
