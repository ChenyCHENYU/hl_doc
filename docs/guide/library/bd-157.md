# 木属性任务

<TopicHeader cat="玩家文库 · 宠物养成" src="《幻灵游侠浏览器》.exe" />

> 来源：《幻灵资料查询》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

恒河星宿变化出奇、层出不穷，一种神秘的力量创造了幻灵世界。

但是很少人对此有所了解，将毕生心血投入于研究的青灵老人，在花费了一生精力之后，终于对此力量有了一些了解，常常在名剑山庄正院的青灵老人（58，34）对好学的人是很热心地讲解构成幻灵世界的神秘力量的情况，以及由此神秘力量一分为五繁衍出的各系幻灵兽的故事。

了解这些情况以后，可以知道，如果想追寻那五系的力量，则需要通过各系各个宠物的考验。

绿洲东郊的“[酷毙象](/pets/56)”（30，66）最近正沉浸在愤怒中，原来青之绿洲来了一群盗猎者，他们为了得到象牙竟然大肆屠杀憨厚的大象！玩家如果能为绿洲的象族解决这个心头大患，“酷毙象”是不会亏待他的。

在教训那群盗猎者之前，“酷毙象”会给玩家一个“青木之眼”——带上它，你能轻易看穿那群恶棍的伪装。很快，玩家就在青之绿洲的一个帐篷内找到了盗猎者（59，97），还等什么？

打败他后，带着他交出的象牙，回去告诉“酷毙象”一声，珍贵无比的“神木令1”就到手了。

有了“神木令1”玩家就可以找榕盘谷的“[跷跷鼠](/pets/62)”（36，19）开始新的历练了。这个“跷跷鼠”不简单，它可握有获得木属性力量的关键宝物——“神木令2”。不过，想获得“神木令2”，玩家必须证明自己的实力。

“跷跷鼠”会给玩家一封“考试介绍信”，带着它，找到天关20层的“[阿斗](/pets/260)”（24，13）接受考验，赢得战斗后，“阿斗”会给玩家一封“过关证明”。带着证明，去向“跷跷鼠”领取“神木令2”吧！

最近，沙漠地区的雨水奇缺，许多植物已经奄奄一息了！能拯救植物的英雄，自然有资格得到木属性的力量。青风原的“[鲁鲁](/pets/71)”（68，39）告诉玩家，一个叫“苦根”的已经到“青之绿洲”想办法了，请玩家带着它开的“介绍信”去帮帮苦根。

原来，“青之绿洲”的苦根（44，06）已经找到了充沛的水源，他让玩家到断魂崖上找百醉上人（31，08）要一个紫金葫芦来——这个葫芦似乎可以装上无穷无尽的酒和水，有了它就有办法将那些水运到沙漠了。

玩家将紫金葫芦交给“苦根”后，得到一片“灵之绿叶”，再将“灵之绿叶”交给“鲁鲁”，“神木令3”就到手啦！

不能善用力量的人没有资格获得木之力量。赏月谷的“[迷你象](/pets/58)”（38，58）正准备测验玩家的品行呢！只要答对它提出的问题，玩家就能获得“神木令4”了。

羁马谷的“[弹簧鼠](/pets/63)”（47，47）遇到了一件烦心事，许多年前，他曾将一件叫“雪莲花”的宝贝借给了西雪岭的冰雪老人。但是，许多年过去了，总不见冰雪老人归还宝物。

玩家如果接受了“弹簧鼠”的委托，那就带着它给的“借贷契约书”走一趟吧。到了西雪岭，玩家很快就找到了冰雪老人（39，32），原来冰雪老人这么做也是有苦衷的——没有雪莲花他就无法生存下去。

他让玩家将一件不亚于雪莲花的宝物——“聚气瓶”带给“弹簧鼠”，就当是交换。相信“弹簧鼠”见到“聚气瓶”后会献上“神木令5”的。

另外，有一点要特别注意，玩家千万不要去强行夺走冰雪老人的“雪莲花”，因为“弹簧鼠”可不认同“得一物伤一人”的做法。

悬台的“[衰呆象](/pets/57)”（47,54）最近忧心忡忡，原来象族里有些年轻的象不听教导，私自跑到遥远的镜雪原去了，“衰呆象”请玩家带着一件信物——“象牙饰物”找到出走的大象，劝它们回归象群。

玩家找到镜雪原的“倔衰象”（41,14）后，必须以实力告诉它:“外面的世界很危险！”只要打败“倔衰象”，它就会将一个“牙魂”交给玩家，并保证尽快归队。玩家带着牙魂，重新找到悬台的“衰呆象”，就可以得到“神木令6”啦！

“神木令7”在踏雪原的“[淘淘](/pets/72)”（50，23）手中，不过玩家如果想得到这个宝贝，必须为淘淘解决一道难题：前阵子，一个[强盗](/pets/101)掳走了猴族的小族长，并声称猴族要交出“猴王丹”，他才会释放人质！

“猴王丹”是猴族的宝物，自然不能这么轻易地交给敌人，所以淘淘想请玩家带上一枚假猴王丹，去救它的小族长。根据“淘淘”的提示，玩家很快就在羊肠道找到了“强盗吴”（66，41）。

别看这强盗人品低劣，但眼光确实不错，他一眼就看穿了玩家手中的是个冒牌货，并且马上就要动武！玩家只要打败他，他就会乖乖地交出一张地图——上面描绘着猴族小族长的所在位置。

将地图交给踏雪原的“淘淘”，“淘淘”会将“神木令7”作为报酬的！

西雪岭的“[白毛象](/pets/60)”（26，32）从小就和两个弟弟相依为命，但是许多年前他最小的那个弟弟突然神秘失踪了！经过多年的查访，也许雪融谷的二弟“[懒懒象](/pets/61)”（40，67）已经有线索了吧。

“白毛象”想请玩家带着“象兄弟的信物”到雪融谷找“懒懒象”问一问。玩家找到“懒懒象”后，一打听，的确有重大的收获：听说瑞天雪城的城主在多年前抓了一只粉红色的大象，从各种特征上来看，都像是失踪的象弟弟！

玩家来到瑞天雪城，果然找到了失踪多年的“[红粉象](/pets/59)”（36，41）。不过，周围还有强大的幻兽守卫看着呢，想救出“红粉象”还要看玩家的本事！

打败幻兽守卫后，“红粉象”将一个项圈交给了玩家，请玩家先去通知西雪岭的“白毛象”，而它自己要留在这找城主的晦气呢！看到项圈后，“白毛象”自然对玩家感激不尽，玩家也就可以轻轻松松地得到“神木令8”啦！

“神木令9”就在翔云台“[橡皮鼠](/pets/64)”（53，31）手里，玩家想得到它照例要经过一番考验！“橡皮鼠”告诉玩家，剑池谷中有一柄神剑，他对自己的主人十分挑剔，自从百年前被上一任主人封印在地下后，就再也没有遇上合适的人。

如果玩家能得到这柄神剑，“橡皮鼠”一定会将“神木令”献出来的。玩家来到剑池谷后，果然找到了这柄神剑——“剑魂”（32，33）！不过，要想降服它，玩家必须打开宝剑上的封印——那意味着一场大战。

战斗胜利后，剑魂告诉玩家：“这么多年来，你是第一个解开我封印的人，但是实力还和我原来主人相去甚远……”不过，没关系，剑魂会将一柄仅次于自己的宝剑——“龙腾剑”送给玩家，“龙腾剑”就是向“橡皮鼠”索取“神木令9”的凭证！

黄泥岗的“[截拳道](/pets/65)”（24,14）有个心愿，它希望和两个兄弟和解。原来它们三兄弟从小喜爱武道，后来由于武学观念上的分歧，终于分道扬镳。要想实现它的心愿，玩家必须先找到在武当后院门修炼的“[空手道](/pets/66)”（10,18）。

“空手道”告诉玩家，它很久以前就想和解了，只是面子上下不来，希望与玩家印证一下武学观点，如果两人心中所想相同，那就是天意，它也好有个台阶下。

玩家答对了“空手道”的问题后，“空手道”会将一条“空手道腰带”交给玩家，玩家带着它，就可以去找第三个兄弟——英雄冢的“[跆拳道](/pets/67)”（30,48）了。

照例，只要答对“跆拳道”的一个问题，玩家就能得到“跆拳道腰带”，看到腰带，黄泥岗的“截拳道”就一定会将“神木令10”双手奉上的！

冰封地狱的“[紫蹄先生](/pets/68)”（38，37）想报答一个人类朋友的恩情，那位朋友年轻时神勇无比，救过“紫蹄先生”很多次。但由于生前做错了些事，他死后不能轮回，现在正在聋耳地狱中受苦，“紫蹄先生”想请玩家去帮帮他。

玩家带着“紫蹄先生”给的“介绍信”，来到聋耳地狱，找到了“紫蹄先生”的朋友——“幽魂”（35，22）。幽魂告诉玩家，自己自作自受，怪不得别人，但却放心不下女儿“月娘”，他想请玩家将一份藏宝图交给月娘，好让她取出宝物使用。

玩家来到凝露山城，将藏宝图交给“月娘”（85，66）后，月娘会将一封“感谢信”交与玩家，玩家带着感谢信再次找到“紫蹄先生”，就可以领取“神木令11”啦！

坚定的心，执着的信念是御使力量的最大动力，想要得到“神木令12”，玩家必须通过地牢“[蒙蒙](/pets/73)”（62，48）的考验。

考验的过程十分简单，拿着“蒙蒙”开出的“考验之书”，前往天关40层，找“[嘟嘟鸟](/pets/13)”（24，13）开始过关战斗，胜利后记得向它索要“过关证明”，就可以了！见到你的“过关证明”，“蒙蒙”会将“神木令12”交给你的。

宠物乐园4楼的“[蓝蹄先生](/pets/69)”（80，53）听说晚枫林出了一件怪事，现在已经有一位人类调查员前去调查了，它请你带上“委托调查书”，也去看看。

玩家来到晚枫林后，找到了“调查员”（18，37）才弄明白，原来最近晚枫林一带的木属性力量急剧流失，植物的生存已经受到了威胁，“调查员”怀疑是孤独亭中有人用卑劣的法术抽取了木属性力量，请玩家带着“力量探测器”前去一探究竟。

到了孤独亭后，玩家果然发现是一个叫“狂风妖道”（48，44）的家伙在干这伤天害理的事！玩家必须打败“狂风妖道”，逼他交出储藏木属性力量的“力量封印”，才能回去向“紫蹄先生”交差。

当然，看到“力量封印”后，“紫蹄先生”一定会用“神木令13”报答玩家的！

炊烟谷的“[黑蹄先生](/pets/70)”（45，30）的麻烦事刚开始。它发现虽然自己有了“力量封印”，但这个封印太强大，它无法释放被夺走的木属性力量！玩家只好带上这个“难解的力量封印”再到孤独亭走一趟啦！

到了孤独亭玩家很快又找到了上回作恶的那个“狂风妖道”（48，44），“狂风妖道”连连诉苦，说自己被玩家打败并废去武功后，现在对这件事也无能为力了。

不过，他还是识相地给玩家开出了一封“告师兄书”，玩家可以带上它，到武当前山找妖道的师兄“云雾真人”（35，25）帮忙。云雾真人可是一个得道高人，他三下两除二的就将“难解的力量封印”变成了“易解的封印”。

将“易解的封印”交给“黑蹄先生”，玩家就可以得到“神木令14”了！

随着修行的深入，翔云台的“[刚雷狒](/pets/74)”（65，56）对修行的意义越来越[迷茫](/pets/192)，它想请玩家替它向两位兄弟请教一番。

玩家首先要带着“刚雷狒”给的问卷A找到华山腰道的“[吼雷狒](/pets/75)”（56,13），“吼雷狒”虽然勉强说出了自己的答案，但是它显然也不自信，他让玩家带着问卷B，前往武当前山，问问另一个兄弟“[奔雷狒](/pets/76)”（64，65）。

同样，奔雷狒对自己的回答也没有信心，他给了玩家一份“疑难问题”，请玩家前往戒律院，请教少林寺的得道高僧“空想僧”（10，15）。“空想僧”非同小可，他三言两语就解开了这个大难题，玩家也得到了一份答案。

将答案交给“刚雷狒”，就能得到“神木令15”啦！

守望林场原本是个伐木基地，后来因破坏森林太过，在“[中岳神猿](/pets/77)”的干涉下，那里的伐木工终于停工了，但是，这段时间这些家伙竟然又开始破坏森林！

剑池谷的“中岳神猿”（12,34）请玩家带一份“最后通牒”给那里的伐木工，一定要制止他们的行为。玩家到了守望林场后，果然找到了伐木工（25，18），他们居然高价购买了许多厉害的幻兽，想跟玩家动武。

不过，只要玩家能取得胜利，伐木工就会乖乖写下“停工声明”，带着“停工声明”找“中岳神猿”，就可以得到“神木令16”了。

记得上回追寻木属性力量的战斗吗？在玩家的帮助下，那些力量虽然已经回归森林，但是却变得异常紊乱，再这样下去，恐怕会给森林带来极大的破坏。梦佛窟的“[西岳神猿](/pets/78)”（27,73）正为这件事烦恼呢。

它告诉玩家，要解决这个问题，必须取得武当张三丰真人亲手制作的擎天灵符才行，它请玩家带上一封求助信，到武当前山走一趟。

到了武当前山，玩家见到了张三丰真人（95，57），但是想取得灵符，还必须通过张真人的考验才行——能力不足的人强行使用擎天灵符会反受其害的。取得战斗胜利后，玩家就可以得到擎天灵符了。

但是，“西岳神猿”收到灵符后却面露为难之色——幻兽无法使用灵符，必须请玩家帮忙，并且要耗费掉玩家全身的内力。不过，只要玩家帮了它这个忙，“神木令17”就归玩家了。

上回，在玩家的帮助下，晚枫林的植物都得救了，但是经过这场折腾，它们终究元气大伤。

吓死人洞窟1层的[东岳神猿](/pets/79)（48，20）请玩家带着一封“介绍信”到天空之城圣宴室找 “可口宝宝”（16，14）讨一瓶“生命之水”来挽救这些植物。

然而，当“可口宝宝”听说是“东岳神猿”要东西，顿时勃然大怒，说“东岳神猿”还欠他不少宝物没还，并扬言，玩家想得到“生命之水”必须打败他养的幻兽。这孩子可是说话算话的，玩家取得战斗胜利后，他果然给了玩家一瓶“生命之水”。

带着生命之水，去向“东岳神猿”领取“神木令18”吧。

得到“神木令18”后，玩家就可以到名剑山庄正院找青灵老人（58，34）了。青灵老人会出题考察玩家在追寻木属性过程中的心得，根据回答的不同，玩家会得到“通灵宝玉”或“冥灵宝玉”，从而进入“通灵剧情”，或“冥灵剧情”。

通灵剧情：

玩家带着“通灵宝玉”，可以到囚塔二层见一位叫“[至尊草](/pets/80)”（16，6）的魔神。在千年前的一次神魔战争中他被群神合力消灭，元神也被分成两个部分封印在塔中。

他告诉玩家，他正是掌握着木属性力量的魔神，但现在元神被封闭太久，力量大减，就是想给玩家木属性力量也无能为力，他给了玩家一根“金箍棒”作为信物，请玩家去仙客厅找轩辕天（16，15）要一颗“聚元珠”，以便恢复元气。

而仙客厅的轩辕天对囚禁“至尊草”的事也有些内疚，他想给玩家“聚元珠”，但“聚元珠”一旦暴露在空气中就会失去功效，除非玩家能到少林寺找来当年佛祖留下的玉净瓶，才能保“聚元珠”无恙。

玩家带着轩辕天给的信物“如意令”，到方丈室找到了少林寺的方丈（19，14），答对方丈的两个问题后，就可以取得玉净瓶了。

接下来，将玉净瓶交给轩辕天，取得“聚元珠”，带着“聚元珠”来见“至尊草”，就可以得到大奖——仙木令一枚，**300级**的“升级药”一份！

冥灵剧情：

玩家带着“冥灵宝玉”，可以到囚塔一层见一位叫“[至尊林](/pets/81)”（16，6）的魔神。在千年前的一次神魔战争中他被群神合力消灭，元神也被分成两个部分封印在塔中。

他告诉玩家，他正是掌握着木属性力量的魔神，但现在元神被封闭太久，力量大减，就是想给玩家木属性力量也无能为力，他给了玩家一根“金箍棒”作为信物，请玩家去仙客厅找轩辕天（16，15）要一颗“聚元珠”，以便恢复元气。

而仙客厅的轩辕天对囚禁“至尊林”的事也有些内疚，他想给玩家“聚元珠”，但“聚元珠”一旦暴露在空气中就会失去功效，除非玩家能到少林寺找来当年佛祖留下的玉净瓶，才能保“聚元珠”无恙。

玩家带着轩辕天给的信物“如意令”，到方丈室找到了少林寺的方丈（19，14），答对方丈的两个问题后，就可以取得玉净瓶了。接下来，将玉净瓶交给轩辕天，取得“聚元珠”，带着“聚元珠”交给“至尊林”。

此时，如果玩家满足要求，也就是对木属性了解18只或以上，并且携带着**800级**以上且忠诚达到100的东岳神猿，就可以将东岳神猿进化成木系超级幻灵兽，并得到仙木令一枚！
