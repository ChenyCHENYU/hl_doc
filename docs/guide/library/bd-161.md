新手任务！

开放3个5级以下玩家做的新手任务，注意哦其中第一个小任务必须是注册新人才能做的，NPC为出生点飘渺峰的仙祖元圣，另外两个NPC分别为水城隐者和护士MM

**任务条件**：玩家等级低于5级

任务流程：

与仙祖元圣对话，可以进入战斗，打完一只一级[阿弟达斯](/pets/211)，装备新手鞋子和衣服后，出新生地

与护士MM对话，送一封信给树城[精灵](/pets/231)，得到止血草拿回给护士MM，升一级并得200两

与水城隐士对话，先用得来的200两买一武器和头饰(+血)，装备起来，隐士会给你一块皮革要求你再打一块，水外郊战斗得到后回来与隐士对话，得到350两
