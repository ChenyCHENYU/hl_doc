[最新消息]关于3。0的飞升以及对宠物的要求（即将开放）

3。0中，凡人飞升很快进入测试。

简单说明如下

1. 凡人**100级**，在完成一个小任务后，可以飞升到散仙，如果练到凡人**120级**，在完成另外的任务后，可以直接选择飞升成地仙或者夜叉。如果飞升散仙，再练到**100级**以上完成相应的任务，同样可以向上飞升成地仙或者夜叉。
2. 飞升成散仙系统送一级的[瞬地](/pets/99)龙（土系），飞升成地仙和夜叉，系统送1级的[嘟嘟鸟](/pets/13)（金系）
3. 飞升后，精神力按照当前点数一定百分比保留成永久精神力，这个比例是和飞升次数相关的，第一次保留10％的精神点数成为永久点数，然后每5次递减1％，在第46次飞升后一直按照1％的点数保留。

1. 每次飞升，玩家出征宠物会同时飞升成为1级，并且代数＋1，而且按照代数相应的增加成长，0代宠物增加1，1代宠物增加2，2代宠物增加3。如果出征宠物是3幻宠物，将不允许飞升。
2. 散仙以上等级的玩家，1级就可以装备**120级**的装备，但是不能发挥装备的全部属性，具体的百分比见附图。玩家装备没有发挥全部属性的装备，将在人物属性界面，看到攻击、防御、敏捷等数值使用黄色显示。

官方发布幻灵**3.0**人物飞升对出征宠物的要求

1. 飞升散仙不限制宠物类型，除3幻的宠物外，**忠诚100**的都可以，等级需要80以上，含80。
2. 直接飞地仙和夜叉的玩家，宠物需要**忠诚100**，等级100以上的，含100（同样不限制宠物类型）
3. 系统送的[苦行龟](/pets/118)为出生宠物，该宠物不会通过其他方法获得了，以后会先出苦行龟相关任务，希望大家不要把乌龟丢弃。
4. 飞升时的出征宠物，在飞升后宠物代数会加1，也就是给玩家一个通过飞升幻化宠物的机会。

因此，没有要求说，要飞升就一定需要苦行龟到**100级**，主要有**忠诚100**，级别80或者100的任何宠物都可以！
