# 7月10~9月20即将开放的任务表

<TopicHeader cat="玩家文库 · 宠物养成" src="《幻灵游侠浏览器》.exe" />

> 来源：《幻灵资料查询》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

7月10日 地仙、夜叉飞升任务，过劫任务 凡人**120级**宠物**120级**直飞地仙、夜叉，散仙**100级**宠物**100级**飞地仙、夜叉

7月15日 雪狼湖任务 获得呼啸符石，帮助玩家回到城市

7月20日 通天点将台任务 单人天关，每2小时开放一次，有铁矿、贝壳、皮革，冰玉丹、不同价格装备，银质捕捉卡、金质捕捉卡、[小叮咚](/pets/266)，[小精卫](/pets/10)、[丸子鱼](/pets/142)、[小猪芬特](/pets/310)、[工兵蚁](/pets/270)，[小丁当](/pets/264)，[金毛狮王](/pets/194)、[蛋蛋鱼](/pets/141)、灵婴虎图鉴卡奖励

7月25日 飞天仙、阿修罗任务 地仙**100级**带**100级**[绿衣仙子](/pets/139)，夜叉**100级**带**100级**[黄龙使](/pets/280)，可以飞升，飞升后宠物完成超级进化

7月30日 仙魔互转任务，兵解任务 互转后玩家的仙魔层次下降一层，给玩家另外一次超级进化宠物的机会，兵解按照等级给玩家奖励，**100级**兵解给一颗内丹，**120级**兵解给2颗内丹，内丹使用后可以给玩家等级升1级

8月1日 飞大罗金仙、魔神任务，锻造配药升级任务 按照五行飞升，分别需要五行宠物的指定图鉴卡一张，锻造配药升5级任务，需要进五行炉中找鬼匠破风完成任务

8月5日 英雄冢任务 玩家有机会获得珍惜图鉴卡，[小猪比特](/pets/308)、婴灵虎、骷髅小兵，有机会给玩家的宠物直接幻化，类似飞升，有机会获得300秒战斗经验3倍的物品（这个和周末的双倍经验不叠加）

8月10日 火属性任务 获得火属性力量，给玩家的火属性宠物一次超级进化机会，可进行两种超级进化选择

8月15日 水属性任务 获得水属性力量，给玩家的水属性宠物一次超级进化机会，可进行两种超级进化选择

8月20日 木属性任务，配药锻造升5，6，7，8级任务 获得木属性力量，给玩家的木属性宠物一次超级进化机会，或者获得一个孕育符石，给玩家满足超级进化的宠物一个进化机会，锻造配药升级5，6，7，8级任务

8月25日 土属性任务 获得土属性力量，给玩家的土属性宠物一次超级进化机会，可进行两种超级进化选择

8月30日 金属性任务 获得金属性力量，给玩家的金属性宠物一次超级进化机会，可进行两种超级进化选择

9月1日 五转任务，投胎任务，锻造配药升9级任务 完成任何一个属性任务，按照职业通过相应考验飞升。仙可飞的职业为锻造、养宠、武功，魔可飞职业为pk、养宠、精神力。投胎必须五转之后**100级**，可以重新回到凡人修练。需要找到神匠幻灭，接锻造配药升9级任务

9月20日 六转任务，锻造配药升**10级**任务 完成五属性任务，集齐五行力量，通过相应考验飞升。锻造配药升**10级**任务
