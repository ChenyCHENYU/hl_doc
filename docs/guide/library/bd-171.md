# 太乙珠煅造+233防右饰的全部数据(新数据)

> 来源：《幻灵资料查询》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

(二)太乙珠(大罗飞五转时的任务物品)

**1**：减敏过程

第一步,加血到3985,加第一个极限鞋.====>减敏132.

第二步.加血到4948,加一个加敏2050左右的半成品鞋子,====>减敏164.

第三步,加第一个极限血饰,然后再加第二个极限鞋子.====>减敏215.

第四步,加第二个极限血饰,再加一个加敏1900左右敏的半成品鞋子.===>减敏231

第五步,加第三个极限血饰,再加一个加敏1000左右敏的半成品鞋子.===>减敏233.

2:加防

同理于长命锁,把太乙珠的血加极限6994,然后连续砸上6个极限衣就OK了.加防233.

3:加内

第一步,加一个加内3600左右的半成品内带,===>加内399.

第二步,加血到4852,加一个加内1650左右的半成品内带,===>加内450.

第三步,加血到4801,加一个加内1100左右的半成品内带,===>加内456.
