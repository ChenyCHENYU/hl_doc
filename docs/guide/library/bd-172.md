# 长命锁+227防右佩的数据(省材版）

长命锁减敏改进版,加内原创

人鱼之泪(坎)

**1**：减敏过程

第一步,加血到3843,加第一个极限鞋,=====>减敏128,

第二步,加血到4779,加一个加敏2060的鞋子,====>减敏159.

第三步,加第一个极限血饰,再加第二个极限鞋,====>减敏210.

第四步,加第二个极限血饰,加一个1800左右的敏鞋子,===>减敏226.

第五步,加第三个极限血饰,加一个950左右敏的鞋子,====>减敏227.

用掉了2个极限鞋子和3个极限血,3个半成品的鞋子.

PK人的话,到这一步就可以了.

2:加防

右饰属土,土生金,如果想把防加到极限,把长命锁加血到极限6828.

然后连续砸上5个极限衣,加防极限是227.

最后用最便宜的剑在把-50攻清掉 （剑9点、佩6点）

3:加内

第一步,加一个加内3600左右的半成品内带,====>加内381.

第二步,加血到4701,然后加一个1650左右的半成品内带,====>加内432.

第三步,加血到4650,然后加一个1100左右的半成品内带,====>加内441.
