# -减血666幻装1

<TopicHeader cat="玩家文库 · 综合其他" src="《幻灵游侠浏览器》.exe" />

> 来源：《幻灵资料查询》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

方法1

需要材料，四个极限内带，三个极限血，两个半极限血（2500左右和900左右）

第一步，极限内带7点，极限血6点，主练7点（得到减300血加内4251身饰）

第二步，减血身饰7点，极限内带2点，主练7点(得到减血300加内6096身饰)

第三步，减血身饰7点，极限血6点，主练7点(得到减血459加内6096身饰)

第四步，减血身饰7点，极限血6点，主练7点（得到减血609加内6096身饰）

第五步，减血身饰7点，极限内带2点，主练7点（得到减血609加内6609身饰）

第六步，减血身饰7点，半极限血2500的6点，主练7点，（得到减血660加内6609身饰）

第七步，减血身饰7点，极限内带2点，主练7点（得到减血660加内6660身饰）

第八步，减血身饰7点，半极限血900的6点，主练7点（得到减血666加内6660身饰）
