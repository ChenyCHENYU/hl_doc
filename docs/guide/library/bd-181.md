# 300级230防御10敏捷盘龙尊数据.

<TopicHeader cat="玩家文库 · 锻造-其他" src="《幻灵游侠浏览器》.exe" />

> 来源：《幻灵资料查询》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

盘龙尊

水城买到最便宜草鞋×1

水城买到最便宜头饰×1

极限头饰（血佩）×4

极限身饰（内带）×3

极限鞋子若干

**2**：制作步骤

①盘龙尊6点，水城最便宜鞋子3点 此步锻造降其敏捷为0

②盘龙尊6点，水城最便宜头饰5点 此步锻造降其生命为0

③给盘龙尊加内至3339左右、加第1个极限头饰，得到-333血 +3339内

**位置**：盘龙尊7点、极限头饰5点

④使用第1个极限身饰给盘龙尊加内，得到-333血 +5268内

**位置**：盘龙尊7点、极限身饰1点

⑤使用第2个极限头饰给盘龙尊减血，得到-501血 +5268内

**位置**：盘龙尊7点、极限头饰5点

⑥使用第2个极限身饰给盘龙尊加内，得到-501血 +5811内

**位置**：盘龙尊7点、极限身饰1点

⑦使用第3个极限头饰给盘龙尊减血，得到-579血 +5811内 <此步可不用极限头饰>

**位置**：盘龙尊7点、极限头饰5点

⑧使用第3个极限身饰给盘龙尊加内，得到-579血 +5889内

**位置**：盘龙尊7点、极限身饰1点

⑨使用第4个极限头饰给盘龙尊减血，得到-588血 +5889内 <此步可不用极限头饰>

**位置**：盘龙尊7点、极限头饰5点

**3**：这时候把盘龙的内力清除到 0 [盘龙 12 点，血药 11 点，循环几次就可以了]

自己用 HLHL 挂出一个 1 万多修的半极限鞋

清完内力的盘龙 1 点位置， 1 万多修的半极限鞋放 3 点位置

得到 ++230 防御 ++10 敏捷

这时候再一次把盘龙的内力清除到 0 [盘龙 12 点，血药 11 点，循环几次就可以了]

得到 **300 级**++230 防御 ++10 敏捷 的 宠物装备。。。。。。
