宠物锻造

保1升1降1法：

\+攻+防的水城最便宜衣服拿紫水晶练下，再练宠物，宠物攻不变，敏降防升！

\+攻+防的水城最便宜武器拿紫水晶练下，再练宠物，宠物防不变，敏降攻升！

升2降1法：

\+攻武器、+防衣服一起练宠，宠物敏降攻防都升！

1-**70级**H端或原始端正常练，可用点点多功能辅助V**0.5**里的群杀（攻击次数小于等于怪物数量+1才可以群秒）。

**70级**宠物锻造下，下线，Z端进，开点点多功能辅助V**0.5**

点点多功能辅助V**0.5**设置自动购买消淤散、人宠补血，时间200。

快速闯天关到需要的关数，循环天关里面勾选持续战斗画面，人防宠攻。
