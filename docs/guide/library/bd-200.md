# 进化、幻化

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典.exe" />

> 来源：《幻灵宝典2011》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

一、进化：

1. 宠物多少级进化才好，考虑勋章与满血奖励的话，推荐1200-1250进化。一般认为，500-**800级**进化很难得到勋章，800-**1000级**进化得到一个，1000-1200进化得到2个，1200以上得到三个。
2. 在哪里进化好呢，根据天晴提供的资料，个人认为，为保证不产生变异，应去与宠物属性相生的地图进化，而要想增加变异几率，有两种方法，一是去相克地图，理论上比其他地图容易变异，另一种是去兄弟天关70，变异机率又会提高许多。（地图属性见附录）
3. 进化时的装备：进化的时候，装备不会被系统收走，所以，考虑到进化后容易练些，一般是戴+150防御的手镯或者+120防120敏的环。
4. 什么样的进化是正常的呢，一般玩家认同这个公式：进化前成长/10+（进化后标准成长-进化前标准成长）+满血奖励，普遍认为是**0.5**。
5. 注意事项：偶听到一种说法，即进化前把宠物放到配偶的身上，成长容易加的多一些。另外，进化时身上尽量不要带与之属性相克的宠物，不知道是不是真的，也发出来请大家验证。并且，无论进化前伤害度是多少，进化后都会变为1。

二、幻化

1. 主宠和副宠的选择，主宠用什么，完全看自己的喜好了，而副宠一般使用地藏或者白发。（在这里要说的是，主副相克，是没有关系的，幻出的宠物的成长主要受地图影响。）而在这两种中，非常多的人是用地藏的。这是因为，首先，地藏的初级形态啉啉，可以在夫妻天关获得，并且成长比较好，而白发的初级形态，除了每年一次的端午节会有“免费”的，一般是靠8元宠卡获得，成长的往往不如啉啉，不是十分经济实惠，其次，地仙劫比夜叉劫容易，也比较近。至于其他副宠的选择，除非经常买年卡，钱多的没处花，可以考虑用啊弟之外，一般都没有更好的选择了。
2. 主宠和副宠的级别，为保证100%成功，主宠的级别相对要高些，由于满血奖励，主副都推荐1200-**1250级**。其中，有幻化优先级别的影响（可进化宠终极状态优先于可进化宠二进状态优先于可进化宠1进状态优先与可进化宠初级状态优先于不可进化宠），配合地图的属性（见附录），成功率达到100%时主宠的级别也有所区别。这里只举几个简单的例子，终极宠物和不可进化的宠物幻化，主副都是301，也可达到100%，同属性的可进化的宠物和进化2次或终极宠物幻化的几率比不同属性的高10%，如蝴蝶或者鱼同仙子或地藏只需要**850级**，在金属性的地方是100%，但是，无论副宠再如何优先，只要主宠级别提高10，成功率就增加1%。
3. 幻化代数的计算，没有幻化过的宠物简称为0代，幻化过1次的为1代，2次的为2代，3次为最终形式，不可以再幻化了。下面是公式：0代和0代幻化出来为1代，简称0＋0＝1；0代和1代幻化出来为2代，简称0＋1＝2，2个1代幻化，同样得到的是2代，也就是1＋1＝2（比0＋1得到的宠物成长要高很多喔）；0代和2代幻化得到的是3代，即0＋2＝3，1代和2代幻化得到的也是3代，即1＋2＝3，而2个2代幻化得到的也是3代,即2+2=3，这时宠物成长达到最高，也不可以再进行幻化。
4. 幻化时所在地图的影响，与主宠相生的地图，成功率会增加，相克的地图，成功率会降低。
5. 幻化时戴的装备：根据天晴的资料，幻化时所戴装备所加属性会影响幻化后宠物4围属性，简单说就是，幻化前戴的装备是加攻击的，幻化后攻击会提高一点，另两方面成长会有下降，其他同理。但，总成长是不变的。一般来说，大家喜欢用减血装备，这样有利于提高另外三围的生长率。需要注意的是，幻化后装备可是会不见的喔。
6. 成长公式：主宠成长低于副宠时，幻化出的最低成长大约是：主宠成长50％＋副宠成长的50％；当主宠成长高于副宠时，幻化以后的宠物最低成长大约是：主宠成长的95％＋副宠成长的5％，但是由于有满血奖励，一般会比计算高出1左右。
7. 勋章和技能继承，根据官方攻略，幻化出的宠物可以继承主宠全部的勋章和副宠一半数目的勋章（需要取整），并继承主宠的全部技能。
8. 双胞胎：幻化成功率越高，幻化代数越高，得到双胞胎的几率越小，但不是一定不会出（有种看法认为，地图有一定影响）。
