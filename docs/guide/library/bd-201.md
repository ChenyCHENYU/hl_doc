幻化宠物的时候，出征你要幻化的主宠，然后战斗，杀一只怪，逃跑，再跳到相应坐标，换出征宠幻化（建议身上第一只放1级的宠，第二只主宠，第三只副宠）（建议主副宠，所穿的幻化的装备，都是幻化号制作名的装备）并且属性一样的进化宠物，没什么要求，只要挑选好时间和地图就好（个人认为，可进化宠，要选不可进化的怪地图进化=因为六合）

**以上地图**：适合幻化和进化双用，至于地图，自己感觉哪好去哪，我都抓了一堆宠实验过了，确实很容易出双，并且成长都会比别的地图高出一[点点](/pets/88)，如果要反驳我的成果，那么，你就去实验，拿数据来说话！

在要幻化前,先抓几对野宠.吃忠到100,一般都第四对，第七，第八对出双，野的出双，就赶紧幻化要幻化的宠，也有可能连续出双。
