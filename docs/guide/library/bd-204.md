# 养宠经验值的获得

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典.exe" />

> 来源：《幻灵宝典2011》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

1. 通过对出征宠物进行满血升级可以获得不定的养宠经验值,具体点数如下:

1——**99级**——每升一级可以获得3点

99——**199级**——每升一级可以获得4点

199——**299级**——每升一级可以获得6点

299——**399级**——每升一级可以获得8点

399——**499级**——每升一级可以获得10点

499——**599级**——每升一级可以获得11点

599——**699级**——每升一级可以获得14点

699——**799级**——每升一级可以获得15点

799——**899级**——每升一级可以获得17点

899——**999级**——每升一级可以获得19点

999——**1099级**——每升一级可以获得21点

1099——**1199级**——每升一级可以获得22点(3幻不可进化宠)

1199——**1299级**——每升一级可以获得25点(3幻不可进化宠)

1299——**1399级**——每升一级可以获得26点(3幻不可进化宠)

1399——**1499级**——每升一级可以获得28点(3幻不可进化宠)

1. 通过主持进化与幻化获得养宠经验值,具体数目不祥

**1200级**进化可获得170点养宠经验
