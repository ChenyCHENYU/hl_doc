# 3幻满级没进化过的0敏变态练级宠的养法：

<TopicHeader cat="玩家文库 · 宠物练级" src="幻灵游侠宝典.exe" />

> 来源：《幻灵宝典2011》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**1**：先选一只你最喜欢的宠，一定要是 0 幻的，到满级炼到最低敏。

**2**：炼化宠的方法：金宠 12 点，木 1 点，水 3 点，火 9 点，土 6 点，极限 3168武器 9点或 8 点，极限 3168衣服 11 点，宠物++武器++衣服一起炼==最低敏的状态。

**3**：再到山城装备店买 +120攻击的瓶，或者++150防的环[不要买++100血++150防那个]，带上这些装备能使到后代的敏一出生就是最低敏的状态。不带这些装备不行，到 3 幻降不到 0 敏~特别注意~！~

**4**：副宠不用改三围，因为副宠的三围不能影响后代的三围分配，副宠带不带装备都无所谓。

**5**：主副宠带着装备幻化。得到 1 幻主宠，练满级，用极限减敏。再按照 0 幻的做法幻化。

**6**：得到 2 幻主宠，练满级，用极限减敏。再按照 0 幻的做法幻化。

**7**：得到 3 幻主宠，练满级，用极限减敏。这样这只宠绝对是~[高攻击~高防御~ 0 敏捷]~的极品变态练级宠~！~。

**8**：如果炼不到 500 敏以下的话，我 奉先吕布 陪大家每人 100 亿，说到做到！！

**9**：这只宠的敏捷可以随便调整在 500----6000 之间。合适挂机练级，在个人天关绝对没有敌手了！~

**10**：用++1000敏的半极限鞋炼它，这只宠就是1000敏左右，
