# 幻灵游侠2.5之宠爱一生

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

在充满奇幻色彩的东方大陆，有一个人类与怪兽共同生存的世界。

这里群峰山峦迂迥，诸海白浪翻滚，令人不由自主的幻想起天地间的灵气皆汇集于此川岳海洋之中，而在这片这块广阔的大陆上，一直以来都相传有长生不死的秘法，所以引来数不胜数的诸路豪侠剑客在这里苦苦修炼，目的就是希望有朝一日能够参透天地间永恒的奥秘，从而达到天人合一的境界。

另外，在东方大上还出没着一种被称作是"幻灵兽"的特有生物，据说在修炼的过程中借助于其永恒不灭的奇异力量，就能够尽快的突破凡人之躯。于是，幻灵兽的神秘力量成为这个大陆上各路人马你争我夺的目标，由此引发的纷争也开始涌现……

在这个奇幻的游侠世界中，同制是特立[独行](/pets/5)的，武功自创就是一个全新理念，它为玩家发挥自己的创造性提供了最大的自由空间，除了个别的初级武功可以在游戏中的NPC身上学到以外，其他所有的武功都要靠自己去创造。

等级越高的玩家创出来的武功就越深奥，攻击力也越惊人，附带的效果也越多。在自创武功的进修，武功招式的名称、类型、附带的特殊效果甚至武功招式的特效动画都完全由玩家自己决定。

一旦创招成功，系统将把你的喜讯通告给所有玩家，那可绝对是轰动江湖的盛事。玩家自创出来的武功不但可以自己使用，还要以传授给自己的朋友们，让大家一起分享成功的乐趣。

《幻灵游侠》世界中共为玩家提供了十余类近百种酷到极致的武器，但只为玩家提供初级到中级，更高级的全都要靠玩家们自己在游戏中去创造，包括武器、防具、药品等。游戏里，根据玩家等级的高低，武器也有多个锻造等级。各种武器、的名字属性完全由创造的玩家自由选择，创造成功后物品上还会加上创造者的名字（酷吧！）。

人物等级达到一定的级别后，就可以"飞升"，也就是"轮回转世"。游戏设置两种转世途径：正道和邪道。正道是玩家达到一定级别一转轮回成为散仙后，依次经历天仙、地仙、大罗金仙，最后成为顶级的幻灵天神。邪道早由散仙依次经历夜叉、魔神、阿修罗王，最终也修练成为幻灵天神。正是所谓的"正邪双，殊归同途"。

幻灵兽，它们有自己特殊的攻击方式，比如两次攻击、三次攻击，杀伤效果很不错的哦。还有就是混乱攻击、毒素攻击、睡眠攻击、定身攻击，各有各的妙处啊！至于舍命一击、无痕一击、必中一击，更是绝杀中的绝杀！

最令人感动的是：关键时刻幻灵兽还会挺身而出"忠心护主"这招惊天地，泣鬼神的英勇壮举，以保住你老人家的性命．．．．．555，很感动是吧？

要想得到它们，你可以花钱买，也可以到野外捕捉。幻灵兽分可进化类和不可进化类两种。前者的进化系统包括升级、幻化、进化三阶段。随阶段的提升，幻灵兽的四围（生命力、攻击力、防御力、敏捷度）也会有相应的提高。

当你的两只幻灵兽达到一定级别的时候就可以幻化了，两只幻灵兽进行幻化以后，其二者本身消失，幻化后的幻灵兽会继续上一代的一些优势特性。如果幻灵兽再进行修炼达到一定级别，那就可以进化了。

再提醒大家一句，不要以为有了进化后的终极神兽就天下无敌了。真要这样，天上天下岂不乱做一团！

那些不能进化的幻灵兽在前期也许会显的很弱，但是对某一类的幻灵兽有致命克制能力，在战斗中足以让这些终极神兽吃尽苦头，就象自然界中的"天敌"。

所以呢，在提供的100多个宠物角色中，要选你所能、只能带的5只宠物时，一定要三思而后行哦。

幻灵游侠》为提供最广阔、最方便的交流空间。《幻灵游侠》中的战斗是属于RPG中最常用的回合制战斗模式，但不同是加入了幻灵兽和组队。幻灵兽是玩家们在世界中历练的最好伙伴，在战斗中的作用是不可忽视的！

一进入这个世界玩家就会得到系统自动提供的一只幻灵兽，以后玩家可以依靠自己的力量去捕获各种各样的幻灵兽。

组队则可以让玩家在游戏中交更多的朋友，一是可以共同练级，二是方便交流练级心得，还可以交换互需的物品、宠物在你受伤的时候别人也可以给 你补药帮你恢复体力。

当你自创一门武功成功的话，还可以教给你的队友，如果能从队友那里了解一些锻造兵器、合成药品等的独家心法、经验，对你以后的成功会有很大帮助的，而所有这一切都需要你和队友在相互沟通、交流的基础上互相了解，加深友谊才可以的。

当你的等级已经达到一定级别，就可以向有关NPC申请创立门派了。当你成为某门派的开山鼻祖时，你的大名马上就会响彻江湖，在你的脚上地面也会出现一个代表帮主的光圈，有想加入你门下的玩家看它就会向你下跪拜师。

呵呵．．．．．．是不是很得意啊？不过做帮主也很累的，要制定帮规，对于屡教不改的顽劣之徒还要逐出师门，以免影响帮派的声誉。管理好一个帮派，成为一代宗师可不容易哦，还有很多要做的事情，要您在游戏中一步步去学习。

《幻灵游侠》中还有一些十分特殊的功能，如偷盗、点穴、轻功、下毒、暗器伤人等。这些功能让您可以在享受回合制的游戏时同时可以体会即时作战的乐趣。

游戏里特别设计有许多超浪漫的富有意境的场景，分布在幻灵世界中的各个地方，那美丽的景色会使每个玩家驻足留恋，绝对是谈情说爱的佳境。

当一对男女玩家感情成熟以后，自然是要考虑结婚了。

在《幻灵游侠》中有全套的结婚服务，玩家既可以一切从简（只是办理结婚手续确定二人关系），亦可大宴宾客，花重金租用婚礼场地，新郎新娘可以广邀亲朋好友甚至GM也可以邀请来主持婚礼哟！

而且系统可以根据玩家的要求在场地奏乐、散花甚至下雪、放礼花等等等等，当二人成为夫妻以后可以选择是否购置新房，这里的房屋是可以购置家私以及升级的，可以让你把多余的钱和道具存在家中不怕丢失。"爱的小屋"最后还会变成庄园的哟！
