# 400级---585血、+240敏的宠装[紫血]数据

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

精华里只提供了磐龙做原材料的减血装（-588血），，所以我一直都是用商店卖的240敏戒指做原材料做宠装，实际效果跟磐龙做的相差无几。

**材料**：1个山城卖+240敏紫血扳指、3条极限内带、2个极限血佩、2个半极限血佩

**炼化数据**：血 内 敏 备注

3303 240 直接加修

\-330 3303 240 +极限血

\-330 5232 240 +极限内

\-498 5232 240 +极限血

\-498 5778 240 +极限内

\-576 5778 240 +3060血佩（可以更多甚至极限血）

\-576 5856 240 +极限内

\-585 5856 240 +1056血佩 （可以更多甚至极限血）

最后降修为-585血、+240敏**400级**用，就可以给爱宠带上了，
