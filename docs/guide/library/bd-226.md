# -732血，+7332内，+244攻内人用黯神灵戒左饰（90万满修PK装备）

<TopicHeader cat="玩家文库 · 锻造-饰品" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

黯神灵戒

(一)减血732的数据..

清掉原来的1000血,把左饰放1点,水城珠宝店的水坠纹放6点,1点主炼.

**1**：直接加内到4170,加第一个极限血饰======>减血417.

**2**：直接加内到5268,加一个加血2580的半成品血饰.=====>减血525.

**3**：加第一个极限内带===>加内7053,然后加第二个极限血饰=====>减血678.

**4**：加第二个极限内带===>加内7278,加一个加血2415的半成品血饰===>减血726..

加第三个极限内带===>加内7326,加一个加血918的半成品血饰===>减血732.. (二)90W修加攻的数据.. 加攻的极限是244,把做好减血732的左饰直接加极限内带把内加到极限. 然后加极限武器加攻到不能加为止.(不能降修加攻..) 当然了,其实要不要把攻加到极限是根据个人的红利点和所用招的大小而定的. 没必要一定要把攻加到极限.
