(二)加敏:

**1**：降攻到3989,加1双极限鞋子(武器11点或12点,极限鞋子3点)

→加敏908的武器!

**2**：加攻到4182(加一个+攻2341的半成品武器)加一双加敏2165的鞋子.

→加敏996的武器!

**3**：加攻到4055(加一个+攻2200的半成品武器),加一双+敏1800的鞋子.

→加敏1045的武器!

**4**：加攻到4040(加一个+攻1884的半成品武器),加一双+敏1600的鞋子.

→加敏1079的武器!

**5**：加攻到4047(加一个+攻1712的半成品武器),加一双+敏1397的鞋子.

→加敏1103的武器!

**6**：加攻到4037(加一个+攻1542的半成品武器),加一双+敏1205的鞋子.

→加敏1120的武器!

**7**：加攻到3994(加一个+攻1296的半成品武器),加一双+敏984的鞋子.

→加敏1130的武器!

**8**：加攻到3999(加一个+攻1154的半成品武器),加一双+敏936的鞋子.

→加敏1139的武器!

（三)1139敏武器的加内

**1**：降攻到1066,加第一个极限内,→加内693(位子武器11点,内带1点)

**2**：降攻到1003,加第二个极限内,→加内1368

**3**：降攻到1311,加第三个极限内,→加内1974

**4**：降攻到1864,加第四个极限内,→加内2322(从这开始武器9点,内1点)

**5**：降攻到2290,加第五个极限内,→加内2577

**6**：降攻到2584,加第六个极限内,→加内2784

**7**：降攻到2784,加第七个极限内,→加内2907(这一步降攻的时候有点过了,大家做的时候降到2850左右的时候就可以加内带了)

**8**：直接加第八个极限内带,加内到3069
