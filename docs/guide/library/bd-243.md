# 磐龙樽制作减血装备最佳做法

<TopicHeader cat="玩家文库 · 锻造-防具" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

1，准备工作：磐龙樽一个，草鞋一双，水城最便宜头饰一个

极限（4251）血佩四个，极限（4251）内带三个

2，磐龙樽减敏减血

原料磐龙樽：

**减敏**：草鞋9点，磐龙樽7点主炼

**减血**：上面得到的装备7点主练，水城最便宜的头饰5点

3，具体铸造过程：

第一加内3339+

第二加极限血佩（1个）-333血+3339内，位置：主练7点，血饰5点

第三加极限内带（1个）-333血+5268内，位置：主练7点，极限内饰1点

第四加极限血佩（1个）-501血+5268内 ，位置：主练7点，血饰5点

第五加极限内带（1个）-501血+5811内，位置：主练7点，极限内饰1点

第六加极限血佩（1个）-579血+5811内，位置：主练7点，血饰5点

第七加极限内带（1个）-579血+5889内，位置：主练7点，极限内饰1点

第八加极限血佩（1个）-588血+5889内
