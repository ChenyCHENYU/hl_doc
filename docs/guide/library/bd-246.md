# 减70敏刀血内敏刀制作过程

<TopicHeader cat="玩家文库 · 锻造-武器" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

刚做的血内敏刀~把加血内敏的过程发出来~方便大家一下~

材料减敏70的刀~沙城有卖~

步骤一加内:

按照精华理的方法将刀做到减防1896~

降等级至**200级** 加一个极限内带得到加699内的刀 内带1点刀3点

降等级至**200级** 加一个极限内带得到加1398内的刀内带1点刀3点

降等级至**200级** 加一个极限内带得到加2097内的刀内带1点刀3点

然后一直内带1点 刀9点极限带加到3090内~

听说可以到4000内~个人原因没有做到极限~

步骤二加血:

降修行到49800加极限血配得到加血1830血得刀~

加攻击到2800加极限血配得到加血2400左右的刀~

加攻击到3100加极限血配得到加血2833的刀~

加攻击到3200加极限血配得到加血2960左右的刀~

这时候加一个极限武器~

然后一直加血配血加到3897这时候是加血的极限了~

步骤三加敏:

武器9点~极限鞋3点~一直加敏就可以~我的加到315~4W修行~敏还可以加
