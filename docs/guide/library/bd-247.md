# —70敏捷刀制作的最佳过程

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**准备**：沙城买—70的刀一把，极限武器5把，极限衣服20

1，54次 —462防

2，72次 —730

3，66次 —921

4，64次 —1068

5，63次 —1185

6，62次 —1285

\+第一把极限武器（主武器9点，极限武器7点）

给得到的武器减防御，武器9点主位，衣服12点，到御览加极限衣服减少的防御少于30

\+第2把极限武器，位置同上

和上面一样，加极限衣服如果减少的防御少于30

\+第3把极限武器

一直等防御—1897

就完成了这把武器的铸造
