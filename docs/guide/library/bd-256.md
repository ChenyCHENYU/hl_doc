# 金光刀加敏的研究和数据

<TopicHeader cat="玩家文库 · 锻造-武器" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

原创]skysunsan

**原材料**：减防到极限状态的金光刀 +6438攻 -1931防 -150敏

**分析**：一开始可以有两种做法，可以选择不降修或者降修加敏，为了不破坏主属性上限，这里我采用了不降修的方法！

1，加第一个极限鞋得到 +3663攻 -1931防 +250敏

武器12点鞋3点

2，加第二个极限鞋得到 +3011攻 -1931防 +815敏

武器6点鞋3点

**分析**：由以上两步来看，武器在不降修状态下加极限鞋时，放在6点效果较好，希望以后做的朋友注意一下！

3，加毒提攻得到 +4284攻 -1931防 +815敏

**分析**：这一步我试过把攻提到超极限，但是无效，也正是由这一步的实验决定了以下的做法全部取的是3168这个第一极限点，而不是4358这个超极限！

4，加第三个极限鞋 1005敏

5，提攻到4094 加1822敏鞋 1053敏

6，提攻到4046 加1575敏鞋 1086敏

7，提攻到4013 加1368敏鞋 1109敏

8，提攻到3990 加1190敏鞋 1125敏

9，提攻到3974 加1053敏鞋 1136敏

10，提攻到3963 加962敏鞋 1138敏

**分析**：做到这里已经无法再加敏，把攻击提到极限同样无效，虽然1138和理论金光加敏的数据有一定差距，但是我认为这是在许可条件下的差别！就象醉剑只能做到1134一样！
