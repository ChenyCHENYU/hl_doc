血防鞋的步骤

**材料**：使用已制成的-1995攻加1305防的鞋子 100W修行

1. 鞋子9点主练 第一个极限头饰6点副练 得加1200多血的鞋子
2. 鞋子3点主练 第二个极限头饰6点副练 得加1500多血的鞋子
3. 此时加一双极限鞋子，主练鞋3点 副练（极限鞋子）鞋11点 加敏
4. 鞋子3点主练 第三个极限头饰6点副练 得加2100多血的鞋子

最后降修行 得到-1995攻 +1305防 +600多敏 +2100多血的鞋子
