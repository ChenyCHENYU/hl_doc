# 积累功德最新最快的办法

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

【人物篇】

申请4个新人帐号（免费3天）建议帐号名尽量一致。比如：king01、king02、king03、king04...记住一个帐号（便于快速修改）。

【装备篇】

**身饰**：幻兽之灵 0级使用 +100血、100防、100敏（水任务兽玉换得） 推荐指数★★★

梦之链 0级使用 +100血、100防 （中秋任务绝版） 推荐指数 ★★

药王佩 0级使用 +20防、 20敏 （乾坤五行炉开炉任务）推荐指数 ★☆

彩蝶（飞龙）香囊 **10级**使用 +50防 +50敏+20攻（+50防+20敏+50攻） （端午任务得） 推荐指数 ☆

疾风之镯 **50级**使用 （兄弟77关换） 推荐指数 ☆

**头饰**：恋之守护 0级使用 +30敏 （恋之守护任务） 没商量，就是他了！

**衣服**：彩云衣 0级使用 +150防 （水任务10打怪得） 没商量。就是他了！

鞋 ：真爱仙履 0级使用 +200敏（雪狼湖任务得） 没商量，就是他了！

按幻兽之灵装备下来：1级新人 100血250防350敏（新人20点加敏）

添加一个最重要的装备：**90级**加1800+的防衣（或**100级**）

【带功德办法】

1级到5级在水成郊外练，然后去做丑剑客任务，升到**15级**，练到**29级**，再找丑剑客，升到**39级**，然后带到**69级**做清风原哪个修补剑的任务，就成了**89级**

带1级之后穿上**90级**加1900左右的防衣（这个过程10分钟左右）

也可以一直升级到69，做次任务直接到**89级**，练几级就能穿装备了

大号带只敏低于700的宠物，能秒怪就可以

要是有时间可以去西码头打**250级**（**110级**以下在明月桥不能一战一级）、要不就直接在明月桥挂，明月桥脚本在下面

这样可以直接挂到**250级**左右换下另一批小号。

3批小号1万功德，150X3=450战，懂算术的就知道快不快了（最适合晚上睡觉之前挂机）

不过就是有个难题，**90级**或**100级**1800+衣服难找啊，还有小号要加点血才能挂机

在带功德之前.先放四只[嘟嘟鸟](/pets/13)在每个小号的身上.让小号升级的时候给宠加忠、虽然有[点点](/pets/88)麻烦. 不过这样也有好处...四个小号..每个小号带四只...等宠满忠了的时候.再结婚转到大号去.让大号进化.一次加130点经验.16只就加了2080点的经验..还有16只九转鸟..

【带功德好处】

多了功德

给大号加了养宠经验

带了N只[觅雾鸠](/pets/16)

加帮凑人数
