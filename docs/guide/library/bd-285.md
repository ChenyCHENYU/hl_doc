# 总结90W修PK人装备与分配

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

PK分为五种. 招人(分为纯招人和招标人) 内人 .血人.标人.血防人.

简介:

纯招人 ,都是纯用招打.以招取胜.一般都适用于单挑.

招标人,能打能标.在用招打的同时配合加上一两个标.如果对方加血慢的话不是被打倒就是被标回药店.适用于混P,比赛等情况下.

内人,以自己的优势-高内,克制对方,不让对方出手.没一点杀伤力.适用于比赛情况下.

血人,以自己的优势-高血,跟对方耗,你打我几拳,我加一次血,直到你没药为止.没一点杀伤力.适合用在比赛时给人送药.

标人,也分大标人和小标人.大标人,攻特高.一般人难挨得住他两标,但是精准度低.小标人,不像大标人一样几乎标标致命,但是它精准度高.适用于混P,比赛等情况下.

防血内人,有防,能挨得住大标人的几标,血多,合适当肉盾,有内,不会挨大招人打空内.当肉盾给人送药是最好不过的.适用于比赛的情况下.

这只是普通的PK人罢了.最恐怖的PK人.当数90万修行的人了.

90万修行的人也分为两个人.一种是纯PK人.另一种是多属性人.

纯PK人.没防.高敏高血.让人打得头皮发麻都没死.但是有个缺点-没防.如果敌方一起用标的话.不幸的话很快就马上被标死.

另一种是多属性人.敏虽然不是很高,比一般的小招人高出一点.但是有防,有内.标人标不死他.内人点不到他.那种属性在比赛的时候是最另人头痛的.

90万修行的人都有一个共同的特点.那就是血内敏都很高.可以充分利用一个炼话药.配合上一个炼话药就可以打8-9拳大拳.那样比起来就占了很多优势.因为他不会浪费药.杀伤力极高.

下面来谈谈各个属性人的装备

类型 武器 衣服 鞋子 左饰 右饰

纯招人 纯攻或攻敏 纯敏或血敏 纯敏 敏内 纯加血或减敏加血

招标人 血内敏武器 纯敏或血敏 纯敏 敏内 纯加血或减敏加血

内人 血内武器 血内甲 血内鞋 减血加内 减敏加血

血人 (同内人)

大标人 血敏武器 减内的血敏衣 纯敏鞋 磐龙清防就可 减敏加血

小标人 (同大标人)

血防人 血防武器 减内加防 血内鞋清防 磐龙清敏 减敏加血

90万纯招人 血内敏武器 血内敏甲 敏内鞋 黯然佩改装 加防减敏加血减攻

90万多属性人 血内敏武器 减内的防敏甲 敏内鞋 黯然佩改装 加防减敏加血减攻

装备与点数的分配:

纯招人

**武器**：用醉剑做成减防1910减100敏攻XXXX(据修行定).

**衣服**：用正气甲做成减攻100 加敏1171敏的那种.

**鞋子**：飞羽做的纯敏鞋 减1995攻 减300防

左饰用紫血板戒直接加修行.加240敏 加内XXX(根据修行定)

右饰可以选择长命锁,太乙珠,丹凤钗几种材料做成减敏或不减敏的直接加血

**加点**：只要把混攻调到N层武功打怪掉血的一半就可以了.剩下的点数全加敏.

招标人

武器用醉剑做+1135敏 -1910防 加血内看自己的属性来定

其他的跟纯招人的一样

**加点**：把混攻加到N层武功打怪掉的血的一半.剩下的加敏

内人,血人:

**武器**：醉剑或金光刀做的.+4600左右血,+3900左右内 -1910防 -100敏

**衣服**：用正气战衣做成 +2000内 +XXXX血 -100敏的衣服

**鞋子**：飞羽做成的+5985内 +2289血 -300防 的那种

**左饰**：-732血 +XXXX内 (根据修行定)

**右饰**：-50,-100,-120攻 +XXXX血(根据修行定)

**加点**：做内人就把红利全加到内上去.做血人就全加到血上去.

标人

**武器**：+4600左右血 +1135,1139,1140敏

**衣服**：-5940内 +2580血 +1980敏 -70攻

**鞋子**：飞羽纯敏鞋

**左饰**：磐龙把防清0 +200血 +200敏 +XXX内

**右饰**：-227,-232,-235敏 +XXXX血

**加点**：大标人全把红利加到攻上去.右饰带不减敏的那种.小标人减敏加血的右饰,好加点红利到敏上去.剩下的全加攻

血防人:

**武器**：加XXXX血 +120防或100防(剑和刀的区别) 要做加血的武器先把修行算好.血能加到攻的90%

**衣服**：极品的防甲 -5940内 -70攻 -80敏 +XXXX防衣服

**鞋子**：用极品的内人鞋 +5985内 +2289血 最好把-300防清掉

**左饰**：磐龙把敏清完,加内XXX

**右饰**：-227,-232,-235敏的 +XXXX血的佩.

**加点**：看防和血来分配.适当的加上些内..混内不要下1500.混防也不要低与6000.剩的红利全加血

90万的纯PK人

**武器**：跟招标人一样的武器.可以把防弄到负1200多

**衣服**：+2000内 +2100血 +958敏 +XXX防 -100攻 或是+2000内 +1600多血 +1152敏 -100攻

**鞋子**：+5985内 +6653敏 -1995攻

**左饰**：-732血 +7332内 +244攻

**右饰**：+7059血 +235防 -235敏 -120攻的丹凤钗

**加点**：把混内加到上2W.把血也加到2W.剩下的加敏.随便你加敏和血都可以

90万的多属性人

**衣服**：-5940内 +1980敏 +6602防

其他的装备都跟90万的PK人一样

**加点**：靠装备有5000多点防.加到了7000防就够了.把混内加到2W以上..血和敏看你的喜欢加了
