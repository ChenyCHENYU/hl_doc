# 名剑山庄降妖(赤刃)任务

```
到名剑山庄书房找到庄主易云,他会告诉你庄里出了妖怪, 让你帮他收服, 并且给你一把惊鸿剑, 晚上17：00-19：00带着惊鸿剑到名剑山庄正院找到来福(29,34), 他会送你小枯井下面收服妖怪,进去一后可以看到一妖怪, 跟他说话进入战斗(5只1500级的[蓝发魔姬](/pets/285)), 战斗胜利后得到妖怪内丹
```

名剑山庄左厢房找到易天, 他会让你帮他找他的妻子

从树城灵儿处到达寒月台, 找蝶衣, 她会让你帮她找武当山的元元真人炼制 回天灵丹

找元元真人炼制回天灵丹,然后回来给蝶衣, 她会让你去易天那报平安; 最后找到易天,他为了表示感谢, 会送你一把赤刃
