# “由道入魔”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

地焰洞的地狱守护MM处可以打听到由道入魔须要无极天魔丹与凝神丹炼制成的神魔丹，寻找到这两种丹药后可以请地狱守护MM炼制成神魔丹。

然后再打入地狱，在钉床地狱找到由道入魔的前辈－噬魔女（14，30），可以了解到由道入魔的方法。考虑清利害后就可以在噬魔女的帮助下由道入魔了。

一、由道入魔逆天的行为，所以成功者在修炼上会下降一个层次！如由阿修罗王就会降为地仙，以此类推。

二、必须花费300万用来供奉魔神。这三百万必须放在身上。

三、由道入魔就有如再世为人，身上的装备等物品都会丢失。

四、也是最关键的一点！由道入魔要求至少是天仙级别的修为，等级在**800级**别以上。
