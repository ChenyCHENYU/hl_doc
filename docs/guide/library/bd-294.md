# “四转”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**升魔神**：进入油锅地狱 ========选择不同属性飞升找相对应npc

**大罗金仙**：盈露台看守区========选择不同属性飞升找相对应npc

具体的条件：

1. 天仙**1000级**别或者阿修罗**1000级**以上；
2. 选择任意一种属性的图鉴为基础飞升：

四转图鉴：

由原来的百分比计算，改为按只数计算，飞升NPC的对话中有提示。

下列为四转的基本要求：

水系：15只

土系：13只

木系：11只

金系：10只

火系：9只

选择其中一种属性飞升，必须分别达到以下要求：

水系：26只

土系：19只

木系：25只

金系：13只

火系：18只

原来达到飞升要求的玩家同样可以飞

请注意，选择哪一种属性的图鉴飞升，就奖励得到该对应属性的终极宠物一只。

**金系**： [蓝鸟龙](/pets/22)

**土系**：[蓝发魔姬](/pets/285)

**水系**： 敖雪兽

火系： [绿妖](/pets/208)

**木系**： [至尊林](/pets/81)

请量力而行，水系工作量较大，火系和木系完成的难度非常高。不喜欢收集图鉴的，可以考虑完成金系，较容易。根据飞升开放前的最后调整，只有四转图鉴满足四转的基本要求，然后只要选择其中一个属性，达到要求。

 另外，另外说明一下，这一级的飞升不需要有专门的宠物，只要记得飞升的时候，身上还有空的位置可以得到宠物奖品。

**注**：大罗金仙和魔神的部分法术在菜单的仙术部分可以找到，请注意不少法术要牺牲等级和银子。

血雨勾魂 是魔神的法术，可以将地图上所有的玩家的血都减少25％。

花雨普渡 是大罗金仙的法术，主要是给整个地图上不是魔的玩家加血。

这两种法术不仅需要银子，而且要损失1级的等级，请谨慎使用。

大罗金仙和魔神的天劫在天仙和阿修罗的山洞后面。

**友情提醒**：飞升时请卸下身上装备，以免造成不必要的损失
