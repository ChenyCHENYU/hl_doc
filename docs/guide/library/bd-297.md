# “三转之转阿修罗”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

先到华山顶打到天魔散，然后到天灯地狱找到地狱飞龙（49，37），他就会给你一颗阿修罗飞升药了。

满足条件后吃了阿修罗飞升药就可以飞升了。

**飞升阿修罗的条件**：夜叉王**1000级**以上，内力和血全满，出征宠物是一只**800级**以上，**忠诚100**以上的[黄龙使](/pets/280)。

**友情提醒**：飞升时请卸下身上装备，以免造成不必要的损失
