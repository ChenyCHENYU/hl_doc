# “三转之转天仙”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

先到古铜洞窟2打出玉露丹，然后到仙客厅找到青云仙子（16，27），她就会该你一颗天仙飞升药了。

满足条件后吃了天仙飞升药就可以飞升了。

**飞升天仙的条件**：地仙**1000级**以上，内力和血全满，出征宠物是一只800--**1200级**，**忠诚100**以上的[绿衣仙子](/pets/139)。

**友情提醒**：飞升时请卸下身上装备，以免造成不必要的损失
