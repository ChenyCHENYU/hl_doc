# “夜叉王装备”任务

<TopicHeader cat="玩家文库 · 锻造-武器" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到钉板地狱(第二层)(57,31)找魔女飞纷说话,她会让你用一只一级的"[红刀](/pets/125)"和5万两银子跟他换一件装备.

抓到一级"红刀",然后身上放5万两银子,再找她说话,她会收走宠物和钱,同时给你一件飞纷皓月甲.

::: info 玩家提示
- PS:飞纷皓月甲 攻击:+50 防御:+150
:::
