# “地仙装备”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

来到天空之城的记录点房间,进入下面的房间(12,28)找幻影兽小白说话!

他会让你拿一只一级"[拂叶鸠](/pets/14)"和5万两银子跟他换一件盔甲.

抓到一级"拂叶鸠",身上放5万两银子,然后再跟他说话,他会收走你的宠物

和银子,给你一件幻影锦云甲任务(还不错哟).

::: info 玩家提示
- PS:幻影锦云甲 攻击+50 防御+100 血+100
:::
