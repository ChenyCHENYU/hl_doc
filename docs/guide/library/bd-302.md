# “转仙”任务

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到武当山(95,57)找张三丰说话,如果满足飞升条件,即可进入战斗,打赢后得到"仙道飞升药",吃完就可以飞升为地仙了。

**友情提醒**：记得把装备存起来 要不然就没有

::: info 玩家提示
- PS：如果不想飞的朋友，千万别乱吃哟，战斗中补血也要注意点哟，吃完就飞了。
:::
