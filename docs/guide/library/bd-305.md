# “二级房屋升级”攻略

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到皇宫的湖滨小区参观，可以看到新的二级房屋样板房，款式多多哦。

如果有兴趣，可以先进入样板房内参观（很漂亮哦，特别是中式房屋，古色古香，还有水雾缭绕的户外温泉哦。）。满意后花费1500万购买了二级房屋的设计图。

带着这设计图回到自己已经购买好，并且建造了一级房屋的小家旁，点击房屋后会出现选项，原来的拆房选项变成了拆房或升级房屋，选择该选项后出现的对话框除了拆房的几个选项外，还有个升级成二级房屋，点击后房屋就升级成二级的了

可以开始重新添置家具咯。

与一级房屋相比，房屋内使用面积大大提高，明显建筑水平也高了很多，有了庭院哦。而且一级房屋只能放置特殊的物品箱两个，而二级房屋这类特殊物品可以放四个哦！ 各类家具装饰品相加一共可以放置二十个。

::: info 玩家提示
- 注意：二级房屋必须在一级房屋的基础上升级。
:::
