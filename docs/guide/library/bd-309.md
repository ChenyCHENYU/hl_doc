# “拿宝箱钥匙”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

在凝露山城可以找到地理学家汪思敬（60，32），跟他说话，他会告诉你只要帮他抓一只凝露山城门口的[独行](/pets/5)就可以换一把黄色木箱的钥匙。

::: info 玩家提示
- PS：拿到这把钥匙，在每个小时的前几分钟就可以到水城客栈底下的宝洞里开启宝箱领取奖品了。
:::
