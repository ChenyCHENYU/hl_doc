# “打入天空之城”任务

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到武当练功房(20,18)找无极真人说话,如果不是**200级**以上地仙,则进入战斗,打赢可进入天空之城。

如果是**200级**以上地仙则可以直接进入。

::: info 玩家提示
- PS:要打的都是**900级**的[风舞](/pets/4)哟。
:::
