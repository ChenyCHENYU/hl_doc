# “水属性任务”攻略

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

恒河星溯变化出奇、层出不穷，一种神秘的力量创造了幻灵世界。

但是很少人对此有所了解，将毕生心血投入于研究的悠然老人，在花费了一生精力之后，终于对此力量有了一些了解，常常在断壁一带的悠然老人（**58.48**）对好学的人是很热心地讲解构成幻灵世界的神秘力量的情况，以及由此神秘力量一分为五繁衍出的各系幻灵兽的故事。

了解这些情况以后，可以知道，如果想追寻那五系的力量，则需要通过各系各个宠物的考验。

良禽择木而栖，灵兽择主而侍。西码头的“[骑士龟](/pets/116)勇勇”，最大的愿望就是能跟随一位强大的主人，为了能找到一个配得上它的主人，它在西码头苦苦等候。它听说华山经常有高人出没，但由于路途遥远它至今仍未找到机会去华山。

如果玩家愿意帮助，就可以到华山附近去帮“骑士龟勇勇”物色主人。当到达华山亭时玩家就可以碰到武艺已趋大成的“剑无涯”，他正想找一只合适的幻兽陪伴他。

“剑无涯”让玩家带着他的本命玉牌给“骑士龟勇勇”，只要看到他的玉牌幻兽就会知道他的实力。“骑士龟勇勇”为了表示感谢，将会送给玩家一块“水行令”，凭着这块令牌就可以去寻找水属性的力量。

剑池谷“[琳琳](/pets/131)飞羽”做“甜蜜露”还缺少一种“神奇花粉”，想请玩家到坠泪岗她姐姐“[盈盈](/pets/130)翠羽”那里拿。但“盈盈翠羽”在前些时候把“神奇花粉”都送给他的好朋友丘丘了，如果尽快的赶去可能还会剩些。到吓死人洞“[珍珍](/pets/132)丘丘”那里拿到神奇花粉交给“琳琳飞羽”可以得到“水行令2”

净沙原“[厚皮鳄](/pets/114)霹雳（**32.6**）”皮坚肉厚，对自己很有信心。放言所有来寻水力量的人只要打败他们几个兄弟就算通过他的考验，可以得到它送出的“水行令3”。选择战斗的话，只要打败5只**500级**的厚皮鳄就可以得到“水行令3”

不归海岸的“[蓝牙](/pets/127)”最近正为他母亲的病而烦恼。她母亲的病只有一种“蓝幽草”的才能根治，但是拥有这药的人不喜欢幻兽，把他给赶出来了。得知玩家是为追寻水的力量而来的，想请玩家帮助取“蓝幽草”。

断魂涯的“糊涂老人”因为他的小儿子自去抓一只幻灵兽不小心死了，所以恨透了幻灵兽。所以玩家再拿“蓝幽草”的时候千万不可以说是为帮“蓝牙”的忙。带着“蓝幽草”交给“蓝牙”，为了表示感谢它将会送你“水行令4”

带着“水行令4”到斑鸠小舍（68 48）找“[霓裳](/pets/135)”。“霓裳”在很久以前受过一个人的帮助，一直没有机会报答，只要玩家能帮他恩人就算过了它这关。

原来它的恩人无忌是个冒险家，整天爱到处乱跑，这天在沉没的城市（46 10）被一群幻灵兽给困住了，玩家只要帮忙赶跑那5只**700级**的[铁甲龟](/pets/117)就可以得到物品“冰泪坠”回斑鸠小舍“霓裳”那里换取“水行令5”

凰之谷“[苦行龟](/pets/118)”最大的愿望就是可以走遍天下，因为重任在身没有机会出游而倍感遗憾。如果玩家可以找到一只**500级**以上忠100的苦行龟来代替它，那么将可以得到“水行令6”

“[乌哩头](/pets/119)小弟”(绿幽洞：11 35)最崇尚力量，如果玩家能向它展示出自己的强大能力的话，那么进入下一关就轻而易举了。

它的哥哥——乌哩头大哥在赏月谷训练一些徒弟舞枪弄棒，如果玩家能打败他们就可以得到乌哩头小弟的认可从而获得进入下关的令牌。

到赏月谷与乌哩头大哥对话并打败它手下的7只**900级**的乌哩头得到物品“考验之牌B”回到绿幽洞交差得到得到物品“碧水令7”

徘徊林（17 31）“[蛋蛋鱼](/pets/141)”闲来无事，昨夜斟观天象，发现树城一带的五行之气有紊乱之相，其中水性力量似有削弱，想请玩家帮助查明原因。

带着“调查委托书”找到树城“长者”（61 97）得知：这阵子树城唯一的水井不知道怎么不出水了，害的大家都要跑到水源丰富的水城去取水喝。并告知玩家树城水井的水源都来自山城那附近一带，到那调查可能会有些线索。

原来，不久前鳄鱼霸王看到山城水源充足从沙漠移居到此霸占了下游的水源。打败鳄鱼霸王手下7只**1100级**的[大嘴鳄](/pets/113)赶跑鳄鱼霸王后，树城的水源终于回来了，树城的水性力量从而恢复如常。

为了表彰玩家的勇气和善心蛋蛋鱼将会把“水行令8”交给玩家。

水城（62 5）“[羽衣](/pets/134)”一直以来都在找寻一种叫神圣之羽的东西，却渺无音信，最近终于有了点头绪，玩家带上羽衣赠与地[精灵](/pets/231)之链，去青灵洞，就会得到这个传说种的神羽。

但神圣之羽的主人——纷飞，从不轻易把神秘之羽送人，只有强者才有资格得到它。打败纷飞手下的7只**1300级**的粉衣后，玩家的能力得到了纷飞的认可，得到物品“神圣之羽”。

得到圣洁而美丽的羽毛后，羽衣兑现了她的承诺，将“水行令9”送给了玩家。

沙漠，水属性力量最弱的地方。山城“[口袋鸭](/pets/128)扁嘴”自他一个小兄弟跑到沙漠后，夜不能寐，当心兄弟会遭遇危险。看到玩家一路过关斩将而来，因而想请玩家帮忙将它的小兄弟安全的带回。

“救宠一命胜造七级浮屠”带上“委托书”去青之绿洲寻找“口袋鸭嘎嘎”吧（26 42）。

原来扁嘴的兄弟答应朋友一定要带这里的青灵之水回去，因这有几只“幻兽守卫”（青之绿洲：51 40）守着，凭它的力量无法打败，所以一直僵持到现在。打败9只**1300级**的乌哩头得到物品“青灵之水”。

口袋鸭嘎嘎得到青灵之水后，让玩家将一封报平安的家书交给他大哥，就飘然而去给朋友送水了。回到山城，口袋鸭扁嘴得知兄弟平安后，赠与玩家“水行令10”

水族的制衣高手[灵衫](/pets/136)（雪城：92 56）花了很长的时间精心制作了一件彩云衣，最近被雪融谷的幻兽怪盗所偷。得知玩家正在追寻水之力量，请求玩家帮忙夺回衣服。幻兽怪盗不甘心轻易将衣服交还，非得要玩家用武力夺回。

打败7只 **1500级**的[空手道](/pets/66)后，得到物品“彩云衣”。雪城灵衫因彩云衣的失而复得而欣喜若狂，将“水行令11”送给玩家。

“山中无甲子，寒尽不知年”。聋耳地狱的“[红刀](/pets/125)”守卫地狱多年，好想能有一次长假可以出去看看世面。但只有得到“地狱天使”（冰封地狱：20 30）的批准，“红刀”方能请假。“地狱天使”得知红刀不安于工作，勃然大怒。

但答应，只要打败他的幻兽（9只1700[蓝发魔姬](/pets/285)）就破例放红刀出去几天。带着“特赦书”交给聋耳地狱的“红刀”为了报答玩家，红刀将“水行令12”给玩家作为谢礼。

独木原的“[欧欧](/pets/124)”在玩家身上感觉到水族的力量波动，得知玩家是来接受水之力量的考验。因而让玩家帮忙寻找个杀伤3500的毒药来跟人换一样东西，你如果能帮弄来毒药，就可以过关了。但这种毒药只能用当地战斗奖励的两种物品锻造方可得到。交给“欧欧”3500的毒药后得到“水行令13”

“行万里路，读万卷书”[愣头青](/pets/121)为了增长见识出门历练。本来打算下一站是要去沙城，可是通往沙城的唯一通路上有些[山贼](/pets/103)在守着，它打又打不过，又出不起买路钱，。只好滞留在树城宠物店。

得知玩家身怀水行令，想请玩家帮忙到石壁洞口“山贼”（左边的那个）处拿过路条。靠打家劫舍为生的山贼自不肯放过到嘴的肥肉。玩家要么选择孝敬他们5000两银子，要么就只好用武力通过了（9只1900的[小妖](/pets/193)）。

为愣头青拿到过路条后，身无长物的愣头青把“水行令14”送给玩家，同时让玩家替他照顾水族的幻兽——[巧巧](/pets/129)。

水的力量看似柔弱，其实蕴藏着巨大的能量，它没有起点也没有终点，从恒古以来就存在了。道德经有言：上善若水。因此只有善良勇敢的人才可以领悟它的真谛，找到它的神秘之源。

榕盘谷的“[卜卜](/pets/122)”对玩家是否了解水的力量还略带疑问。因而让玩家到紫苔洞窟（54 29）找水族的长老，只要得到它的认可，就算通过了卜卜这关。

水族长老的考验很简单，只要打败它手下几个水族的幻兽（9只**2100级**的[逐浪仙子](/pets/149)）就可以了。

战斗胜利会得到“水长老的认证”，从而表明玩家已经有了继续追寻水族力量的资格，回到卜卜处换取“水行令15”“[摇爷](/pets/120)”在辗肢地狱等候追寻水之力量的人已经多年了，但是能来到它这关的却寥寥无几。

因而它从不怀疑那些能顺利到达它这关的玩家的实力。只是有个和它一起来这当差的水族朋友，已经很久没见面了，甚为记挂，想让玩家帮忙去问候一下。带着摇爷“给朋友的信”去聋耳地狱找“红刀”。

刚被批准放假的红刀，得到老友的音讯大为感动，请玩家带一块温玉送给摇爷。对于玩家的宅心仁厚，摇爷大为赞赏，把“水行令16”交给玩家继续寻找水之力量。

东码头（33 17）“[硬骨鳄](/pets/115)”的几个孩子不知天高地厚，成天就想着出去闯天下，让这位当母亲的很是担心。为此，想请追寻水之力量到此的大智慧之人帮忙说服它的孩子回家。

自认为实力在水族中已经是数一数二的“鳄鱼兄弟”们正在西码头玩耍，它们向往的是更为广阔的世界，想创出自己的一番天地，如何肯听从母亲委托人的劝告。要想让它们回家只有打败它们（10只2300的硬骨鳄）。

在见识了玩家的手段后，鳄鱼兄弟终于明白了天外有天的道理，写下了“孩子的悔过书”交给玩家。看到悔过书后，“硬骨鳄”深表感谢，将“水行令17”交给玩家。

并且，只要玩家从树成宠物店愣头青那得到的水族幻兽——巧巧的等级为800-**1000级**，它还会将巧巧的等级增加**201级**。

新山城（73 84）“[绿甲](/pets/126)”有位朋友“疑惑”身为水族的一分子，却对水的力量不甚了解。想请追寻水属性力量的而来，对水之力量已经颇有研究的玩家帮忙去提点一下。带着绿甲的嘱托到深蓝海城找到“疑惑”，它想请教你水的力量的特点。

回答疑惑的问题后会得到与你所答的内容相应的物品，回到新山城交差，只要你的答案是对的就可以得到“水行令18”

水族有一件世代相传的镇族之宝，叫做避水珠，有了这样宝物，即便是凡人也能去任何有水的地方。但在前些天水族庆典的时候，有人把避水珠偷了去。镜雪原（36 41）的“大嘴鳄”想请追寻水之力量的水族朋友帮忙找回宝物。

偷盗“避水珠”的“小贼”远逃到了观日桥头（34 12），当玩家找到小贼后他会矢口否认偷了避水珠，只有使用武力战胜他手下的10只2500的[酷毙象](/pets/56)，他才会把避水珠交出。镜雪原“大嘴鳄”深感大德，将“水行令19”交给玩家。

居住在炮烙地狱（30 41）的“铁甲龟”常年与朋友失去联系，很是想念以前的老朋友，想给远在雪城的灵衫捎去一封信。

得到多年失去音信的朋友的问候，灵衫颇为感动，由于“铁甲龟”一直以来腿脚就不便，为了让它早日康复，灵衫让玩家带“活络油”给铁甲龟。

不仅联系到了朋友，而且还感受到朋友的关怀，铁甲龟感激涕零，答应将“水行令20”送给玩家，同时将玩家身上所带的**800级**至1000的[彩衣](/pets/133)（巧巧进化而成）增加**201级**。

“[丸子鱼](/pets/142)”在武当练功房苦苦修行，正到了即将进化的紧要关头，听说人类有升级药可以提升级别，因而想借助升级药的神奇功效来突破修练途中遇到的障碍。送上升级药，丸子鱼就会兑现诺言给你通往下关的“水行令21”。

弱肉强食的江湖，实力证明一切，只有强者才能通过山城宠物店“[戛戛](/pets/123)”的考验。“戛戛”有个兄弟在华山一带训练手下。带着“戛戛”的“考验推荐信”去华山脚找“幻兽训练官”，如果能打败它手下10只**2700级**的戛戛就可以得到一块证明你通过考验的“验证之石”回山城宠物店向戛戛换“水行令22”

“[粉衣仙子](/pets/138)”虽然荣登仙籍，但却没有得到仙境居住权，只好跑到降尘台 (66 79)暂时落脚，为了能在仙境中活得更好，粉衣仙子多次向“仙界管理员”（紫阳门 26 8）申请居住权，却始终未能如愿。

原来要得到居住权的办法只有两种，一种是花费200万两银子来购买，一种是通过暴力来夺取（10只2900的地藏）。当玩家为粉衣仙子“居住权证”后就可以得到“水行令23”

皇宫中一年一度的幻兽大赛就快要到了，居住在皇城（81 91）的“[乒乓鱼](/pets/143)”想在这次大赛中出人头地，但听说今年有许多厉害的家伙参加，因而想找一种叫“幻兽之灵”的饰物来提升能力。

而此种饰物只有在遥远的凰之谷中有位隐居的“老工匠”才会制作。由于制作幻兽之灵的一种必须材料——兽玉已经没有了，如果玩家能拿到这种材料（出谷战斗就有机会得到物品“兽玉”），“老工匠”会破例帮忙做一个。

得到幻兽之灵的乒乓鱼为表示感谢，会把通往下关的“水行令24”送给你。

水系幻灵兽是所有幻灵兽中最庞大的一系，逆之往事（23 52）的“悠然老人”对玩家能做到这一步大为吃惊。只要玩家的水系图鉴做了20个就可以回答悠然老人提出的问题。根据回答的不同选择不同的考验者。

如果回答“我想要拥有强大的力量”，就可以得到霸王令去找敖雪兽霸气通过考验。如果是回答“对未知的力量的好奇心”，则得到奇云令，可以去找[幻云兽](/pets/151)瑶奇接受考验。

霸王令任务：

水族中有一件宝物——聚水珠是由空灵园（31 87）找“敖雪兽霸气”保管的，后来它出游时不慎丢失了，对此它一直耿耿于怀。为了考验追寻水之力量的人的智慧和勇气，霸气要求玩家去寻找聚水珠。

如果玩家能帮忙找回遗失的宝物，就可以顺理成章的得到水属性的力量了。为了寻回宝物，霸气委托它的朋友石老头帮忙调查此事。带着霸气的族长令去将军碑谷找石老头，就可以得知聚水珠落到了一个叫乌云盖天的豪杰手中。

这家伙的脾气孤僻，很难对付。要从他手上拿回聚水珠恐怕很难。石老头让玩家带着名帖去名剑山庄练功房找“乌云盖天”。性格孤僻的他要求玩家打赢了他的幻兽才肯给出聚水珠。

完成任务后，带上聚水珠去找霸气，就可以在霸气的帮助下提升**300级**的等级（当然不超过最高等级），并得到碧水令。到此完成水属性任务霸王令剧情。

奇云令任务

带着“奇云令”到空灵园找幻云兽瑶奇。瑶奇要玩家完成两件事情就算通过它的考验。其一是，它听人说皇城中有种叫翡翠白玉汤的东西，是天下的美味，常心向往之，只是无缘得以一尝，希望玩家能帮它取来，了却心愿。其二就是要玩家把所带着的水族的[彩虹仙子](/pets/137)（彩衣进化而成）练到**800级**。

皇城甬道（13 18）的“悟食老人”大内御膳房的总管，小小翡翠白玉汤对他来说自然不在话下。

但是假公济私的悟食老人家中修缮园子尚缺10万两银子，如果玩家答应出这笔钱就可以带着“悟食老人”的家书去水城找正在筹钱的“悟食老人”的儿子悟施人交钱。交给他10万两银子后就会得到一封家书回悟食老人那换翡翠白玉汤。

带着“翡翠白玉汤”，并让**800级**以上的彩虹仙子处于出征状态，瑶奇就会用水属性的力量把“彩虹仙子”进化成“[敖云兽](/pets/154)”。
