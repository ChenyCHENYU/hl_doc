# 火属性任务”攻略

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

恒河星溯变化出奇、层出不穷，一种神秘的力量创造了幻灵世界。

但是很少人对此有所了解，将毕生心血投入于研究的悠然老人，在花费了一生精力之后，终于对此力量有了一些了解，常常在断壁一带的悠然老人（**58.48**）对好学的人是很热心地讲解构成幻灵世界的神秘力量的情况，以及由此神秘力量一分为五繁衍出的各系幻灵兽的故事。

了解这些情况以后，可以知道，如果想追寻那五系的力量，则需要通过各系各个宠物的考验。

双印谷逆之洞窟外的[乐乐熊](/pets/188)思思，他听说逆之洞窟里头有一些他没有见过的熊猫[绿锦宝](/pets/268)，所以想来此地寻找绿锦宝陪他玩耍，不料绿锦宝呆在洞窟最深处，而此洞内还有其他猛兽盘踞，所以思思不敢进去寻找绿锦宝陪他玩，玩家若是愿意帮助他，找一只一级的绿锦宝来陪他，思思为了表示感谢，将一块火行令交给他，告诉玩家凭这令牌就可以继续接受火系考验了。

收下令牌后思思提示玩家去找他的兄弟[欢欢熊](/pets/189)欣欣接受考验。

十步杀一人，千里不留行！是多么潇洒的江湖生活写照，一心想过仗剑江湖、快意恩仇的生活的欣欣呆在水城的一艘船上（**48.85**）。欣欣虽然有心进入江湖，却苦于无一技傍身，一直没能通过蔡参将的考验。

带着火行令一，找到欣欣，欣欣会请玩家帮忙寻找学习催眠所需要的训兽经，带训兽经给欣欣后，可以得到火行令二。并得到提示寻找[蜜蜜熊](/pets/190)安安进行下个考验，听说安安在很久以前被人收服去看守一个神秘的地方。

幻灵中由幻灵兽看守的地方有夫妻天关、单人天关等地，经过摸索来到了单人天关的第四层。看守第四层的果然就是安安。安安发现玩家身上带有火行令，便询问玩家是否来此接受考验，并拜托玩家帮忙寻找他的妻子静儿。

同意后离开天关来到山城，遇上失忆的静儿（**65.71**），为了帮她恢复记忆，玩家跑到华山找到采药人朱照启求取灵药华岳仙芝，花费6000钱两后得到华岳仙芝给静儿，静儿恢复了一些记忆，但是由于身体还过于虚弱，所以请玩家帮忙带送家书给安安，安安收到家书后，为表感谢就将通过他考验的证明-火行令三给了玩家。

带着火行令三到将军碑谷找到正在水边观赏鱼儿的[迷惑](/pets/191)小华，小华很喜欢鱼，听说海底之城聚集了世上最美的鱼儿，因此很想去那里，所以请玩家帮助寻找一只一级的[乒乓鱼](/pets/143)好让他可以变化成乒乓鱼的样子混入海底之城。帮他找到乒乓鱼后可以得到火行令四。

喜欢到处旅行的[迷茫](/pets/192)小伟这次却被沙盗洞穴而难住了，他听说这个洞内怪石嶙峋、景色幽奇。于是远道而来想进去观赏，可是到了沙盗洞口(**36.27**)才知里面怪物凶狠异常，小伟打不过它们，可又不想空跑一趟，很是为难。

他心想少林武功独步武林，想学会少林金刚掌定能打败那些怪物，所以请玩家帮助找到学习金刚掌的佛经给他，让他可以学习。（临时抱佛脚？！ ^0^）帮他找到佛经可以得到火行令五。

天生没有方向感却又疼爱老婆的[小妖](/pets/193)阿威，由于老婆喜欢[雪凤凰](/pets/17)，于是就打算跑到凰之谷找一只哄老婆开心，却不料由于自己一时小气没买小贩兜售的地图，加上自己没有方向感，没走一半就在暮归道（**8.28**）这儿迷路了。只好请玩家帮忙找一只一级的雪凤凰好回家交差。帮了他的忙后可以得到火行令六。

百兽之王辛巴最喜欢在敕勒川（**80.50**）晒太阳，玩家找他接受考验时，着实让不喜欢追求力量、喜欢开开心心过日子的辛巴头疼了一把。

经过思考后辛巴出了个不算太难的题目给玩家，他听说水城下有个宝洞，宝洞内有很多宝箱，其中褐色宝箱中有不少好东西，但是需要有对应的褐色宝箱钥匙才可以开启。于是请玩家找一把褐色宝箱的钥匙给他。

帮他找到褐色宝箱的钥匙后可以得到火行令七。

银罐谷的[匆匆](/pets/195)小遥（**45.27**）对追求力量的人都是严格考验的，必须向他证明了自己有足够实力，否则是无法通过考验的。通过和他战斗，打败五只六百级的匆匆后可以得到火行令八。

怨灵洞口的[西皮](/pets/196)希亚（**36.63**）他曾经见过沙城每日的PK竞赛中在竞技场内维持治安中的林捕头的玉佩，并且非常喜欢，想购买但是林捕头不愿意割爱。但是希亚对那玉佩念念不舍，朝思暮想。帮他找来林捕头的玉佩，就可以得到火行令九。而且他告诉玩家，如果要继续接受考验需要去找[旺旺](/pets/197)小天。

据说小天很怕热，所以躲在太阳晒不到的地方。来到铜人殿找到怕热的小天（**77.57**），他告诉玩家如果能帮他弄来冰晶，那玩家需要帮忙的地方他也尽力帮忙。

了解了冰晶的来源以及好处后，来到玉洁桥，如果恰巧遇上常枫，那么可以向他打听冰晶的情况，可以了解到在此处战斗时有可能得到这里怪物所收藏的冰石，当得到六个冰石后就可以请常枫帮忙将冰石提炼成一块冰晶，提炼冰晶时必须注意一定要带好六个冰石再请常枫帮忙提炼，如果数量不够，常枫提炼一半不但会白费功夫，而且会浪费玩家辛苦打到的冰石。

得到一块冰晶后就可以拿回去给小天，小天看到冰晶后很高兴，他询问玩家是否愿意带着他的一位族人一起接受考验，同意后可以得到一只一级的旺旺和火行令十。

山城的小阳（**115.78**）为了购买烟火，特地跑到山城来等待江南霹雳堂的人，结果一直没等到。若玩家帮他买了一只烟火，可以从他这里得到火行令十一。

一心向往大草原的风影虽然已经从主人身边离开，但是由于顾虑小主人虫虫的感受，左右为难地停留在青幽洞（**13.30**）中。他请玩家帮忙给虫虫送封信，带着风影的信到水城找到虫虫（**79.79**），可以感受到他们之间深厚的情谊。虫虫看完信以后也请玩家帮忙带回信以及口信给风影，做完这些送信工作后，可以得到火行令十二。

梦佛窟外可以找到晓风，他因为怀疑自己珍藏的火之念珠失窃是与[嘟嘟鸟](/pets/13)小月有关可又没有证据，如果玩家带着火行令十二并对火属性了解了14只或以上，晓风就会让玩家帮忙找回念珠。

同意后来到明月桥上找到小月（**10.8**）打听火之念珠的事，小月由于被冤枉很是气愤，于是说要玩家打败他才透露有关念珠的事。和他战斗打败五只八百级别的嘟嘟鸟后得知是深蓝海城的[绿甲](/pets/126)拿去的。

到深蓝海城的深蓝海底与绿甲战斗，有一定机率得到火之念珠.

带着这念珠就可以回去找晓风了。找到晓风时可以知道如果身上带有一只精心饲养的等级在**800级**到**900级**以内忠诚度100的旺旺，并处于出征状态就可以接受晓风的考验了。带上合适的旺旺并出征后，如果是精心饲养的，也就是说成长比较好的旺旺，那么就可以通过晓风的考验并得到了两百级的等级奖励和火行令十三。

带着火行令十三到瑞天雪城找到洛影，他很喜欢可爱的幻灵兽，一直希望有一只可爱的[小叮咚](/pets/266)能陪他玩，但是由于小叮咚在天空之城，所以一直未能如愿，玩家若帮他找一只一级的小叮咚来陪他玩，就可以得到火行令十四。

华山的小狼仙（**33.43**）很羡慕胡狼与宁静雪（雪狼湖任务）的真爱，所以很想要代表真爱的白色绣球花，通过雪狼湖任务得到白色绣球花后给小狼仙可以得到火行令十五。

在雪狼崖的老狼仙（**27.26**）有一个朋友蝶依，他们两族之间虽然水火不容，可他们之间的交情很好。老狼仙听说蝶依出事情了（名剑山庄任务），很是担心。

但是由于自己不便出面直接去找蝶依，所以请玩家帮忙代为打探消息，玩家可以通过树城的灵儿到寒月台找到蝶依，将老狼仙的信交给蝶依，并带蝶依的回函给老狼仙可以得到火行令十六。

老狼仙会着重提示下一个考验需要找阿蒙，告诉玩家阿蒙喜欢懂礼貌的人，要记得打招呼。

在武当前上遇上由于练功不慎走火入魔而到武当来找张真人求治的阿蒙，他喜欢懂礼貌的人，所以如果没有使用动作与其招手打招呼，他是不会搭理人的哦。

边招手边和他说话了解情况后，知道了他需要归元仙露才能尽快恢复，于是在阿蒙的提示下到了酒鬼冢找高阳酒徒询问归元仙露的情况。

高阳酒徒由于口渴难耐，就写了封索酒信让玩家先帮他到名剑山庄找张一丁讨要极品状元红并让玩家去找玉露丹，带上名剑山庄的极品状元红和玉露丹后再回去找高阳酒徒。此时才知此两物品是制作归元仙露的关键材料。

高阳酒徒制作好归元仙露后自己先抢喝了几口才给玩家，带着归元仙露回去给阿蒙，阿蒙为了表示感谢，就将火行令十七交给玩家。

带着火行令在教堂外找到赫鲁斯（**89.63**），必须对火属性了解程度达到14只才可以接受他的考验，他会请玩家帮助寻找广陵散。根据赫鲁斯的提示，到英雄冢的传说中的英雄冢战斗，打败1300左右的[黄锦宝](/pets/269)有一定几率得到广陵散。

找到广陵散并带着精心饲养的等级**800级**到**900级**，忠诚度一百的[啮风犬](/pets/201)就可以去找赫鲁斯接受考验，通过考验后可以得到火行令十八，接受考验的啮风犬也可以得到两百级的等级奖励。

在敕勒川大蓬内的阿图姆，见到玩家以后对玩家能通过这么多考验表示难能可贵，让玩家尽情地展现实力与他战斗，需要注意的是这里有支线情节。

在阿图姆处可以得到火行令十九，并了解到接下来的考验是由火系终极幻灵兽进行，火系终极幻灵兽有三位，只能选择其中一位来接受考验而无法接受其他两位的考验以及需要找悠然老人询问适合自己的考验者的情况。

在断壁找到悠然老人，根据回答的不同选择不同的考验者，分别是[火妖精](/pets/207)魅影、[绿妖](/pets/208)碧云。选择好合适的考验者后可以得到相应的令牌：火魅令或者绿影令。然后按照选择不同进入不同的任务情节。

魅影剧情：

根据悠然老人的提示，到水城宝洞那里去寻找魅影。原本只能由阿修罗或者魔神进入的阿修罗、魔神修炼圣地，现在只要持有火魅令或者绿影令就可以得到特许进入了。

在守侯洞窟找到魅影（**29.52**），需要对火属性了解18只或以上才可以继续接受考验。听魅影讲述完她们姐妹之间的往事后，魅影请玩家带信给碧云。玩家必须让她们姐妹和好才可以通过考验。

通过暮归道的小妖阿威可以到达百草池，百草池是个美丽的地方，碧云就在这里（**29.17**）。

带着魅影的信给她后得知其实她并没有生魅影的气，她请玩家帮忙找回她妹妹璇紫多年前被名盗柳随风盗走的白玉扇并交给璇紫，同意后碧云将一对碧星耳环交给玩家，让玩家一并带给璇紫。

通过英雄冢任务中获得白玉扇后，到夜晚的时间伤口找到璇紫，璇紫收下白玉扇与碧星耳环后会给一枚碧玉扳指，带碧玉扳指回去给碧云后，碧云就给了玩家一对烈炎耳环，带着这烈炎耳环就可以回去找魅影交差了。

此时如果带着满足条件，也就是八百级以上**忠诚100**的[幻变天狼](/pets/205)并出征，就可以接受魅影的考验。通过考验的话，接受考验的幻变天狼就会进化成火系超级幻灵兽，并得到一枚风火令。到此完成火属性任务魅影剧情。

碧云剧情：

在百草池找到碧云，喜爱自然的碧云认为只有有实力并且心性善良的人才适合拥有力量。她听说沙城的人们遇上一些麻烦，请玩家帮忙解决此事来证明自己的实力与心性。

到沙城找到胡老头（**75.66**），知道沙城的水源被一伙[强盗](/pets/101)占据的事情，并了解到那些强盗可能是火系超级幻灵兽璇紫的手下。同意帮助沙城的人后，得到沙城的委托信。

带着委托信到夜晚的时间伤口找到璇紫，原来那些强盗不是璇紫的手下，而是魅影的手下。替璇紫找回丢失的白玉扇后，璇紫给玩家一枚黄玉戒指作为信物。带着这信物到守侯洞窟找到魅影，魅影看在璇紫的份上，就将自己的令牌给玩家了。

将魅影的烈炎令交给胡老头，就可以凭借此令解决沙城的水源问题了。这样就可以得到胡老头代表沙城百姓写的感谢信。

碧云看到感谢信就让玩家通过考验，并给玩家一颗九阳丹和一块风火令。只要带着九阳丹找碧云，就可以在碧云的帮助下提升**300级**的等级（当然不超过最高等级）。到此完成火属性任务碧云剧情。
