# “天魔解体”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

先去武当炼丹房找“元元真人”，他会告诉你去华山找“朱道友” 。

然后去华山腰道找他，跟他对话会得到“无极草”。（朱在右上紧靠地图右边的地方，没有道路的，只能跳过去）

再你把“无极草”交给元元真人，打完800的[刚雷狒](/pets/74)后会得到“无极天魔丹”。

接下来拿着“无极天魔丹”去吊烤地狱找“魔女”，她会问你：[天魔解体大法]是很危险的，他要让你失去五分之一的等级，然后将剩下等级的一半参数返还给你。（大体这个意思）

最后就是你的问题了，按不按确定，掉不掉级别？ 你自己决定哦~

任务的注意事项:

**一**：等级**600级**以上就可以做这个任务了

**二**：天魔解体必须下降20%的等级

**三**：剩下的一半等级的属性点数可以重新分配

**四**：在解体以前最好把未分配的点数分配完哟。

大家如果有需要，就可以通过这个任务重新分配部分点数了~~~：）
