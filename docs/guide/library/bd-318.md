# 开启乾坤五行炉任务

<TopicHeader cat="玩家文库 · 锻造-饰品" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

在山城药店门口可以遇见药王（27，35），从他那里听说了乾坤五行炉的情况，了解到武当的元元真人正是当今世上少数懂得使用乾坤五行炉的人。找到药王炼丹所需要的无极草与药王交换可以得到药王佩。

带着药王佩到武当练丹房内找到元元真人，元元真人会先考查玩家对乾坤五行炉的基本常识。（这些都是常识性问题哦，很容易的。）当三个问题都答正确后元元真人会赠给玩家一个乾坤五行炉并且指点了玩家的炼化入门知识。

这样，就可以开炉炼化咯！只要点高级=》乾坤五行炉即可。

三个问题以及答案如下：

一、乾坤五行炉中最多可以同时放入几样物件进行炼制？ 答：8个

二、乾坤五行炉是根据天地间的什么原理而来的？ 答：五行 （顾名思义就知道了哦!）

三、在乾坤五行炉中武器是属于五行属性中的哪一个？ 答：火
