# 退江湖（关闭pk）任务

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

如何关闭PK执照（关闭之后其他玩家不能PK您，您也不可PK其他玩家)

吾入江湖数十载，历经无数血雨腥风(就是常见自己的星星而已，^0^），心有倦意，但我不P人，人P我。今天终下决心，退隐江湖。（被一个黑社会追杀，想不退都不行了）

在水城当铺旁与贤者倾诉退隐之意，他告诉我带着本金刚经找少林的慧明大师(也就是少林唯一的和尚)可帮我主持金盆洗手。于是，日夜兼程，奔赴少林(一路被人打，星星又看了几次，唉)。

慧明大师知道我的来意，为试我心诚否，指定我找寻一只一级忠100的[苦行龟](/pets/118)于金盆洗手中放生消除戾气。素菜我都不吃一口，奔往树城。

告诉你吧，这么多年江湖我也不是白混的，得到一级苦行龟的最快捷径就是做名剑山庄的捉龙换龟的任务，要去名剑先要从树城便利店旁的灵儿姑娘那得到香包才会有钓鱼翁愿意送你去名剑。

得到香包就去吓死人洞二层捉只三百多级的[纹地龙](/pets/272)再去东码头找钓鱼翁去名剑，进名剑之后找到左上方的小女孩换到一只苦行龟了。

再回少林，慧明大师就会帮你主持金盆洗手当画面上显示“系统”“昭告天下，从此金盆洗手，退隐江湖：恩恩怨怨，一笔勾销”时金盆洗手成功，洗的真干净呀!

（呼，真是险啊，好几十人追到少林来P我呀，小命总算保住了，嘿嘿等我练成绝世武功，你们一个都逃不要，什么!你们也金盆洗手!晕!!!)

**出场人物**：一个打不过就逃的高手中的高高手、贤者、明慧和尚、灵儿、钓鱼翁、小女孩、放生后却被我堡汤的苦行龟、被我玩够的纹地龙、一群没良心的黑社会.

**关键人物出场坐标**：贤者(水城)：66， 71 /明慧和尚(少林)：12, 5 / 灵儿(树城)：30, 33 /小女孩(名剑山庄)：20, 40 /渔夫(东码头)：53, 64
