# 物混乱技能任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

来到新天空之城喷泉（27,39）找到正在补天的女娲，女娲会请你去帮忙到西天界找修炼千年的巨鳖取回天柱以将西斜天的撑起。

在女娲的帮助下来到西天界，巨鳖拒绝将天柱交出，便可与之及其弟子进行交手，两轮胜仗后可将天柱取回交给女娲。

为表示感谢，女娲将送你一件神奇的礼物，它能让你的出征宠学会“混乱攻击”的技能，但此技能密笈暗藏在一块神铁中，神铁被女娲身边的[黑龙使](/pets/279)偷走，女娲便会请你再协助将神铁寻回，并给你一块召唤神铁的磁铁。

来到深蓝海底（25,27）找到黑龙使，打赢它后将神铁和磁铁取回带给女娲，女娲便信守承诺将宠物“混乱攻击”的技能密笈赠予你。
