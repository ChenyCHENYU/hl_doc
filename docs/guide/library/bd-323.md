# 宠物催眠任务技能

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

在雪城宠物店跟小白（20，22）说话，他会让你找一只一级**忠诚100**的[苦行龟](/pets/118)跟他玩。

给他一只一级**忠诚100**的苦行龟，他就会给你一本训兽经。

然后到沙城宠物店找小红（21，17），将训兽经给他，并且通过他的考验（3只**200级**的[迷惑](/pets/191)），他就教你的出征宠物一招催眠攻击。
