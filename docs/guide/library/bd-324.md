# “醉拳系列”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

这个任务只适合攻击点：1000，内力点：2000的玩家。

先完成逍遥战衣的任务，然后带着逍遥战衣找到浪子剑阿锋，他会给你一把醉龙舞雪剑。

然后到东码头找到钓鱼翁（53，65），他会让你拿一只一级[红大嘴](/pets/9)跟他换醉生梦死酒。

然后到酒鬼冢找到高阳酒徒（39，24），把醉生梦死酒给他，他就会教你一招醉拳。

::: info 玩家提示
- PS：醉龙舞雪剑：攻击 +300 防御+100，敏捷-100
- PS：醉拳：使用等级：600，消耗内力：600，攻击效果1080。
:::
