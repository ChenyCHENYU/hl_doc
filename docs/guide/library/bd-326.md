# “乒乓鱼”任务

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到雪城宠物店(23,11)找[花花](/pets/86)说话,他会让你帮他从地狱救一只一级的[小丁当](/pets/264)回来。

去地狱抓一只一级的小丁当,回来找花花说话,他会给你一根"人鱼项链"。

到沙城宠物店（11，18）找小仙说话，如果同意将"人鱼项链"给她，她会让一只一级的[乒乓鱼](/pets/143)跟随你。
