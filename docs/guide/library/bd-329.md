# “名剑山庄”任务

<TopicHeader cat="玩家文库 · 宠物分布" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

**任务NPC位置**：灵儿 树城 坐标29,32

钓鱼翁 东码头 坐标52,64

张一丁 名剑山庄正院 坐标49,82

小鱼 名剑山庄正院 坐标18,50

**任务流程**：首先身上要有一只300多级的[纹地龙](/pets/272).然后去树城找灵儿带个香包交给东码头的钓鱼翁既可去名剑山庄,到山庄内找小鱼将宠交给他任务完成,可得到一只一级[苦行龟](/pets/118).
