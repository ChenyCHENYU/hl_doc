# “庄周梦蝶”任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到观日桥找到惠子（11,13），惠子会问你鱼儿是否是快乐的，如果你告诉他鱼儿是快乐的，他便会和你探讨一番鱼儿是否快乐的哲学，并在你的认真坚持下，让你带上一只[乒乓鱼](/pets/143)和一封手书去找能通晓鱼儿语言的庄子。

如果一开始你就认为他是神经兮兮的，惠子便会让你带上一只乒乓鱼和一封手书去找庄子，让庄子研究一番后来此与他探讨鱼儿是否快乐的哲学。

到闲情园（30,27）找到正在白日做梦的庄子，如果你手上有庄子手书和乒乓鱼，庄子便会告诉你鱼儿为什么是快乐的，并会告诉你他其实是一只蝴蝶，不论你认为是真是假，除非你对他不礼貌，否则他都会告诉你他梦见自己化身为蝶，在花间翩翩飞舞，并指点你一些做人的道理，为了表示感谢，你可以帮他找到他的花魂-代表真爱的白色绣球花，并把乒乓鱼赠予他，他便会送给你一件梦蝶佩（0级+防30的右饰）。
