# 幻灵“进入英雄冢”攻略

<TopicHeader cat="玩家文库 · 锻造-饰品" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

到瑞天雪城找到徐天麟（73，26），他会让你帮他找女儿，并且给你一个苦艾香囊。到皇城的大殿里找到徐君如（29，30），他会告诉你她被人劫持的经过，并且给你一块大内通行令，让你帮她找回家传的翠羽钗。

到凝露山城找到周仁（52，91），跟他说完进入战斗（10只**1350级**的[旺旺](/pets/197)），战斗胜利得到翠羽钗。然后回去找到徐天麟，他会给你一块英雄令，带着英雄令找徐君如就可以进入英雄冢了。

进入英雄冢，到最底层可以看见有五个人分别站在五个角，这里是五位战死英雄埋骨之地，只要玩家为这些英魂完成一系列任务将可得到英雄们的承认，为玩家举行传承英雄力量的仪式。

首先找右下脚的柳随风（39，17），他告诉你在子时到午时可以找下面的守护神兽说话. 打赢1235的[幻云兽](/pets/151)后拿到神兽令,叫你在午时到子时再与柳随风说话。柳随风会让你帮忙到华山的某个地方帮他把隐藏的东西取回来。

玩家答应后可以得到一块玉佩。到华山瀑布找夜行兽（4，14），对话后进入战斗（10只**1400级**的[蓝大嘴](/pets/8)）。战胜后夜行兽会给你一把白玉扇，让你再去找柳随风。

将白玉扇交给柳随风后他会给你一个神偷令牌，让你去鹰枪无敌何轻烟（英雄冢22，23）。与何轻烟对话，他会给你一个磁气瓶让你帮忙到敕勒川替他找魔鹰。

到敕勒川找到何轻烟的化身为[火凤凰](/pets/18)的魔鹰后与之对话可以得到一个火凰草去何轻烟那里交差。交给何轻烟火凰草就算过了这关了，何轻烟会给你一块神鹰令去找钟离剑。

带着神鹰令去找钟离剑。原来钟离剑是铁剑门的掌门，按铁剑门的规矩，掌门卸任时应该掌门铁剑留给下一带的掌门。

但钟离剑在与魔头的血战中死了，掌门铁剑也不知下落，只要玩家能帮他找到遗失的铁剑，并且把剑交给华山脚下的铁剑门门人，他就会推荐你去见他的兄长禁军统领——沈铁衣了。钟离剑让你带着一块原来挂在铁剑上的玉佩到沙漠去找线索。

在遗忘之地会碰到一只喜欢收集各种东西的幻灵兽（19，62）在这渺无人烟的荒漠地带难得碰到一个人，幻灵兽提出只要玩家跟它过过招，就可以把铁剑奉上。答应后出现10只**1500级**的[黄龙使](/pets/280)。

战胜这些黄龙使，就可以得到铁剑门的掌门铁剑。把铁剑交给华山脚下的铁剑门弟子（29，62），带上他给的铁剑副令就可以回到英雄冢找钟离剑交差了。为了表示对你的感激之情，钟离剑会给你一块令牌让你去找沈铁衣。

对于玩家到来，沈铁衣深感诧异，因为几乎没有人来到过他这里，但是对于玩家是否能继承5位英雄的力量，他还是要进行一番考较。

沈铁衣当年深受皇恩，为了报答知遇之恩，他会让你带着他的“铁军令”去帮紫禁城的江大人收服两个不受皇家约束的江湖帮派。带上令牌到紫禁城找江大人（51，45）。

他会告诉你凰之谷的权利帮和梦佛窟的金钱帮与朝廷作对，让你去收服这两个帮派。在凰之谷战胜权利帮帮主（30，25）及他的手下10只1600的[飞天鼠](/pets/23)，可以得到权利令，表示该帮派从今以后听从皇家的指挥。

梦佛窟战胜金钱帮帮主（89，62）及其手下10只**1600级**的飞天鼠可以得到代表该帮最高权利的金钱令。降伏两个帮派后，带上权利令和金钱令回到江大人那交令，为了表彰你的功勋，会给你一个奖牌。

带着奖牌玩家可以回到英雄冢去找沈铁衣。由于完成了沈铁衣生前的夙愿，他对你感激不尽，会让你带着他的信物“中军令”去找最后一位英雄——江湖浪客顾人来。

验过令牌之后，顾人来会让你带着他的古瓷瓶到他出生的小鱼村去看看，顺便帮助那边的村民。在顾人来的家乡不归海岸你会碰到一个顾老头（12，37）。看过古瓷瓶，他会向你述说最近来了一伙海盗想把夺取村子作为他们的分舵。

战胜海盗手下**1700级**的[绿甲](/pets/126)后，你就算通过了顾人来这关了。带上顾老头的粽子就可以回去见顾人来了。

见到顾人来后，他对你的侠义心肠大为赞赏，认定你就是继承他们力量的最好人选，会把一块“英雄令”给你。让你去找守护兽替你举行传承仪式。

在适当的时间（子时至午时）再去英雄冢找守护神兽，奉上英雄令，它就会替你举行仪式了。仪式完毕后，玩家可以获得的物品将不再单一的为“九转天仙丹”。将随机获得“9转元阳丹”、“9转蕴灵丹”、“10元宠物礼包”等等。想知道获得的更多物品，那么现在就出发吧！
