# 猎人迷药任务

<TopicHeader cat="玩家文库 · 任务与飞升" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

在猎人洞窟里(14,33)附近的地方打[嗷日犬](/pets/199),可以随机得到"猎人的迷药".

拿到"猎人的迷药"后出来跟李月蝶(14,36)说话,可以得到"用过的猎刀".

带着"用过的猎刀"到水城(57,89)找快手老王说话,可以得到一颗"升级药"

(可以升5级,吃了可以直接过天劫哟).
