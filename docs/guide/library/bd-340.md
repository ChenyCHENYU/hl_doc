# 当你登陆游戏游戏遇到以下只有一半画面的时候？

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵游侠宝典2009版.exe" />

> 来源：《幻灵游侠宝典2009修改版》（游戏内资料查询器，Mission.txt 数据包），条目化整理保留原意。

右击HL桌面图标-选择属性-属性里面的兼容性-勾上兼容性-选择WIN98和ME.确定重上.

或者你可以将兼容性里面的 禁用视觉 勾上就可以了

如果选择了兼容性后,聊天记录出现只有一行的问题..那么将禁用视觉勾上试试.
