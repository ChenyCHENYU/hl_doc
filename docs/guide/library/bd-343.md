磐龙樽+230防宠装数据

1，准备工作：磐龙樽一个，草鞋一双，水城最便宜头饰一个

极限（4251）血佩四个，极限（4251）内带三个

2，磐龙樽减敏减血

原料磐龙樽：

**减敏**：草鞋9点，磐龙樽7点主炼

**减血**：上面得到的装备7点主练，水城最便宜的头饰5点
