# 『天下幻灵』 浅谈PK宠！

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**浅谈PK宠！**大家玩幻灵的朋友，有的喜欢PK有的喜欢聊天，我想最主要的还是练宠吧！  
练宠的朋友也可以分成几类，1，随便练个练级的宠，2要求好看的外加成长高的，3练PK宠。  
本人就喜欢PK宠，下面我谈谈我练PK宠的经验。  
首先当然要选终极宠，少进化一次的宠的成长跟不上，还要选每个属性的终极宠里敏成长最高的（落后就要挨打）。现在金系里没有敏宠，所以金系在3。0前，是没有PK宠的！  
1，PK宠可以说是对成长的要求比较高点，如果你的成长低了，就没有那么多的点数分在攻防敏的上面。我个人意见，现在的PK宠最起码要54+的。  
2，PK宠对原始攻防敏所分配的比例的要求一点不比成长低。  
应该知道PK宠的敏捷是决定谁先出手的，先下手为强啊，单P的话谁先出手谁就占了70%以上的胜机，团P的话先出手的一防可以说是占了90%以上的胜机。有的朋友要问你光有敏没有攻秒不了人怎么办？当然攻击也很重要，但是我个人认为攻比敏的重要性差很多。最没有用的当然是防，所有说一个PK宠的好坏，首先看他的防能降到多少低了。  
PK宠可以分成2种  
1，攻击2。2万，防2000左右，敏（看你这个宠的成长了，当然越多越好），这样的宠可以秒对方的低防的PK宠。（代表是熬雪）  
2，攻击在2。7万，防2000左右，敏（看你这个宠的成长了，当然越多越好）这样的宠基本上能全秒，攻击有2。7万还秒不了对方宠的话，那对方的宠根本就没有足够的敏捷能打到你的宠了！（代表是[紫衣](/pets/209)和幻云）  
下面我再谈谈练PK宠的过程。  
有的朋友要说，我把宠锻造一下就行了，问题是大家都会锻造啊，而且锻造是有极限的，所以根本就在于这个宠的原始攻防敏所占的比例了，（最好的第1种比例是攻击在30%左右，防在17%—敏53%+，第2种比例是攻击在45%左右防在20%敏在35%）。要做到这点就要在找原始材料的时候最好找敏型的，在幻化过程中先锻造，再加装备幻化，尽量把原始主宠改造成敏型的。  
有的朋友要问，你幻化前就锻造会不会影响成长，这个问题我不是很清楚，但是就算影响点成长那也不是很多，所得到的好的3W比例比掉那么一[点点](/pets/88)成长所得到的好处有用的多！54+的3W比例好的可以赢55。5+的3W比例不是很好的宠，大家可以去看看上榜的的熬雪  
幻云 紫衣 !  
最后总结一下，PK宠就是成长加3W比例！(锻造熬雪和紫衣的方法,全是在没办法的时候实验出来的!)

**补充1**我的熬雪是：  
0幻6。76的[珍珍](/pets/132)，0幻15。35的地藏（7点蝴蝶出的垃圾）2个宠加敏戒指幻化的，出1幻多少珍珍的我忘了，1幻24。37的地藏，2个宠加敏戒指幻化的，出2幻满级21。95的珍珍。  
2幻的副宠是从星光那里买来的38。95的啊怒。  
在幻化前，我发愁了，我的珍珍本来就是攻型的，再加上啊怒的攻防行的，那幻化出来肯定不会是高敏型的了，而我要的就是高敏。最后自己发急了，决定试验一下先锻造再幻化会怎么样，掉不掉成长已经不在乎了，就用极限鞋子把2个宠锻造了一下敏捷，再各带个加攻100点加敏120点的戒指（为了把防的比例降下去）幻化了，结果天逐我原，出来个高的敏的珍珍，然后一路进化到熬雪。在311级的时候我的熬雪的敏占的比例是53%，我就用极限鞋子锻造了一下，以后在611级和911分别用极限鞋锻造了一下，最后等1250级用飞羽的超极限锻造完成了现在的熬雪（上榜第1的熬雪）。

**补充2**第2种比例的宠（紫衣），  
因为已经出来了1年快了,具体的数据基本上忘了,就说一下练的过程  
汪汪的满级6.6的  
蝴蝶基本上全是6.8和6.9的,2幻的地藏是37.37的!  
因为紫衣的攻击比例太高,练紫衣的时候已经不是只要求把防降下来,还要求把攻击降低,所以我从一幻化开始就分别把汪汪和地藏用极限鞋子锻造了,3幻的满级汪汪的攻击才1000多点,然后一路进化(进化前用极限鞋子锻造过),到紫衣的311  
611  
911级又用极限鞋子锻造过,到紫衣1250级的时候,用极限鞋子锻造可以得到极限敏的但是防有6000上下的结果,而用飞羽锻造可以得到防的最低的敏却不是最高的!  
这2种结果放在目前 全是不够完满的 又发急了!  
想锻造宠不能加2种 能不能减2种加在一种属性上那  
就去天关拿了10双飞羽  
外买了20双极限做实验,最后得到了我现在的紫衣的身段!  
具体的数据 保密了近一年
