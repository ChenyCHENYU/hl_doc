# 锻造宠物的帖子我来写一个

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

再说说宠物锻造的极限（只是个人经验，不准确望见谅）  
加只能加1/2  
据个例子说如果要加防 而宠物（从来没锻造过）的原始防5000 那么最多只能加到7500左右

减只能到1/6  
据个例子说如果要减敏 而宠物（从来没锻造过）的原始敏2000  
那么最多只能减到334左右

再说说锻造用的装备原料  
如果想加防减敏攻击不变  
那么就买一件加攻击的衣服作为原料开始锻造到一定等级  
再来锻造宠物  
如果想加攻击减敏防基本不变 那么就买加防的武器做原料  
如果想加敏减攻击方不变  
那就买加防的鞋做原料

如果想单加 其他的不管  
那就买纯加的单属性原料好了

如果攻防都要加 那么用武器和衣服一起来锻造宠物好了

以次类比 不多说了

**我来讲讲宠物炼化吧**老看到有人叫嚷宠物怎么炼化  
我就把我所知道的说说吧  
1。宠物炼化不减成长的，它不减忠，不减3围总点（实际上是差1点，有时是多1点，有时是少1点），也不影响炼后3围的实际成长（也就是攻原来1级+2炼后还是1级+2），不过影响幻化后的3围分配。  
2。怎样按需要炼化  
（1）加攻：买把武器来炼上去，然后同宠物炼  
只加攻 炼出的是把宠的防和敏加到攻上去  
敏防都减  
+攻+敏的武器 炼出的是把宠的防加到攻上去，敏保住，只波动1~2点  
+攻+防的武器  
炼出的是把宠的敏加到攻上去，防保住，波动1~2点  
（2）加防：买衣服  
只+防 只+防 敏攻全减  
+防+敏 保敏+防-攻  
波动1~2点  
+防+攻 保攻+防-敏 波动1~2点  
（3）加敏：买鞋子  
只+敏 只+敏 攻防全减  
+敏+防 保防+敏-攻  
波动  
+敏+攻 保攻+敏-防 波动  
3。关于炼化的位置  
（1）装备都按属性放  
武器放火位（9点）；衣服金位（11点或12点）；鞋子水位（3位）  
（2）宠物也按属性放调整的最多  
不过如果你用鞋加水系宠的敏  
那把宠放水位，装备自己看吧~：）  
土系（5点）木系（1点或7点）  
4。关于调整的幅度宠物在一定等级能调整3围幅度是有限制的  
比如说宠物100级你炼武器把100的防炼到攻上去了，然后你再用几个毒把武器炼上去再和宠物炼，还是只能调整100，就是到了100级的攻极限；不过当宠等级到了101时又能调整一[点点](/pets/88)  
5。关于减一加二  
需要两件纯装备来煅  
举个例子，想去攻+防+敏，就要煅一个衣服，煅一个鞋子  
然后把宠扔炉里，装备各就其位（如衣服金位），宠最好占属性位，如果属性位被装备占去，用相生位，也被占就随便呗
