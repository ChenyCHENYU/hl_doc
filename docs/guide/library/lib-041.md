# 龟壳、龙鳞等物品的出现地和用途(附:紫阳丹练法..图解)

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

地点后为参考坐标  
如果大家有更好的坐标请补充：）  
其用途为：

1、5个龟壳练成玄武丹，5个玄武丹练成乾金丹。一般情况下使用有毒药的效果。  
2、5个龙鳞练成青龙丹，5个青龙丹练成离火丹。一般情况下使用有毒药的效果。  
3、5个凤翼练成神凤丹，5个神凤丹练成垦土丹。一般情况下使用有毒药的效果。  
4、5个象牙练成穿云丹，5个穿云丹练成震木丹。一般情况下使用有毒药的效果。  
5、5个人鱼泪练成柔肠丹，5个柔肠丹练成坎水丹。一般情况下使用有毒药的效果。

当把5个龟壳提炼成玄武丹的时候,  
分别把5个龟壳按**12.11**.**9.7**.6点的位置摆设好...主炼9点.便可得到玄武丹....

龙磷,象牙,凤凰羽翼还有人鱼泪也是按同样的方法提炼..

当把5个玄武丹提炼成乾金丹的时候,方法跟把龟壳提炼成玄武丹的方法一样,  
分别把5个玄武丹放到**12.11**.**9.7**.6点.主炼9点.  
便可得到乾金丹...青龙丹,神凰丹,穿云丹和柔肠丹也是按同样的方法提炼..

最后把乾金丹12点，离火丹9点，垦土丹5点，震木丹7点，坎水丹3点按五行位置放入八卦炉，主炼乾金丹，可以得到紫阳丹。

得到了紫阳丹后，将紫阳丹置于乾金位置，作为主炼，无极草震木，冰石坎水，无忧失心草离火，千年灵芝艮土为副，就可以得到提升人物功力的升级圣药通玄丹。（也就是升级药）
