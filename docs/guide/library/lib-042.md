# 鲁班秘籍所记载的特殊装备和物品的炼法

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

离卷（20点）：皂角鞋坎水，狼爪离火，霸王钳震木，龙林乾金，鳄鱼骨艮土，主炼皂角鞋，即可得到狂狼战靴。-100生命，+1000内力，-50攻击，+500敏捷的鞋子。

震卷（30点）：人鱼之泪坎水，凤羽离火，象牙震木，龟壳乾金，水纹坠艮土，主炼水纹坠，得到长命锁。+300血，-50攻的**800级**头饰（右）。

坤卷（40点）：玄金镯震木，人鱼之泪坎水，狼爪离火，龟壳乾金，龙鳞艮土，主炼玄金镯，得磐龙樽。+200生命，+230防御，+200敏捷，修行19200的头饰（左）。

艮卷（50点）：正气甲12点（主）正气甲11点,鄂鱼骨9点,象牙7点,霸王钳5点,龙鳞3点.正气战衣，+400生命，+2000内力，-100攻击，+300防御，+100敏捷，修行19200的衣服。

坎卷（60点）：龟壳乾12金,霸王钳兑11金,象牙震7木,人鱼之泪坎3水,凤凰羽翼离9火,龙鳞5土,主练龟壳乾12金,可得到宠物谨慎枝能.

巽卷（70点）：玄武丹乾位,穿云丹震位,柔肠丹坎位,神凰丹离位,青龙丹艮位,主练乾位,得到相当于五个顶级毒药的蓝水晶。

乾卷（80点）：紫阳丹放乾金、无极草震木、冰石坎水、无忧失心草离火、千年仙芝艮土，主炼乾位。得升级药。

**飞锻造的时候拿到的秘录**：鳄鱼骨放金，11、12点。凤凰羽毛放火，9点。布鞋放水。3点。布鞋主练，得到凤凰战靴。-280防御，+500敏捷，修行800的鞋子。

龟壳——坠泪岗战斗奖励。（45，25）（39，8）（37，17）

龙鳞——吓死人洞2层战斗奖励。（11，29）  
狼爪——踏雪原战斗奖励。（59，73）  
凤凰羽翼——凰之谷战斗奖励。（33，55）

鳄鱼骨——东码头战斗奖励。  
象牙——西雪岭战斗奖励。（27，35）

霸王钳——不归海岸战斗奖励。（62，67）  
人鱼之泪——拿[乒乓鱼](/pets/143)任务物品的人鱼项链，到深蓝海城找人鱼三公主（34，44）  
交换得到。
