# 标人的说明

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

标人的装备  
**武器**：由于人物不同，因此所用武器也不同，一般说来，武器的敏捷在1100左右，血一般在2000-4000之间  
**衣服**：用正气战衣锻造血敏衣，敏捷可以在1900左右  
**鞋子**：飞羽锻造纯敏鞋，按照修行而敏捷不同，一般在3200左右  
**身饰**：+240敏的扳指  
**头饰**：最大加50敏。但从实战考虑，50敏实在对局势无关紧要，建议用太乙珠锻造血饰比较合适  
以上装备只是对目前锻造材料以及系统的普遍分析以及玩家常用装备，不排除有极品装备以及高修的可能

属性分配  
**招人**：略。因为招人的分配五花八门，而且属于标人旁支。  
**大标人**：点数几乎都加攻击，敏捷完全靠装备来提升。以“攻”为主分配方向，“敏”为辅助分配  
**小标人**：点数以“敏”为主，“攻”为辅  
现在流行标人为1500一个划分，因此，大标人与小标人的敏差一般也在1500和3000这2种阶段，个别人可以与之差别4500敏。  
**属性分配的误区**：既非大标人，也非小标人，位于二者之间。如：一标7000血。  
产生这种情况一般有以下几点：  
1，装备不全  
2，点数不够  
3，对PK认识不深  
4，大招人  
因为一标7000血，1标往往不能秒人，而敏捷肯定不足，即使能发出2连标，对方也有很大的闪避机会。如果对方闪避了2连标，就会将自己陷入一个十分被动的局面

药物分配  
**招人**：一般在（药：标）4：6-6：4之间，大多人选择5：5的分配  
**标人**：一般在（药：标）2：8-3：7之间，高手大多选择1：9这样的比例  
当然，药物的分配主要靠个人的喜好以及对PK的掌握程度。越是新手，药物比例就越多，因为他们在PK场上有双重作用：保住生命并为队友进行医疗

PK手法  
**大标人**：一标秒  
**小标人**：2连标，甚至3连标  
**招人**：一招一标，再招、再标....或者2招一标

第六章  
克制方法  
标人的强项就是攻击力强，敏捷高。尤其是3连标杀人的小标人，敏捷更可以达到万敏，即使被几个招人围攻，依然可以安全撤离。  
但他们最大的弱项就是内，任何一个招人都可以点了他。很多人考虑标人用外挂，连标速度很快。但外挂是把双刃剑，招人也可以用外挂点了标人。  
在PK场中，射人先射马，一定先抬走对方的内人而或再去围攻标人，如果直接打标人，后果往往是很悲惨的......
