# 黯神灵戒的两种做法.(五系任务中火系所得的材料)

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

根据其属性可以做成两种用途..

第一种是做成减血的加内的身饰.(90W修的还可以加上攻)  
(一)减血732的数据..

清掉原来的1000血,把左饰放1点,水城珠宝店的水坠纹放6点,1点主炼.

1:直接加内到4170,加第一个极限血饰======>减血417.  
2:直接加内到5268,加一个加血2580的半成品血饰.=====>减血525.  
3:加第一个极限内带===>加内7053,然后加第二个极限血饰=====>减血678.  
4:加第二个极限内带===>加内7278,加一个加血2415的半成品血饰===>减血726..  
5:加第三个极限内带===>加内7326,加一个加血918的半成品血饰===>减血732..  
(二)90W修加攻的数据..

加攻的极限是244,把做好减血732的左饰直接加极限内带把内加到极限.

然后加极限武器加攻到不能加为止.(不能降修加攻..)

当然了,其实要不要把攻加到极限是根据个人的红利点和所用招的大小而定的.  
没必要一定要把攻加到极限.
