# 『天下幻灵』 右饰集锦(减敏改进版,加内原创)

<TopicHeader cat="玩家文库 · 锻造-饰品" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**右饰集锦(减敏改进版,加内原创)**(一)长命锁  
人鱼之泪(坎)  
凤羽(离)

象牙(震)

=====>长命锁(艮位主炼)  
龟壳(乾)  
水坠纹(艮)

1:减敏过程  
第一步,加血到3843,加第一个极限鞋,=====>减敏128,  
第二步,加血到4779,加一个加敏2060的鞋子,====>减敏159.  
第三步,加第一个极限血饰,再加第二个极限鞋,====>减敏210.  
第四步,加第二个极限血饰,加一个1800左右的敏鞋子,===>减敏226.  
第五步,加第三个极限血饰,加一个950左右敏的鞋子,====>减敏227.

用掉了2个极限鞋子和3个极限血,3个半成品的鞋子.  
PK人的话,到这一步就可以了.

2:加防  
右饰属土,土生金,如果想把防加到极限,把长命锁加血到极限6828.  
然后连续砸上5个极限衣,加防极限是227.

3:加内  
第一步,加一个加内3600左右的半成品内带,====>加内381.  
第二步,加血到4701,然后加一个1650左右的半成品内带,====>加内432.  
第三步,加血到4650,然后加一个1100左右的半成品内带,====>加内441.

(二)太乙珠(大罗飞五转时的任务物品)  
1:减敏过程  
第一步,加血到3985,加第一个极限鞋.====>减敏132.  
第二步.加血到4948,加一个加敏2050左右的半成品鞋子,====>减敏164.  
第三步,加第一个极限血饰,然后再加第二个极限鞋子.====>减敏215.  
第四步,加第二个极限血饰,再加一个加敏1900左右敏的半成品鞋子.===>减敏231  
第五步,加第三个极限血饰,再加一个加敏1000左右敏的半成品鞋子.===>减敏233.

2:加防  
同理于长命锁,把太乙珠的血加极限6994,然后连续砸上6个极限衣就OK了.加防233.

3:加内  
第一步,加一个加内3600左右的半成品内带,===>加内399.  
第二步,加血到4852,加一个加内1650左右的半成品内带,===>加内450.  
第三步,加血到4801,加一个加内1100左右的半成品内带,===>加内456.

(三)丹凤钗(飞功德时的任务物品)  
1:减敏过程  
第一步,加血到4017,加第一个极限鞋.===>减敏133.  
第二步,加血到5010,加一个加敏2096的半成品鞋子.===>减敏167.  
第三步,加第一个极限血饰.加第二个极限鞋子.====>减敏218.  
第四步,加第二个极限血饰.加一个加敏1812的半成品鞋子.===>减敏233.  
第五步,加第三个极限血饰.加一个加敏1010左右的半成品鞋子.===>减敏235.

2:加防  
加血到极限7065,然后连续砸上6个极限衣,加防235.

3:加内  
第一步,加一个加内3600左右的半成品内带.===>加内405.  
第二步,加血到4911,加一个1650左右的内带,====>加内456.  
第三步,加血到4860,加一个1100左右的内带.====>加内462.

(四)普通的右饰

大家看了前面三个,应该可以明白了,右饰的做法是相通的.  
普通的右饰也是照上面的模式.碍于极限较贵,和现在上面三种材料
