# 金光刀做防敏刀的数据!

<TopicHeader cat="玩家文库 · 锻造-武器" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

1.加毒药到加攻1998，加一个极限鞋子，得到加敏407加攻1357的刀。  
2.加毒药到加攻2661，加一个极限鞋子，得到加敏519加攻1730or1722的刀。  
**★注**：这步可能有点问题。。。有待继续实验  
3.加毒药到加攻2549，加一个加敏1885的鞋子，出加敏574加攻1921的刀。  
4.加毒药到加攻2494，加一个加敏1625的鞋子，出加敏609加攻2039的刀。  
5.加毒药到加攻2459，加一个加敏1410的鞋子，出加敏633加攻2122的刀。  
6.加毒药到加攻2435，加一个加敏1251的鞋子。出加敏651加攻2172的刀。  
7.加毒药到加攻2417，加一个加敏1072的鞋子，出加敏664加攻2225的刀。  
8.加毒药到加攻2404，加一个加敏931的鞋子，出加敏670加攻2236的刀。

这时候再怎么加鞋子，都会减敏到669的。。。  
至于670是不是极限，有待证实，我找了多种计算的方法，都不合理。。

最后感谢菲卖品所提供的金光刀和锻造号让我来研究加敏的数据。。。

以下是金光刀加敏671的数据（由轩辕№雨轩提供）：  
1。1940攻时加极限鞋得到  
415敏1387攻  
2。2653攻时加极限鞋得到 516敏1722攻（这步用2245的半成品敏鞋就行了）  
3。2540攻时加1896鞋得到  
572敏1907攻  
4。2496攻时加1645鞋得到 608敏2029攻  
5。2460攻加1437鞋得到  
632敏2109攻  
6。2436攻加1251鞋得到 650敏2167  
7。2418攻加1081鞋得到  
663敏2222  
8。2405攻加909鞋得到 671敏2237

做好后减攻击到1033，加极限血佩得到924的血  
减攻为0后是27。8W修，火淬是25。02的修
