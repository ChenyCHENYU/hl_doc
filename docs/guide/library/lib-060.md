(三)1139敏3069内武器的加血法  
加血有两种方法,一种是直接把武器的攻加到最大值,然后用极限血饰砸到不能加  
为止,这个适合高修的人,武器可以加血到3700+,降修到0攻后,武器在大约在60W  
左右.(汗...俺不知道什么时候才到)  
另一种就是我要说的降修加血法,适合低修的人,根据自己的修行来加血!  
1:降攻到1347,加第一个极限血饰,→加血1200  
2:加攻到1847(加一把1622攻的半成品武器),加第二个极限血饰,→加血1680  
3:加攻到2227(加一把1495攻的半成品武器),加第三个极限血饰,→加血2004.  
4:从这一步开始,加一把极限器,然后直接用极限血饰根据修行砸极限血饰或半成  
品的血饰.  
加第四个极限血饰→加血2157,  
加第五个极限血饰→加血2310,  
加第六个极限血饰→加血2460,  
加第七个极限血饰→加血2607,  
加第八个极限血饰→加血2751,  
再加一个+3591血的半成品血饰,俺要的东东就出现啦...嘿嘿..
