(二)加敏  
1:降攻到4036,加1双极限鞋子(武器11点或12点,极限鞋子3点)  
→加敏912的武器!  
2:加攻到4102(加一个+攻2341的半成品武器)加一双加敏2065的鞋子.  
→加敏992的武器!  
3:加攻到3919(加一个+攻1905的半成品武器),加一双+敏1597的鞋子.  
→加敏1032的武器!  
4:加攻到4023(加一个+攻1895的半成品武器),加一双+敏1618的鞋子.  
→加敏1068的武器!  
5:加攻到4069(加一个+攻1808的半成品武器),加一双+敏1473的鞋子.  
→加敏1095的武器!  
6:加攻到4056加一个+攻1628的半成品武器),加一双+敏1301的鞋子.  
→加敏1115的武器!  
7:加攻到4004(加一个+攻1391的半成品武器),加一双+敏1115的鞋子.  
→加敏1129的武器!  
8:加攻到3976(加一个+攻1189的半成品武器),加一双+敏997的鞋子.  
→加敏1140的武器!  
我为了省时间,用的是半成品加攻法,不是用毒直接加攻上去,括号内是加到  
一定攻击值所需要的半成品武器,加的时候,加敏的武器放9点,半成品武器放1点.  
加敏的武器作主炼,这样就OK了.然后就是加半成品鞋子加敏.

(三)1140敏武器的加内  
1:降攻到999,加第一个极限内,→加内699(位子武器11点,内带1点)  
2:降攻到1019,加第二个极限内,→加内1374  
3:降攻到1328,加第三个极限内,→加内1980  
4:降攻到1877,加第四个极限内,→加内2328(从这开始武器9点,内1点)  
5:降攻到2305,加第五个极限内,→加内2580  
6:降攻到2592,加第六个极限内,→加内2787  
7:降攻到2863,加第七个极限内,→加内2961  
8:直接加第八个极限内带,加内到3066

(四)降修加血参照七夕武器的加血数据!
