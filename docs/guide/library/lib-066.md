# 正气战衣作血内衣的最新数据(2000内,2139血)

<TopicHeader cat="玩家文库 · 锻造-防具" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

做过的人都知道,存在着一些小错误..今天小女子心情好,就抽时间重新做了一次.把数据重新整理了一下发出来,希望大家不要见笑.

在开始做之前,当然是先给正气战衣清不需要的属性: 止血草12点、衣服7点，给衣服清防,衣服12点、草鞋3点，给衣服清敏,  
得到+400血、+2000内、-100攻的正气战衣

| Quote: |
| --- |
| 偶找不到现在的正气战衣,只好把偶以前的加血2137的衣服拿来作实验. 汗,只是降血降不到正好400,降到了405,那就将就着用吧.大家伙做的时候, 尽量忽略掉第一步这5点的血差,在中间做的时候,补回来.而且在最后一步的 时候,血可以有几十点的误差值,所以这5点是完全可以不放在心上.. |

接下来就是给衣服加血了..

1:衣服加防到221,加第一个极限血饰,========>加血1020.  
2:衣服降防到868,加第二个极限血饰,========>加血1362.  
3:衣服降防到1341,加第三个极限血饰,=======>加血1605.  
4:衣服降防到1513,加第四个极限血饰,=======>加血1818.  
5:衣服降防到1889,加第五个极限血饰,=======>加血1986.  
6:直接加第六个极限血饰,==========>加血2139.

看清楚哦,第一步是加防,其它几步可是降防哦..  
好啦,大功告成,就等着把衣服降修用了..
