# 2000内1171敏的衣服

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**修少的参考 http**：//bbs.tx51.com/viewthread.php?tid=160048  
能节约不少材料。

**正气战衣去血**：衣服7点，水纹坠6点，此时0血、2000内、-100攻击、0防、100敏；  
**去敏**：衣服12点，草鞋3点，此时0血、2000内、-100攻击、0防、0敏；  
用毒药加修到2000内、-100攻击、2602防；（极限衣服是3168纯点）  
加一个极限衣服2000内、-100攻击、3906防；（超极限4472）

以上两步应该可以用两个极限衣服加防到极限。

现在开始砸极限鞋，衣服11点，鞋3点，连续砸31个，就OK。
