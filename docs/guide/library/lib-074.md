# 堕天甲、云锦天衣煅造防衣的数据

<TopicHeader cat="玩家文库 · 锻造-防具" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**堕天甲**：-70攻  
-80敏  
**云锦天衣**：-70攻 -80敏 +100血  
+150防  
**消耗材料**：堕天甲或云锦天衣1件 极限内带17条 极限甲7件 半成品内带4条  
(堕天甲、云锦天衣煅造防衣1000级的属性：-5940内  
+2629防)

云锦天衣清血的方法：  
炼化一个+1200血的头饰，衣服12点、头饰5点、主练衣服；再把衣服的防降到0，在水城饰物店买个水纹坠和衣服炼化、血就清0了
