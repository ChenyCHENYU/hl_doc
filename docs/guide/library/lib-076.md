# 煅造新手入门、煅造基础知识

<TopicHeader cat="玩家文库 · 锻造-其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

一 如果你的炼化经验还是0，那么请点击这里

二 一些基础知识  
**<所谓“连炼”**：1000炼化经验=6连炼、1200炼化经验=7连炼、1500炼化经验=8连炼>

1 五种装备五行属性：武器（火）防具（金）鞋（水）身饰（木） 头饰（土）  
通常我们也叫身饰为 内带或左饰 ；叫头饰为 血佩或右饰

通常也把五行炉的位置叫做 1点、3点、9点、12点 之类的<拿起手表或看看时钟就知道了  
^_^>

2 宠物 + 装备 = 宠物的三围调整 （最好装备等级是宠两倍以上的）  
如果想加防减敏攻击不变  
推荐使用逍遥战衣炼化到20W修行，再和宠物煅造  
如果想加攻击减敏防不变 就用加防的武器做原料 或  
高等级的武器加低等级的衣服  
如果想加敏减攻击防不变 就用加防的鞋做原料 或  
高等级的鞋和低等级的武器

如果想单加、其他的不管 就用加单属性的装备原料  
如果攻、防都要加  
推荐用武器和衣服一起来锻造宠物

3 宠物 + 宠物 =  
装备、药物、暗器  
宠物要炼化成装备时，根据宠的属性放在乾坤五行炉的对应位置  
乾、兑位煅造出衣服 离位煅造出暗器  
坎位煅造出鞋子 其他两方位出的均为饰物

**例如**：主炼方位出的物品

金属性宠（主）+ 宠 =  
加血的药  
木属性宠（主）+ 宠（离） = 内药 （放在左下）= 出饰品加内（或防且同副宠有关）  
水属性宠（主）+ 宠 =  
毒药  
土属性宠（主）+ 宠 = 加血的头饰

**武器**：减防 | 如果要给武器加防、必须找原始就+防的武器  
**鞋子**：减功  
**身饰**：减血  
| 要给身饰加血、同样必须找原始+血的身饰  
**头饰**：减敏  
| 同上说法、目前有恋之守护+30敏的和绝版的思念发钗+50敏的

5 药物和暗器 = 更好的药物、暗器  
-5000毒药练法 = -100毒 +  
暗器重复炼得到  
+20000内的药 = 林天的玉佩 + 止血草（只要是身饰都可以）  
+20000生命20000内的药 =  
+20000内的药（坤）+暗器（离）= +20000血20000内的药

衣服放11点、毒药放12点、其他炉位全放暗器  
武器放9点、毒药12点、其他炉位全放暗器  
鞋子放3点、毒药12点、其他炉位全放暗器  
头饰放6点、毒药12点、其他炉位全放暗器  
身饰放2点、毒药12点、其他炉位全放暗器

7 如何降修及降修的含义、如何微调装备的属性  
->不管衣服、鞋子、武器、头饰还是身饰，降修行都是用草药或银两（通常都用止血草；加血效果越少的，降的程度越大）

降修的含义：  
衣服降修  
= 给衣服降防 <衣服9点、草12点>  
武器降修 = 给武器降攻 <武器12点、草9点>  
鞋子降修 = 给鞋子降敏  
<鞋子9点、草12点>  
身饰降修 = 给身饰降内 <身饰9点、草12点>  
头饰降修 = 给头饰降血  
<头饰9点、草12点>

->微调：  
简单的说就是用毒量不高的毒药与装备炼化，一般都是用药店里卖的毒药(自己炼化毒量不高的毒药也行)；  
在我们成功炼化出一件装备时，通常要降到自己需要的等级

打个比方：  
你已经成功煅造出一双 -1995攻 -300防  
+6651敏的鞋子  
你要把它降到**1000级**使用，鞋子放9点、止血草放11点，循环炼之  
会得到一双 **1000级** +2600敏 -1995攻 -300防  
的鞋子  
而+2600敏并不是**1000级**的最佳敏捷  
此时你要到药店买一个毒药，鞋子放3点、毒药放12点，循环几次  
就会得到一双**1000级**  
+2694敏 -1995攻 -300防 的鞋子(**1000级**最佳敏捷)
