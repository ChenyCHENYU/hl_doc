# 锻造高级篇(待完善)

<TopicHeader cat="玩家文库 · 锻造-其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

首先说下几个极限的感念:  
极限有3种,第1种是用一般毒药锻造可以达到的极限,其中衣服,武器,鞋子的极限是3168,内带和血带是4251(一般我现在用的极限就是这个极限),我们称为1次极限.  
第2种是在一次极限后用第1极限加第1极限复合锻造达到的极限,我们称为2次极限.(武器,鞋子4358,衣服4472,血内不做研究).  
第3种是最高极限,这个是整备2次极限加其他所有属性点.

再说下五行的关系:

金(衣服)

火(武器)

木(内力)

水(鞋子)  
土(血带)

正时针转是相克  
逆时针是被克  
正时针转跳过1格是相离  
逆时针转跳过1格是相生  
任何装备都有1个正属性和相克,被克,相离,相生4种状态.  
装备相克的时候是减,其他状态是加.

说下各个情况下加属性的锻造办法:  
相生=直接往上加极限,相生状态下加极限正属性最高点是不变的.  
相克=个各帖子离都有,就是加负极限加正极限加副极限......  
被克=这个是最难的,被克状态下加副属性后正属性的修行会往下掉,要计算出合适的点才可以加到.  
相离=把正属性降修后加副属性,副属性极限加上去后正属性修行也会提高,这个加起来也简单,不停的往上加就可以.

以武器做例子：  
武器属火，相克金，相生土，被克水，相离木．  
于是武器的属性只可以减金，可以加土水木．  
这里以下部分是我自己的总结了，希望可以得到补充和批评．  
相生＝可以吧正属性点全部加上去，１００％  
相克＝这个就不说了，全世界都是，减多少属性的现在数据全有了．  
被克＝（第1次极限＋减的副属性）＊**０.３**＊**０.７４**４  
相离＝正属性点的７０％可以转过去．

**以武器醉剑为实例**：武器醉剑极限加攻击6361,锻造基础里就有锻造只可以转正属性的30%  
于是6261*0.3=1908  
相生=1908*100%=1908

由于是血还要×3 1908×3=5724  
相克=1908

于是减攻击1908  
被克=(3168+1910)***0.3**×**0.74**4=1133  
于是加敏捷1133  
相离=1908×**0.7**=1**335.6**

由于是内还要×3 1**335.6**×3=4007

这里要说的是所有状态下,相生是个很特别的情况,只要正属性的纯点在那,就可以加极限,加到那个点为止.  
有实际例子可以证明,1把加1134的武器,加了血以后状态是+血4620+功5134-防1910+敏1134.

可能新手看不懂,锻造高手可以一起来研究下.  
再就是不要去死盯着那几个点的出入,这个是理论性的东西,误差不是太大就可以.  
帖子里的加属性方法很实用,这个是锻造高手要知道的.这样可以避免很多弯路,找到相对应的作法,一般懂锻造的人做到最高不是问题.
