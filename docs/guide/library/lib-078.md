**另附上云锦天衣的清血方法**：云锦天衣清血的方法：  
炼化一个+1200血的头饰，衣服12点、头饰5点、主练衣服；再把衣服的防降到0，在水城饰物店买个水纹坠和衣服炼化、血就清0了

左饰现在有两种，一种是普通的锦腰带做材料，另一种黯神灵戒做材料。

（1）普通材料：减血数据由淘气鬼提供，详见http://bbs.tx51.com/viewthread.php?tid=216131&fpage=1

1:把一般的内带加内到3780，加个极限血，得到-378血+3780内的左饰（内1点血5点）。  
2：把内加到4629，加个极限血，得到-462+4629内的左饰（位置同上）。  
3：给-462+4629内的左饰加个内带（内7点，减血内带1点），在加个极限血得到-612+6408内的左饰。  
4：再加极限内带，用极限血佩减血，方法如（3）  
得到-660血+6612内的左饰。  
5：最后在加个极限内带加内，用半成血减血（注：这里不用极限血了,+900血的就可以了）。  
6：然后就用极限内带把减好血的身饰的内加到极限，最后直接用极限武器砸，攻的极限是222。  
当然了,其实要不要把攻加到极限是根据个人的红利点和所用招的大小而定的.  
没必要一定要把攻加到极限.

（2）黯神灵戒，数据由小草，俺本人提供，详见：http://bbs.tx51.com/viewthread.php?tid=311427&fpage=1

(一)减血732的数据..

清掉原来的1000血,把左饰放1点,水城珠宝店的水坠纹放6点,1点主炼.

1:直接加内到4170,加第一个极限血饰======>减血417.  
2:直接加内到5268,加一个加血2580的半成品血饰.=====>减血525.  
3:加第一个极限内带===>加内7053,然后加第二个极限血饰=====>减血678.  
4:加第二个极限内带===>加内7278,加一个加血2415的半成品血饰===>减血726..  
5:加第三个极限内带===>加内7326,加一个加血918的半成品血饰===>减血732..

（zzyymm附录：昨晚锻造了一个黯灵神戒，我是先加内到4227，加一个极限血饰后减血411，然后和极限内带锻造一次，加内6333，加血饰后减血600，再加极限内带，加血7200，加极限血饰减血720，加极限内带后，加内7320，加一个加血一千五百左右的血饰，得减血732，再加上一个内带，加内7332，连续砸上九把极限武器，加攻击244。

没必要一定要把攻加到极限.

五：右饰  
一般用的是丹凤钗和太乙珠，数据还是由俺小草提供，详细见：http://bbs.tx51.com/viewthread.php?tid=285500&fpage=1

第一种，太乙珠(大罗飞五转时的任务物品)

1:减敏过程

第一步,加血到3985,加第一个极限鞋.====>减敏132.  
第二步.加血到4948,加一个加敏2050左右的半成品鞋子,====>减敏164.  
第三步,加第一个极限血饰,然后再加第二个极限鞋子.====>减敏215.  
第四步,加第二个极限血饰,再加一个加敏1900左右敏的半成品鞋子.===>减敏231  
第五步,加第三个极限血饰,再加一个加敏1000左右敏的半成品鞋子.===>减敏233.

2:加防  
同理于长命锁,把太乙珠的血加极限6994,然后连续砸上5个极限衣就OK了.加防233.

**第二种**：丹凤钗(飞功德时的任务物品)

第二步,加血到5010,加一个加敏2096的半成品鞋子.===>减敏167.  
第三步,加第一个极限血饰.加第二个极限鞋子.====>减敏218.  
第四步,加第二个极限血饰.加一个加敏1812的半成品鞋子.===>减敏233.  
第五步,加第三个极限血饰.加一个加敏1010左右的半成品鞋子.===>减敏235.

2:加防  
加血到极限7065,然后连续砸上5个极限衣,加防235.
