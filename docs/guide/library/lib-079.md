# 宠爱海底练拳法（扩展为山沙雪海练拳最终版）

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

因为可以买到1000内力药

但是山城一般情况下都是人山人海

非常容易卡机导致地图出错

回头想想  
好象不止山城有1000内力药啊

为什么不去海底练拳呢

于是来到海底 打开宠爱

.................

居然没有买琼露丹的选择 .......

没有办法  
只好发扬DIY精神

自己试试能不能把琼露丹改出来用

/////////////////////////////////////

经过研究  
得到修改方法如下

（不得以修改了宠爱的  
MAP.INI 向宠爱作者表示歉意）

/////////////////////////////////////

打开宠爱下的  
map.ini  
文件

找到

[Store400000]  
Num=6  
Med0=消淤散  
Med1=镇痛宁  
Med2=甘露酒  
Med3=人参  
Med4=续灵丹  
Med5=百草灵阳丹

段落

把它修改成

[Store400000]  
Num=10  
Med0=消淤散  
Med1=镇痛宁  
Med2=甘露酒  
Med3=人参  
Med4=续灵丹  
Med5=百草灵阳丹  
Med6=回灵粉  
Med7=珍珠丹  
Med8=还神丹  
Med9=琼露丹

保存  
退出 重新打开宠爱

............. 一切OK

享受海底练拳的乐趣吧

但愿别把海底变成第二个枯井原

同样的道理

我们可以把所有有卖琼露丹的药店物品在宠爱里全部显示出来

下面的是修改过的沙/雪/海三个药店的物品的  
MAP.INI 文件
