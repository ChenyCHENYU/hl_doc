# PK半年多的经验与心得!!!

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

我看了好多别的玩家写的帖子，但我感觉写的根本不够详细，一个新鸟“菜鸟”  
是完全看不懂的，所以我感觉应该从基层说起！以下是我PK那么长时间的得到的经验和心得……希望热爱PK朋友和想学PK的朋友，都认真看一看……  
因为我说的东西不是废话……

我认为PK应该分4个部分：创招，分点，装备，实战……

:love1：创招……  
PK主流的招分3类  
小招400-600内  
中招600-800内  
大招800-1000内

现时最高的系数是**2.0**，当然5转的飞招能提升**2.0**的10%，也就是**2.2**左右  
杀伤系数并非定死**2.0**，没飞5转也能创出系数**2.0**+的，但上限我就不知道是多少了，我自己最好的招  
是500整内杀1015，而第一下杀伤是1176，成长**117.6**  
这个相当与系数**2.35**2了

那么什么招叫极品招呢？  
500内的  
第一下杀伤过了1100+ 成长有110+ 就算极品  
800内的 第一下杀伤过了1650+ 成长有165+ 就算极品  
1000内的  
第一下杀伤过了2050+ 成长有205+  
就算极品

之前我看了些朋友的帖子，说招本身和命中有点关系，但我不那么认为的，个人有个人的观点吧？反正呢，创出容易而杀伤系数过了**2.0**的招 都不会差

容易招的出招速度快“至于命中是不是高？我个人没感觉”  
一般招的出招速度比容易招的要慢点 容易招能出6招  
那么一般招就只能出4招  
至于困难招是什么样子 我不清楚  
我自己没创过这样的招……

对于PK，招是很重要的，而不同的招也有不同的打法，用法，所以没有分小招好还是大招好！只要系数过了**2.0**的  
都能用……

接着说一下创招  
要创**2.0**的招 人的纯攻要加到2000  
很多人问如果加到2500会怎么样？答案就是多加了没用的，系数是不会提升的……  
创招的必要条件就是 纯攻加到2000 而自己想创多少内的招  
就加多少内去创  
但是能创的招的上限 暂时能创的最大的招 也就是2000×1000 所以内点加到1000 是完全足够去创  
小-中-大招了 多了也是浪费 “练拳例外”

创招是需要创招经验的 尤其是要掉级的招“杀伤过了1000的招”  
我之前看到很多朋友讨论 经验多是否拳就好？ 我对这个没有特别的看法 也不认为经验多创的招 就一定好 经验多只是成功率高 可以有多点招 让自己选择  
看看哪招好  
我自己最好杀伤的招 就是上面说过的杀伤**2.35**2的小招 那个是在我3W经验的时候创出来的

磨经验的方法有两种  
我用的下面的两种  
1）人在2转以上 练到**299级** 点全部加内 然后去创**1.25**系数的招磨经验 点数是足够创出过1000杀伤的招  
所以创一次，失败了有50经验 成功了就有100经验  
人到**299级** 可以创99次 把自己的级再掉回去200 那么一次循环就有99次 而拿经验最少也有5000

“此方法，必要条件是有好的防具，因为自己的纯点不能加防，否则就慢了”  
2）这个方法比较普遍 就是过劫创招 创一次 过一次劫  
如果是为了经验  
我建议用方法（1）这个方法是可以一天5-8W经验的 而且一点都不累 可以打800[迷茫](/pets/192) 随便挂蝴蝶~：）  
当然创招的方法还有好多好多  
这两个只是我个人比较喜欢用的方法……

创招就到这里为止了……

:love2：分点  
很多朋友认为  
有了锻造 分点似乎就不重要了 其实不是的 PK“老鸟”都知道装备加的再多也好 分点也是有它的比例的  
什么占多少什么占多少……

我下面说几个典型的PK人的属性，我们现在假设下面的数据都是2W修行的人  
佩带极限装备……  
a:中性人，血5000，内3000，敏6000，攻1700  
这个属性的点，什么都在中间，所以没属性克它  
，它也不克任何属性，只要拳好，都能和任何属性打……

b:高敏人，血5000，内3000，敏6500，攻1200  
这个属性适用与打用大招的人，因为大招的人招大，所以敏低，敏相差800+  
低敏打高敏只有40%的命中，或者更少……

d:大招人，血5000，内3000，敏5700，攻2000  
这个属性其实有很多缺陷，内少血少敏低，唯一可以用的就是招大，所以只能用于打血人，因为血人的敏点和这个属性相差不大，所以命中是有保证的……

e:血人，血6500，内3000，攻6000，攻1200  
这个属性，只是高敏人，调整过的属性，敏点和高敏人的差距也只有500，所以命中回避的影响不大，所以这个属性适合打敏人……

上面说的是比较常见的敏人的分点比例  
下面再说2个特殊的  
**f:大内**：血14000 内14000 攻0 敏0  
这个可以说完全是个变态，所有敏人都恨这个属性的人，这个属性，唯一的用处就是点人“当然也能练招”，此属性，只能用于群体PK……

**g:大攻**：血13000  
内0 攻5000 敏0  
这个属性，也就是现在才出现不久的“镖人”，唯一的优势就是能用一个暗器 把上面介绍的4类属性的敏人 送回去药店 但也有极大的缺陷  
只要被点了 就完了 所以选择大攻的朋友 要眼快手快哦……

**h:大攻“改”**：血8000 内6000 攻5000 敏0  
这个是上面的大攻的改版  
此属性我继续挑不出什么毛病了 有血有内 内足够点敏人 而且有内不会导致2倍杀伤 血是少了 但8000血也完全足够 而攻是完全保留 一样可以一个镖送人会药店  
所以这个属性 非常的拽……而敏人也是最痛恨这属性……

上面说的几种属性的比例 其实就是分点的 PK的分点是个重要的环节  
现在PK的人的比例也就是上面几种 当然还有别的“但一定是个菜鸟比例” 大家可以看看自己的比例偏向哪个 自己就属于哪类PK人  
而它们之间是没一者绝对无敌的……  
只能说特殊的那两类比较拽 但它们也不是无敌  
而且会被敏人笑话，看不起……

它们之间的关系是这样的：  
{[敏克攻——〉攻克血——〉血克敏]〈-----镖人克它们}〈----大内克它们  
但大内并非无敌  
因为大内 根本没有攻击力 只能牵制它们……  
当然 敏人和攻人 只要不被大内 点穴  
大内只是垃圾一个……

:love3：装备……  
装备里加的点数  
其实是完全可以自由调整的  
说到装备 还是会牵连到分点  
这里只说一样什么样的装备比较好用，实用……

这里先说一下点的比例：  
1纯点=1攻=1敏=1防=3血=3内  
点和攻防敏的比例是1：1 而和血内是1：3  
但是人的纯点只要加100 攻击或者防御或者敏 就可以多30血……  
所以敏人的纯点  
尽量去加攻或者敏 加内和血 是吃亏 所以血和内要用装备来加

例子：  
如果人的衣服加1000敏  
而跑去用纯点加1000体力“就是3000血”  
那么得到就是1000敏 3000血  
如果换过来 用衣服加3000血  
人的纯点加1000敏“这样可以多得300血”  
得到就是3300血 1000敏 这样就白赚了300血  
也就等于是100纯点……

### 1）武器  
武器极限能掉18XX防 掉了18XX防 那么1000修行用 可以加24XX攻“也就是加了2400纯点”

我的习惯是2400点分1000加内点 1400加攻 的到的数据  
就是3000内力 1400攻的武器  
::: tip 玩家提示
注意：武器不需要做到加2000+的攻击
:::  
因为拳没到12层 自己是不知道需要保留多少攻的  
所以攻击不够可以用人点慢慢补充……  
当然，自己能算出拳的极限杀伤的人也比较多，但我还是说一句，你武器加多了攻击，鞋子是一样要掉下去的，武器不用加到2000+  
否则做鞋子又辛苦自己……

::: tip 玩家提示
PS：前面说漏了一个完全杀伤 完整杀伤就是拳打在人身上的最佳杀伤
:::  
这个比较简单 如果拳杀怪物2000  
那么打人就最多1000“对方没内空内例外”那么就需要1000攻来发挥 “公式就是  
拳杀怪的杀伤/2=需要的攻击点数”

### 2）头饰和镯子  
头饰比较简单 直接锻造到最接近自己修行就行了 用来加血 镯子更简单 因为这个东西  
锻造是锻造不出好的 所以直接去商店买戒指之类的东西

### 3）衣服  
一般来说 衣服都做成血衣服 不做敏衣 前面说过了 要加血或者内最好用装备来加  
因为人加攻敏防满100点会多30血 再说一件衣服能加的血 已经足够用了

### 4）鞋子  
鞋子如果在武器攻击不够的情况下 就不选择掉攻击了  
因为鞋子掉了攻击 人的纯点又加攻击 其实是根本没变过 数据一样的 反而鞋子做的辛苦……  
如果是不掉攻的情况 就锻造到接近自己修行 就OK！如果是要掉攻的  
就要算好自己的拳需要保留多少攻  
然后再去掉攻击……  
::: tip 玩家提示
PS：如果PK的时候，想用不同的招PK，那就多做两双鞋，用鞋子来调整攻击...
:::

上面说的是我做装备的习惯  
至于做法我不介绍了 本论坛里有不少锻造高手的  
大家去参考一下……

:love4：实战  
呵呵  
也许很多PK的朋友 会认为我这里说的是废话……  
但你看下去就知道了 这里才是PK的精华……

### 1）猜测对方属性  
如果分点自己都熟悉了  
这个东西并不难 首先看看对方的招打你多少 “能知道他是哪类敏人，攻击占了多少，也能估计对方内有多少” 再看看招打自己的命中 如果100%中  
那么对方的敏一定高出自己800 如果是1/2左右的命中 那么证明和自己敏差不多……  
上面的东西自己分析一下 就能知道对方大概 多少攻 多少内  
多少敏  
知道用的是什么招 和敏的高低 就可以套上面分点那里说的 属性 多试就熟悉

### 2）自己和对方出招，补血补内的时间  
当自己猜到对方什么属性以后 就知道 对方的内和血的大概数值 也就能掌握对方的补血和补内时间了  
一般的和敌人交手 如果自己是小招 那么就要抢先攻击 争取时间 如果是中招 可以选择先出招或者后出 如果自己是大招 那么就一定要后出招 优势就是 对方打你的时候  
自己只需要补血 不用去补内 这样不会导致PK手忙脚乱 当对方出完招了 对方也没什么内了 那么他第一时间是补内 你这时候出招 如果对方中了 他要补的不光是内  
还要补血 这样对方就没有时间还手 只能挨打 还可能让对方手忙脚乱或者对方空内被打2倍杀伤……

内和血的补法 也说一下 一般来说  
如果自己中血“5000左右” 那么 血到1/2的时候就要补血 至于内的位置在1/3 如果自己只有3000内  
剩下1000了 就算能再出招都好 都不能出  
要补 因为自己没内 会导致2倍杀伤 出现2倍杀伤 自己血了去了大半 那么又需要时间补血 这样就吃亏了……

### 3）跳跃  
这个是PK成为高手的焦点  
也是实战里最重要的一个环节 因为跳牵涉了 补血内和出招时间 跳的时候空中 到落地的时间 是很少的 在这个时间里要喵对方 要P对方 自己没血内了还要补  
所以难度很大 如果不熟悉的话 PK我不推荐使用  
当然能用的好 绝对是优势……  
简单说一下跳法  
“1”2X1  
出1招马上跳  
落地马上再出1招 一个循环出2招 跳1次 然后是补内  
“2”2X1循环  
这个是在上面的基础上 循环的用 如果用的熟悉 就绝对是个高手了  
因为这个  
中间 没内是肯定会的 如果对方打到你 还要补血 所以难度高了 需要多练习  
“3”贴身跳 这个打法就是对方跳什么坐标就跟到什么坐标  
只要一贴着人 就疯狂出招 对方 不动自己不动 对方动了马上跟上去“但只适合用小招”

跳的难点就是 找落地正好能出招的那一刻  
这个需要比较多时间来掌握  
如果这个掌握不好 就干脆不要跳 否则 很容易点了出招 不出 因为点早了 或者点晚了……

实战方面的东西 是有顺序的  
上面说的3点 都是有联系的……  
学懂了1，才能学好2，才能学好3……  
如果自己实战经验多 实战厉害 那么打一个高自己1-2W修行的人  
完全不是问题  
而且实战强 可以强化自己PK40%  
以上的实力……

说到这里我也累了  
也说完了 上面是本人对PK的心得和经验……  
写的东西也许会引来很多PK“老鸟”的争议 但也没所谓了 毕竟这个是我个人对PK的经验 和心得 如果有什么看法  
可以大家一起研究一下 我是来自 风之谷-奔放 的【黑の瞳】 也就是现在的SKY 如果风之谷的朋友 以随时来找我切磋……
