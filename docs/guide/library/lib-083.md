# 献给准备投入PK的朋友们

<TopicHeader cat="玩家文库 · 战斗与PK" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

直接入题

PK分标人、内人、招人3种类型

而标人又分高敏标人和高攻标人。这里只简单的介绍下大众标人一般所用的装备（各人不同）

**衣服**：敏血-内的衣服  
个人觉得正气战衣比堕天甲为材料好  
**武器**：敏血0攻武器  
**鞋子**：纯敏鞋-攻  
**左饰**：加敏戒指（修高加修涨内，不加敏）  
**右饰**：血佩  
-敏或攻  
血加得更多

剩下纯点看个人如何分配，一般是先加敏到自己需要的那么多，然后其他点全部加攻。  
标人主要是看纯攻，比如纯攻3000点，那么暗器（银蜂针）去血是3100，手里剑去血是3400！  
现在的标人敏大概在7500--9000左右，当然，更高的需要看你是否高修多投。本人就一直是9000+敏！  
内人

**衣服**：+2000内正气战衣是最好的材料。再锻造为加血加内衣服。  
**武器**：内血武器 （参考：-70敏刀材料做出来可以加3888内  
加4500左右血）  
**鞋子**：极品为：+5985内 +2289血的鞋  
**左饰**：极品为-666血  
+内的带子或其他材料  
**右饰**：最好材料为太乙珠。其次长命锁  
**属性为**：+血-攻-敏

靠以上装备可以做大内人和大血人，纯点全部加血就是血人，内可以达到**1.4**万左右，还可以点上所有标

人和招人  
全部点加内，就是大内人，看你纯点多少而定。血一般在**1.2**万左右，纯点多另算！  
招人

**招人的点数基本分配**：首先你需要明白自己用的招需要加多少点攻击，比如：杀怪物去血2888，那么你  
的混攻就需要加2888/2=1444，这样才能完全发挥招的威力，内力一般控制在不加内药情况下一次可以发  
6---8招左右，看个人爱好而定。其他点数就是敏。少数会加些点到血上而补不足，因人而异！
