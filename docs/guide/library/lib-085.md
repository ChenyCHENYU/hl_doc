# 创招全攻略（入门篇）

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

内力点数为纯点100点以上

如何分配点数可以创招掉级

杀伤过了1000的招都可以掉级（504内以下不掉）  
这里有几个选择方法  
1 660攻击660内  
2  
782内0攻击

如何创出**2.0**和**2.5**以上的招  
飞尚武天神可以创出**2.5**以上的好招  
除了尚武的话，其他的都只能创出**2.0**的招  
最低点数要求  
2000点以上的纯攻，内力按你要创的招而设  
就是说你要有2000以上的纯攻，才能创出**2.5**+的好招

【创招要点】  
1.要求你有一定等级，或点数才能创招，要创好招得飞尚武才行  
2.建议穿上减内的衣服创招，减内要超过你加内点的内，要把内减为零，这样省钱，  
::: warning 注意
3.千万不要在水城、山城、树城药店创招，以免给人暗算
:::

【如何创招】  
1.不掉级招只要随便那里都能创，只要有100以上的纯内，不过加的经验少，更因为刷屏而遭人非议、这种办法毫无意义，而且有刷屏的危险，遇到有心人，会吃大亏，轻则被人塞药，重则给GM踢下线，再严重者，封号处理  
[推荐指数 ☆☆☆☆☆]不推荐

### 2.掉级招有几种方法  
A.练到一定等级，加800点纯内，开始创招，掉到不能创招了，再挂机练上去，最好是大罗以上，因为大罗一级的点比凡人多了100多点，一般170级以上的大罗就能创招了，要是有投过胎的可以更少级，这种方法不建议采取，意义不大  
[推荐指数 ★☆☆☆☆]

B.带鸟、刷宠经验、创招一起来，在明月桥创招掉级顺便带鸟忠、这种最划算，我计算过了，10多分钟带出1批鸟（一只20万），也就是80万幻币、520点养宠经验、1000-1500左右的创招经验，不过速度中上，不能长时间挂机、  
[推荐指数 ★★★★★]

C.天仙299或399创招过劫，就是在天仙299或399的时候，过劫升到300或400，创招掉一级、再过劫、再创招、这种方法速度比带鸟快，可以挂机、也不费钱、  
[推荐指数 ★★★★☆]

D.加兵解创招，加兵解，然后创招，掉到不能再创了，再加兵解（PS：看到有人兵解就加不过只能加2次）最低、最佳创招等级最好是大罗160-**180级**左右，点数加800点纯内、加次兵解再创招、创完再加兵解、没有人兵解的话，到华山脚练级创招、加兵解创招，不必练级，但是很费钱，适合想早点飞创招的人、速度快

【创**2.5**好招要点】  
1。先学会怎么算找的系数  
创招系数 系数用手算是  
N层打怪去血/{[1+（N-1）/10]*消耗内力}=杀伤系数  
用外挂的话.用亚男的那个计数器..链接:http://bbs.tx51.com/viewthread.php?tid=182712 (在三楼)  
2，HLHL创招的要点  
先看系统显示的数据，如果系统显示杀伤在**2.0**以上的容易招都留着，出去打一打看效果再决定删或留  
500内创的招一定要容易招才留，正常招连系数都不用算，直接给咔嚓掉。

用欢乐幻灵在创招的时候保持容易招.....等容易招满了的时候..用口算算一下.如果杀伤是内的2倍值得去试试,杀伤没两的2倍直接删了.想看他是否是好拳就得先看他系数...不打怪是算不出系数的....

**创招的人请注意**：为什么我会说：  
::: warning 注意
千万不要在水城、山城、树城药店创招，以免给人暗算
:::  
今天、我在山城看到有人在山药创招，还没有说2句话，整个屏幕给刷得满满的，于是我就去传音，叫主人换的地方，以免干扰到他人聊天。主人不在，估计是挂机，本来想上报GM，叫GM踢他下线，后来还是给他塞药，  
然后在水城药店，有个垃圾骗子在那里创招，前天我叫GM把他踢下去，今天大号不敢创了，开小号，我这回可是不客气了，马上截图到官方网站，一下子，5分钟之内GM来了，立马把他踢下去了  
呵呵，GM对我说，这个人要是再犯，封号处理  
每个人在幻灵多少会有仇人，因此建议创招在雪城和海底药店，要不去山城便利店啦，水城便利店等人少的地方，不要干扰别人的聊天，也避免给人暗算（PS：宠爱的注意了，要是想创招的话最好不要在山、树、水药店，会有专人在处理创招刷屏的哦！）
