# 好招是如何练成的.带你走出创招误区.

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

今天我们不说创什么样的招怎么分点,不说该穿什么装备,也不说该过劫创还掉级创这些废了1年还嫌废不够的废话.今天主要从系统和感觉入手.

5转尚武创招,非掉级招最高系数可达**2.59**+,但绝对到不了**2.6**~这里的非掉级招指的是504内以下的.也不知道什么时候系统改了,以前501内就开始掉了.现在要504.  
而创超过504内力的招.系统判定为掉级的高级招数.这时候,不管是504内招还是1000内招.系统认定都是一样的,即最高系数为**2.32**,这是极限了,不可能有更高的.谁说有超过这个系数的不是吹就是不会算~大家都别信.我都算了1年多了,应该比较有准头吧........

但是这里面有一个特例需要注意,那就是系统加上去的内力和你创招时自己设定的内力直是2个不同的概念.比如说:我的招创的时候设为500内,不掉级,但是创出来以后是540内,这时候按上面说理论系数不应该超过**2.32**,但打完怪以后算出来是**2.51**,就是说不受内力多寡的影响,这时候系数还是按非掉级招来算.即时系统在加多少内也是如此(越大越好!小招的系数大招的内力,靠!~无敌了).

最后是各种客观因素对招的好坏的影响:  
1.容易招和正常招,首先要确定一点,容易招绝对比正常招好!!创的时候看到正常招一率删无赦!!为什么好?正常招出来打怪的实际杀伤绝对比系统显示的要低,而容易招反之.且容易招每级杀伤成长都要比系统多出12点左右(如0层时打怪1200,那么每升一级应该是长120,然后在这个基础上+12)这样的话练到12层就等于多出来了一层杀伤!!!至于某些传言所说的容易招比正常招在pk的时候出招快,纯属无稽之谈.出招快慢取决于个人手感和技术.

2.攻的多寡.按我一贯的做法是越高越好!!但也有个比例,基本上我是创500内非掉级招加3000攻最少,后来有了装备,尚武的时候加到了5000,创800招时是3200的攻.1000招从不创,因为我用1200*1200的老拳.可以看出来,攻和内的比例是按倍数加的,也许是我迷信.要不要加这么多还看你自己.

3.声望.声望多寡影响招的好坏一说,纯属虚构!!本人就是例子!!因进江湖近1年,pk情况可想而知,声望最低时跌破2位数,但网宿谁敢说他小招有我杀伤高??(12层1438)

附:系统n次改版后,一些现在或未来都不可能再现的"绝世武功".  
1.测试时个别有识之士为兼顾攻内平衡,开创1500×1500大招先河,并于正式版后大展其威!!具体表现为散仙打地仙无视高转克低转先去内铁则!!!1转打2转直接去血,恐怖之极!  
3转的同时被封.  
**2.12**00×1200拳,传承测试时1500拳之精髓,要求属性更加合理化的bt武功,于低敏克高敏时期无敌于天下,如火狐冷月孤星剑,网宿无痕一剑(嘿嘿)等. 于1848版之后被封. 3.  
0内招.4转时期出现,空内即可出招,起初被当做烟花来玩~后经高手提出而被广泛应用与pk赛,练至12层可打掉内人2000左右内力~可谓"空手套白狼"之典范!!**2.5**版之后绝迹.
