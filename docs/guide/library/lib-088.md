# 五转飞升详细攻略（整理中）

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

魔道① 掌握幻变魔力：飞偷（易容，好像没开，可以出监狱不花钱）② 成为无敌战神：声望（可以靠掉3级改变身上的点数分配，团P有优势）③ 驯养绝世魔售：养宠（1级宠一抓必中，抓来的宠至少85忠，可以把宠多练**50级**，可以超进化）④ 苦修无上魔功：修行（**1400级**）⑤ 但求魔度众生：功德（买三级房子8000W、进新山城不花钱）剥皮地狱：地缺魔（30，52）**

1：幻变魔尊（偷窃）  
如果偷窃≥25万，可以从地缺魔处得到掠天之令  
受命到磨骨地狱找破天魔（12，35），对话后得到[迷惑](/pets/191)丝巾  
到皇城的太和殿找飘雾（17，32），花50W得到飘雾从皇宫盗来的七心海棠  
再到名剑山庄的右厢房找李氏三兄弟（14，12）盗取飘云的魂魄  
接下来就看运气了，如果失手偷不到会被送入天牢，所以建议在整点时偷  
得到飘云的魂魄后去找破天魔，打败迷失本性的飘云后，就得到“掠天守护佩”  
**详细任务过程**： http://bbs.tx51.com/viewthread.p ...  
p;page=1#pid2059942

2：嗜血魔尊（声望）  
如果声望≥2000万，可以从地缺魔处得到嗜血之令  
受命到污秽地狱找幻灭魔（41，48），对话后接受幻灭魔的考验  
到天牢第二层找魔界守护将军（24，36），连续战斗三次，中间不没中断  
第一次两人都是**2000级**，第二次变成**3000级**，第三次是**4000级**；魔将玄广是土性的，雪空是火性的！  
打赢后得到英雄令，回去找幻灭魔复命，得到“嗜血守护佩”  
**详细任务过程**：http://bbs.tx51.com/viewthread.php?tid=234391

3：堕天魔尊（修行）  
如果修行等级≥2万，从地缺魔处得到堕天之令  
受命到天灯地狱找曜日魔（35，47），对话后接受曜日魔的委托  
去名剑山庄，接下李氏三兄弟的一掌，降**100级**，得到“金光刀”  
重练回**1300级**，再去接李氏三兄弟一掌，降**200级**，得到“堕天甲”  
再练到**1300级**，再接下李氏三兄弟一掌，降**300级**，得到“龟背靴”  
**->合成魔界法器**：金光刀9点、堕天甲12点、龟背靴3点、甲为主锻造  
带着魔界法器找曜日魔复命，就能得到“堕天守护佩”

4：摄魂魔尊（养宠）  
如果养宠经验≥20万，就可以要求考验养宠技能。从地缺魔那里得到“妖兽之令”，受命到铡头地狱找善于操控万千幻兽的妖兽魔君兽心魔（31，33）。先打败兽心魔座下五大守护兽，再去按照兽心魔的要求重新驯养五大守护兽，完成兽心魔的要求就可以换到“妖兽守护佩”。

5：泯灭魔尊（功德）  
如果功德值≥1万，从地缺魔处拿到泯灭之令  
受命到焰浆地狱找无情魔（25，26），对话后得到渡仙令  
去沙城找凝云（24，42），接受凝云的要求去找银花婆婆帮忙  
制作“紫阳丹”，“点击这里查看制作方法”  
带着紫阳丹去雪融谷找银花婆婆（7，31），对话后收走紫阳丹得到“丹凤钗”  
把丹凤钗交给凝云，得到一件银风战衣  
带着银风战衣回去找无情魔复命，可以得到“泯灭守护佩”

**先丢这里，有空再改**完成十个支线任务中的任何一个，（目前飞功德的任务五和十由于功德值刚开放，暂时无法完成）带着对应的守护佩，大罗金仙到盈露台找仙界接引使，魔神到油锅地狱找魔界接引使，就可以完成飞升。

**火属性任务**：http://bbs.tx51.com/viewthread.php?tid=106008  
**水属性任务**：http://bbs.tx51.com/viewthread.php?tid=105776

不过做任务过程中如果有损失对应的经验要补回才能成功飞升：  
::: warning 注意
飞升时，飞升养宠的要损失二十万的养宠经验，飞升声望的要损失一千万的声望值。
:::  
飞五转养宠的基本条件：仙飞养宠需要：**100级**蓝发一只。**200级**[绿妖](/pets/208)一只。**300级**傲雪一只，**400级**[至尊林](/pets/81)一只。**500级**[蓝鸟龙](/pets/22)一只。魔飞养宠需要：**500级**蓝发。**400级**绿妖。**300级**傲雪。**200级**至尊林。**100级**蓝鸟龙

仙飞升养宠的得到红色[小猪比特](/pets/308)，魔飞升养宠的得到肉色[小猪安特](/pets/309)，其余职业的仙飞升得到异种[穿心兽](/pets/35)，魔飞升得到红色[飞天鼠](/pets/23)。  
另外附上各个职业的优势：  
**飞升养宠**：对一级宠物一抓必中，抓到后初始忠诚85，出征宠物等级上限上浮50，将来可以用养宠经验换得可进行四进宠的最后进化；  
**飞升修行**：人物等级上限上浮**100级**；  
**飞升锻造**：锻造装备要求修行等级下降10％；  
**飞升创招**：同样系数的招数，使用内力不变的情况下，杀伤力上浮10％；  
**飞升声望**：损失少量级别，找特定npc可以随时重新分配所有当前点数，但是失去创招的能力；去污秽地狱，那里的NPC可以给嗜血魔尊重新分配当前所有点数  
（掉3级）  
**飞升偷窃**：掌握易容术，随时变成其他玩家造型，被抓入监狱出来不需要交钱（不含天牢）。  
**飞升功德**：交易时价钱降低,可用功德换得特殊宠物。
