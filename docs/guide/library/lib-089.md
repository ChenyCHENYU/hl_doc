# 快速带功德--6个半小时1W？

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

申请4个新人帐号（免费3天）建议帐号名尽量一致。比如：king01、king02、king03、king04...记住一个帐号（便于快速修改）。

**按幻兽之灵装备下来**：1级新人  
100血250防350敏（新人20点加敏）  
3。宠物篇

单人天关3层抓N只（各人能力，我有2个宠袋。抓了20只）**150级**的[欢欢熊](/pets/189)，敏捷在150-170左右不等。

高兴的话毒死这帮熊，就是血为1  
**解释一下**：1、为什么要抓熊。因为推荐挂功德的地点为松竹林，打**190级**的刺头敏在130左右。让新人带熊出征可以跟人合击（并不是指望这些熊帮你秒刺头。虽然熊是克刺头的）打还是要靠你大号的人和宠！

2、为什么要毒死他们。因为熊能和人合击，所以也有经验拿。当新人够等级了。熊也升了不少级。下批新人怎么办？如果毒他们到1点血，可以使他们在战斗中死亡概率加大，减少升级可能。（我20只用光后就没再去抓。太麻烦。新人带乌龟出征了！不过速度就慢了点）

准备就绪就开动吧，建新人，重新分点。全敏！新人出来在客栈，然后集结到水城驿站。1个号组队。另外3个加。凑200两给组队的号。从驿站直接到树城去松竹林。大号分发装备、宠。然后组队！小号们穿戴整齐。带好宠出征。不用加血了。直接加入队伍混吧。  
::: tip 玩家提示
提示：大号用**2.5**版本开宠爱。小号们开**2.0**版本。常用命令里选自动战斗！队型：鸟阵。
:::

20分钟后。新人们都55-**60级**了。停。上缴装备。钱财.宠（超过150就连宠带人一起删了）。  
10分钟后。又一批新人来到了松竹林。重复以上的动作。。。。。

计算：

4个新人=**60级**×12=720点功德/30分钟！1小时1440点功德。**6.5**小时~7小时。1W功德任务圆满完成！  
我因为在两台电脑之间反复奔走。又因天气太热汗如雨下。所以奔走的速度约等于乌龟爬行速度的80%。有条件1开5的朋友估计时间更短。

以上为本人带功德的一点小经验，与大家分享。如有不对的地方请大侠们指出！
