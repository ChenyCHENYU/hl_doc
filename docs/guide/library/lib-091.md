# 详解投胎！

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

二：为什么要投胎？投胎有什么好处？  
投胎即可以增加修行，又可以获得永久红利点，还可以帮助一些任务的完成。  
投胎后的修行奖励是按照投胎时的级别乘以投胎层次的倍数来了，既地仙×1倍、天仙×**1.5**倍、大罗×2倍、5转×**2.5**倍。  
**比如**：地仙**800级**投胎可以获得奖励的修行等级是800×1=800，地仙**1200级**投胎获得的奖励的修行等级是1200×1=1200  
**比如**：天仙**800级**投胎可以获得奖励的修行等级是800×**1.5**=1200，天仙**1200级**投胎获得的奖励的修行等级是1200×**1.5**=1800  
投胎后获得的红利点根据投胎的层次分别是：地仙10点、天仙15点、大罗20点、5转25点。

三：什么人适合投胎？  
幻灵游侠毕竟是个集养宠、锻造等多方面的游戏，所以只有当你在养宠和锻造等方面有一定的积累了，投胎才能够事半功倍。  
上网时间比较充裕的玩家（能够24小时使用我网络），修行等级达到一定高度，所带出征宠物能够轻松的先出手秒50~60关的宠物，这样的玩家反复投胎比较见成效。  
虽然每次红利点加的比较少，但聚沙成塔，投胎次数多了后，累计起来却是个不小的数目。

四：如何合理分配网络使用时段？  
这个问题不针对上网没固定时间的玩家，只为能够24小时使用网络的玩家而设。  
地仙**800级**层次投胎是目前最快的，因为不需要比如飞仙子做图鉴那样的任务。  
如果白天能够长时间面对网络，那么可以把需要破劫的地仙阶段放在服务器维护后的10点~18点这个阶段，投胎后的凡人放在18点~2点，散仙放在2点~早上服务器维护。  
如果是晚上能够长时间面对网络，那么可以把散仙阶段放在服务器维护后的10点~18点这个阶段，地仙放在18点~2点，投胎后的凡人放在2点~早上服务器维护。

五：投胎注意的事项！  
出征的宠物一定要设置成你练级的**1200级**宠物，投胎后不要更换。  
凡人**70级**后可以去天关50~53关挂机到**700级**（一仗一级），**700级**~**800级**可以去59、60关挂机（**780级**后2仗1级）。  
凡人和地仙阶段需要重新在天关50那存记录，身上带的进入天关的钥匙不要丢，通过装备到身上在换下来调整钥匙在物品栏的位置。

::: tip 玩家提示
PS：如果你有充裕的上网时间，成长能够秒到60关的宠物，相应修行等级的装备，那么一天投胎一次，增加1600级修行、10点永久红利点就不是梦想。
:::

投胎的好处在于，你只需要地仙阶段守在电脑前，而其他时间你尽可以做别的事情，而兵解是做不到这点的。

装备提升的属性点毕竟是有限的，即使你人物到了100W等级，你的属性点仍然是有限的，而投胎的好处就是可以增加这个属性点。

而且投胎的过程也在增加修行等级，虽然一次增加的要少些。
