# 兄弟天关隐藏关揭密

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

第70关，如果队长出征宠物成长率超过50，和守关npc说话，则进入隐藏关，并且如果宠物满足条件，完成地图上npc要求的简单任务，除了战斗中可以抓到新宠物[强盗](/pets/101)，还可得到20000修行可装备的＋300攻的身饰“云淡风清瓶”奖励。而且无论任务完成与否，都可以得到一颗锻造用的水晶。

第76关，如果身上有疾风之令，和守关怪物对话，则有进入隐藏关提示，进入后，用疾风令可以和地图上npc交换三种装备之中的一种。并且该地图上还有宠物进化变异和越级进化的热点。  
（3种装备之疾风之镯+100防**50级**用，疾风之戒+120敏，**50级**用。疾风之瓶+110攻.**50级**用）－（进化变异的地点--和npc说话他会告诉你：在玄天阵中心进化、可以大大提高宠物越级变异的几率，左侧的小台上可以提高变异的几率）

第80关，如果战斗后队长的出征宠物保持满血，则可以选择进入隐藏关。该地图有新宠物[鬼火君](/pets/221)抓。并且战斗奖励有可以给宠物疗伤的再造丹。
