# 详解霸王卸甲以及宠攻要求数值能伤到霸王卸甲.

<TopicHeader cat="玩家文库 · 锻造-防具" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**霸王卸甲属性**：攻在760-850之间，防约76000-78000.血约15576-16874之间.  
霸王卸甲的属性不是固定的。曾经0防不防御的情况下，让霸王卸甲打，掉血大概是1580-1686这样，（最高与最低值，某只攻比较高），非攻阵，刚才用杀伤为1298的招打大象，13拳挂，估计血在15576-16874这个范围内，均属本人亲身经历，若有偏差可将自身不同的经历上述……

以下是详解霸王卸甲的防御：

宠物被怪物克  
**怪物打宠去血公式为**：宠去血=怪攻击 ×2 － 宠防防 ÷2

先假设霸王卸甲防数值为78000  
普通情况下：  
19500×2-78000/2  
当金系宠攻到达19500以上（带章）没出龟背阵型，可以伤怪血。往后算的就每点攻能多伤1滴血，1W点攻就是伤1W血。

**出龟背的情况下**：（只做影响防御的，其他不管）：  
出龟背，3个怪阵型影响防御高出7%。  
20865*2-78000/2+78000*0.07

当金系宠攻到达20865以上（带章）可以伤怪血。往后算的就每点攻能多伤1滴血，高1W点攻就是伤1W血。

实验:  
22666攻的凤凰.普通打怪去血数值是6149或7618.  
先算防的最大值:  
6149=22666×2-霸王卸甲/2 (防为  
78366)  
**再看最小值**：7618=22666×2-霸王卸甲/2 (防为  
75428)  
**算算平均值**：(6149+7618)/2=22666×2-霸王卸甲/2 (防为  
76898)
