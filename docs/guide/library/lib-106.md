# 一级房子升级二级房子

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

有中式,西式,阿拉伯式,南方式的房子样式,满意后花费1500万购买了二级房屋的设计图....

带着这设计图回到自己已经购买好,并且建造了一级房屋的小房旁,点击房屋后会出现选项,原来的拆房选项变成了拆房或升级房屋,选择升级房屋,点击后房屋就升级成二级的了...

(与一级房屋相比,二级房屋这类特殊物品可以放4个! 各类家具装饰品相加一共可以放置20个...)
