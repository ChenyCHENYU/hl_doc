# 安家置业

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

到皇城找黄大人(37,62)可以进入参观初级三种样式的房屋, 有中式、阿拉伯式、欧式三种风格,  
选择自己喜欢的一种就可以花费500万购买该房子的设计图纸了

->点击被栅栏圈围的土地,  
会出现选项, 主要功能为建造房屋、缴管理费、退地皮; 如果有房屋设计图, 就可以开始建造房屋, 点击缴管理费一次就缴钠5天共50000两维护费,  
多点就可以多交纳(最多可以缴30天也就是一个月的费用), 退地皮是将此地皮退还给帮派,  
能够得到5万

->点击房屋后,  
可以看到自己已经缴了管理费用的天数以及回家、缴管理费、拆房、门锁相关等选项

**拆房相关**：选择拆房以后,  
房屋会变成地皮, 但房屋内的家具等不会消失, 只要在同地图上重新建造房屋, 东西就会回复, 这个功能是用来房屋升级使用的; 如果变成地皮以后, 再选择退地皮,  
那么家具等物品会彻底消失的!?

**门锁相关**：皇城的黄大人(37,62), 花1000两可以购买到空钥匙, 在自己的房屋选项中选择花1000两配钥匙,  
配了钥匙以后就可以将钥匙给朋友, 让朋友进入自己家; 如果觉得自己家钥匙所托非人或者给太多人了, 就可以花10000两换锁, 换锁以后,  
其他人就不能再用原来的钥匙进入自己的家了

**缴费相关**：房屋管理费任何人都可以缴, 只要点击房屋后点击缴管理费就可以缴了;  
管理费如果欠缴时间超过10天, 就无法进入, 如果欠缴时间超过20天, 帮派就有权利收回地皮
