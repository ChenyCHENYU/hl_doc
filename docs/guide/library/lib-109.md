# 水属性任务

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

首先到华山亭找到剑无涯,然后得到一块令牌,然后到西码头找到[骑士龟](/pets/116),从那里得到水行令1

然后到剑池谷找到蝴蝶飞羽,听飞羽说需要她姐姐的[神气](/pets/40)花粉,就到坠泪岗借花粉,坠泪岗找到翠羽得到盛露瓶找丘丘,到吓死人洞窟找到丘丘,得到神气花粉,然后直接回到剑池谷找飞羽换得水行令2

到净沙原找霹雳聊天之后开战打**500级**鳄鱼,得到水行令3

然后到不归海岸,找到[蓝牙](/pets/127),听蓝牙说要找到"蓝幽草"救母亲,回到断魂崖找到糊涂老人得到草药,交给蓝牙后,得到水行令4

到斑鸠小舍,和灵裳说话,要找到四处巡游的恩人...到沉没的城市找到无忌战斗打7只**700级**[铁甲龟](/pets/117),得到冰泪坠,回去叫给灵裳,得到水行令5

到凰之谷,找到罗锅,他要求一只**500级**以上忠100的[苦行龟](/pets/118)来代替他,他才会给你令牌,得到神龟令,拿龟叫给罗锅后得到水行令6

接下来去绿幽洞找到[乌哩头](/pets/119)的小弟,听他说要先打赢赏月谷的乌鳢头大哥的一群手下,胜利后回到绿幽洞的乌哩头小弟得到水行令7

接下来到徘徊林找到[蛋蛋鱼](/pets/141),听他介绍树城一带的水属性气示弱,拿他的委托书去树城(委托书无限领取),到树城斗宠处的下面找到"长者"听她说要到山城附近找水源,到山城兄弟天关入口处的找到鄂鱼霸王,打赢7只1100的鄂鱼,委托书被收走,得到鄂鱼骨,回去叫给树城的长者,得到长者项链,回到徘徊林叫给蛋蛋鱼长者项链得到水行令8

接下来到水城找到[羽衣](/pets/134),带上羽衣给的[精灵](/pets/231)项链去青灵洞找到纷飞打7只1300[粉衣仙子](/pets/138),得到神圣之羽,到水城交给羽衣得到水行令9

然后到山城找到 [口袋鸭](/pets/128)扁嘴 ,听他说他的兄弟在沙漠走失了,我们去营救,再青之绿洲可以找到 口袋鸭嘎嘎  
,不过要营救嘎嘎还要去取得青灵水,听说是被几个家伙看守,这里我找了好久,可能是我眼神不好使没有注意到,得青灵水是在青之绿洲(52,41)打完后在和口袋鸭嘎嘎对话,得到平安信,回到山城交给口袋鸭扁嘴得到水行令10

接下来到雪城(94,58)找到[灵衫](/pets/136),灵衫要找到彩云衣,于是到雪容谷,找到幻兽怪盗,要战斗打7只**1500级**[空手道](/pets/66),得到彩云衣,回去交给雪城灵衫,得到水行令11

到地狱第3层聋耳地狱找到[红刀](/pets/125),带着红刀给的身份牌,去找地狱天使换假条,地狱天使在冰封地狱,要打9只**1700级**蓝发,胜利后得到"特赦书",交给红刀后得到水行令12

前往独木原,找到[欧欧](/pets/124),欧欧要请帮忙找3500的毒药(毒药只能用此地战斗奖励的2样物品锻造才能得到),特制毒药-3500血和加强飞镖+1000攻击,毒主炼7点,镖1点,得到超强毒药(提供几个打镖的坐标(33,40) (25,25) (26,26) (29,43) (28,41) (29,43)  
),给欧欧后得到水行令13

去树城宠物店找到[愣头青](/pets/121),他会让你去帮它拿过路条,到石壁洞口和左边的[山贼](/pets/103)说话,他会让你选择给钱(5W)还是战斗(10只1900的[小妖](/pets/193)),胜利后得到"过路条",拿回去交给愣头青,它会给你水行令14和一只1级的[巧巧](/pets/129)(类似[盈盈](/pets/130),但要注意这不是盈盈,而是异种宠物)

到盘榕谷(15,16)找到[卜卜](/pets/122),拿到介绍信,去紫苔洞穴找水族长老(54,29),打败10只2100的[逐浪仙子](/pets/149)后,得到"水长老的认证"拿去交给卜卜,他会给你水行令15

到碾肢地狱(22,39)找到[摇爷](/pets/120),他请你帮他带"给朋友的信"给聋耳地狱的红刀,交给红刀后,拿到温玉(**50级**+30防+30敏),交给摇爷后得到水行令16

先到东码头(33,16)找到[硬骨鳄](/pets/115),拿到"母亲的委托",再去西码头(82,54)找到鳄鱼兄弟,打败10只2300的鳄鱼后拿到"孩子的悔过书",然后再带着800-**1000级**的巧巧回东码头找硬骨鳄,她会给巧巧加**200级**,并给你水行令17

到新山城找到[绿甲](/pets/126),受他委托去帮助他一个朋友,得到一条水之链 (0级加防80,戴左边的)  
然后去海城找到疑惑(绿甲)他会问你一个水的力量的问题 (答案是:变化不定的力量) 得到一封信回去新山城要求得到确定答案,回去后得到水行令18

到镜雪原找[大嘴鳄](/pets/113),观日桥头找小贼,打10头2500的大象,结束后得到避水珠,回去交差得到水行令19

到炮烙地狱找到铁甲龟,要求帮它探望朋友,去雪城找到灵衫,得到活络油(FT),带回给铁甲龟后,要求把[彩衣](/pets/133)练到800-1001(彩衣就是巧巧进化后的..跟[霓裳](/pets/135),羽衣一样的! ) ,把彩衣练到801,去找铁甲龟,彩衣出征,奖励**201级**,得到水行令20

首先弄到升级药,再到武当练功房找到[丸子鱼](/pets/142),,给它后得到水行令21

到山城宠物店找嘎嘎,要求去华山脚找幻兽训练官接受考验,打10只2700的嘎嘎,打赢后得到验证之石,回去山城宠物店得到水行令22

降尘台找到粉衣仙子,要求帮助它取得仙界居住权,去紫阳门找到仙界管理者,对话有两个选项,一个是200万取得居住权,一个是武力获得,我选的后者,打10个2900的地藏,得到居住权证回去找粉衣仙子,得到水行令23

在独孤亭随机打到"兽玉",(从凰之谷跳出后,直接战斗,得到兽玉的几率更高)然后找到老工匠,得到"幻兽之灵",在到皇城找[乒乓鱼](/pets/143)(81,91),对话后得到水行令24

(对水系图鉴做了20个或以上),到逆之往事(23, 52)的"悠然老人",如果回答"我想要拥有强大的力量"、可以得到霸王令去找敖雪兽霸气通过考验；如果是回答"对未知的力量的好奇心"、则得到奇云令,可以去找[幻云兽](/pets/151)瑶奇接受考验

霸王令任务：  
带着"霸气令",到天堂空灵园(31,87)找 敖雪兽霸气  
,对话后得到"族长令",再到将军碑谷找石老头(50,18/就是进入新山城的几个士兵的右边),对话后得到"名帖",再到名剑山庄练功房找"乌云盖天",对话后进入战斗,打赢了得到"聚水珠",回到天堂空灵园就可以在霸气的帮助下提升**300级**的等级(当然不超过最高等级),并得到碧水令..到此完成水属性任务霸王令剧情

奇云令任务：  
到天堂空灵园(53,105)找 幻云兽瑶奇  
,它把奇云令收走,给个"皇城通行令"叫去找翡翠白玉汤, 到皇城甬道(13,18)(在英雄冢里,和那女的NPC说话进去就是了<当然要有进英雄冢的令牌吖>)找到"悟食老人",得到"家书",水城找正在筹钱的"悟食老人"的儿子悟施人交10万两银子,得到一封家书,回到悟食老人那换翡翠白玉汤....带着"奇云令"和"翡翠白玉汤",到天堂空灵园找  
幻云兽瑶奇 ,让**800级**以上的[彩虹仙子](/pets/137)处于出征状态,瑶奇就会帮你进化成"[敖云兽](/pets/154)"并得到碧水令

附: 巧巧→彩衣→彩虹仙子→敖云兽
