# 火属性任务

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

先完成训兽经任务, 得到训兽经; 到水城一艘船上(48,85)找 欣欣, 对话后得到火行令2

到华山腰道找  
采药人朱照启 花6000两买到华岳仙芝; 再到山城找 失忆的静儿 (65,71), 对话后得到一封家书,  
带着家书, 闯到单人天关第4层找 安安 ,得到火行令3

先完成[乒乓鱼](/pets/143)任务, 得到1级乒乓鱼;  
到将军碑谷(59,51)找 小华, 对话后得到火行令4

先完成佛经任务, 得到佛经; 到沙盗洞口(**36.27**)找 小伟 ,对话后得到火行令5

先到凰之谷抓只1级的[雪凤凰](/pets/17),再到暮归道(8,28)找  
[小妖](/pets/193)阿威 ,对话后得到火行令6

先到水城宝洞打到褐色宝箱钥匙; 再到敕勒川(80,50)找 辛巴, 对话后得到火行令7

到银罐谷找 小遥  
(45,27), 通过和他战斗(5只**600级**的[匆匆](/pets/195))后可以得到火行令8

先完成林捕头的玉佩攻略, 得到林捕头的玉佩; 到怨灵洞口找 希亚 (36,63), 得到火行令9

先到雪城的玉洁桥打到6个冰石,  
再找常枫(每天的20:00到21:00)换得冰晶; 到铜人殿找 小天 (77,57),  
对话后得到一只1级的[旺旺](/pets/197)和火行令10

每天的4点半, 到山城便利店找江南霹雳堂的人买到烟火;  
再到山城找 小阳 (115,78), 对话后得到火行令11

在青幽洞(13,30)找到 风影,对话后得到一封信,  
带着信到水城找虫虫(79,79), 得到回信后, 交给风影得到火行令12

:flower身上带着火行令12就可以到明月桥找[嘟嘟鸟](/pets/13)(10,8)战斗, 打**800级**的嘟嘟鸟, 进化后是[觅雾鸠](/pets/16):flower

对火属性图鉴登入9只以上且旺旺等级在800-**900级**忠100, 在海底的深蓝海底战斗随机得到火之念珠; 来梦佛窟(3,61)找 晓风, 如果旺旺合格, 旺旺等级提升**200级**并得到火行令13

在天堂抓只1级的[小叮咚](/pets/266), 到瑞天雪城(66,100)找 洛影, 得到火行令14

首先拿到雪狼湖任务中的白色绣球花, 到华山顶(33,43)找小狼仙, 对话后得到火行令15

从华山顶(33,43)小狼仙处进入雪狼崖(必须带有1级[奇变天狼](/pets/204)或是真爱花种才可进去), 找到老狼仙(27,26), 得到一封信, 带着信到树城从灵儿处到寒月台, 找到蝶依, 得到回信后交给老狼仙, 得到火行令16

首先要在古铜洞窟2战斗随机得到玉露丹, 再到沙城酒鬼冢(39,24)找到高阳酒徒, 得到索酒信, 到名剑山庄找张一丁对话,得到极品壮元红后, 回高阳酒徒对话得到归元仙露,  
再到武当炼丹房外找 阿蒙 ,得到火行令17

首先要在传说中的英雄冢战斗随机得到广陵散,  
并带着800-**900级**忠100的[啮风犬](/pets/201), 从水城虫虫(79,79)处到达教堂, 找 赫鲁斯(89,63)对话,  
啮风犬等级提升**200级**并得到火行令18

到敕勒川大蓬内(20,13)找 阿图姆 ,对话后进入战斗(5只**1350级**的[阿努比斯](/pets/213)), 打赢后选择回答,  
选择后面一句话交100W后得到火行令19 － (若是不想交100W, 先打输,  
然后替他送信到吊烤地狱(45,33)给魔女飞雪, 回来后再打, 这次一定要赢! 过了就有令牌;  
呵呵^^^^多跑两步就能省100W)

到断壁找到悠然老人(58,48),  
**根据回答选择不同的考验**： (完成一个即可、得到风火令就可接飞升5转的任务)  
1  
有力量就可以随心所欲(魅影剧情)  
2 希望有力量帮助他人(碧云剧情)

魅影剧情：

先带有九转任务的白玉扇, 对火属性图鉴了解18只以上; 再到守侯洞窟找魅影(29,52/阿修罗终极天劫这), 对话后得到一封信, 通过暮归道(8,28)的  
阿威 到百草池找到碧云(29,17), 带上白色绣花球到夜晚的时间伤口找到璇紫(早上7:00-9:00),  
对话后得到碧玉扳指, 带碧玉扳指回去给碧云后，碧云就给了玩家一对烈炎耳环。再回到魅影处, 带着**800级**以上忠100的[幻变天狼](/pets/205), 对话后天狼进化为[紫衣](/pets/209),并得到风火令

碧云剧情：

先带有九转任务的白玉扇,  
再到沙城找到胡老头(75,66), 对话后得到委托信, 然后带上白色绣花球到夜晚的时间伤口找到璇紫(早上7:00-9:00),  
对话后得到黄玉戒指; 再到守侯洞窟找到魅影, 对话后得到烈炎令, 交给胡老头得到感谢信, 通过暮归道(8,28)的  
小妖 到百草池找碧云(29,17)对话, 得到九阳丹和风火令,  
再和碧云对话, 收走九阳丹－人等级提升**300级**(不超过最高等级)
