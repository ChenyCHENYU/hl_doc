# 幻灵入江湖与退江湖攻略

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

在水城(101,88)找到贺捕头,跟他说话,他会给你一支贺捕头的飞镖....

拿到飞镖后到水城(31,88)找蔡参将说话,然后进入战斗(5“头”**20级**的捕快),打赢了以后就投身江湖了....

::: tip 玩家提示
ps
:::  
入江湖后可以pk、偷、加帮派(51级以上才可加帮派)、等等

退隐江湖

首先到吓死人洞1抓一只**300级**[纹地龙](/pets/272),然后在树城找灵儿(30,33)拿到香包,再到东码头找老渔翁(53,64),到名剑山庄跟小鱼(20,40)换1级[苦行龟](/pets/118)...

到水城当铺旁找贤者(66,71)拿金刚经,再去少林寺藏金阁找慧明和尚(12,5),跟他对话后收走1级苦行龟,就退隐江湖了....
