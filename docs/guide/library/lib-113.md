# 天魔解体

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

然后到地狱第11层 吊烤地狱(45,33)找 魔女飞雪  
,她会问你"天魔解体大法"是很危险的,会让你失去五分之一的等级,然后将剩下等级一半的属性点数返还给你......

注意事项：

一：等级**600级**以上就可以做这个任务了  
二：天魔解体必须下降20%的等级

三：剩下的一半等级的属性点数可以重新分配  
四：在解体以前最好把未分配的点数分配完哟
