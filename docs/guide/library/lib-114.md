# 宝洞寻宝

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

到水城客栈,通过客栈MM对话,可以进入山洞(邂逅洞窟)......在每个小时的前5分钟,邂逅洞窟(22,48)里会有一只宝洞守护兽出现,对话后就可以进入宝洞....

在宝洞里战斗,可以随机得到"褐色宝箱的钥匙"(**250级**左右的[白大嘴](/pets/7)).....

等待一段时候后会出现宝箱......宝箱一共有十个,左上角有四个,中间两个,右上角两个,右下角两个....点击宝箱后,就可获得里面的奖品.......
