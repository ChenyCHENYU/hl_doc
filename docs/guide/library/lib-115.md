# 增加功德值、飞功德玩家的部分优势

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**例如**：散仙1级队长、带4个新人一起战斗，一战下来有两个人升级、1个101级1个10级、则队长功德值增加2×4＋4＝12点

功德值不仅仅是5转飞升的一个衡量标志，可以让玩家体验扶助新人的乐趣，同时它对于任何一位幻灵玩家的作用都将是非常大的：  
1、宠物相关：功德值可以换宠物,而且换的是用养宠经验也换不到的宠物  
2、偷窃相关：可以消耗一定的功德值出天牢  
3、锻造相关：换取一些锻造用的初级宝石  
4、修行相关：换取一定的等级,效用相当于兵解或者升级药,但不能使用此方法过劫

新玩家定义：  
### 1、没有投胎过  
### 2、凡人  
### 3、等级≤600

老玩家定义：  
### 1、散仙以上

### 2、队长

1、五转飞升功德的条件限定在1万功德值，达到要求即可找相关NPC接受考验，飞升后不扣功德值。
飞升功德后，很多地方都会得到价格10％的优惠，例如进入新山城收费练功区，购买三级房屋等等<其他玩家购买需要8800万、飞功德的玩家只需8000万>，另外，飞升功德的玩家兵解时，护法等级增加程度在原来基础上再增加所得等级的10％，自己修行等级也会多加所得修行等级的15％。
举例如下：队长800兵解，队员1级，原来队长得到400的修行等级，队员得到**79级**，如果队长是五转飞功德玩家，则队长得到**520级**修行等级，队员得到**87级**修行等级

2、新山城功德殿，功德值换取宠物，需要的功德值大幅度下调，基本上是原来的15％左右。而且，如果五转飞升功德值的玩家在这里还有少要求功德值10％的优惠，对这几类宠物有兴趣的玩家可以前去兑换
