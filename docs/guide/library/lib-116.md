# 五行炼化之乾坤五行炉(开炼化功能)

<TopicHeader cat="玩家文库 · 锻造-武器" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

带着药王佩到武当练丹房内找到元元真人,元元真人会先考查玩家对乾坤五行炉的基本常识....当三个问题都答正确后元元真人会赠给玩家一个乾坤五行炉,并且指点了玩家的炼化入门知识.....

三个问题以及答案如下：

一：乾坤五行炉中最多可以同时放入几样物件进行炼制？ 答：8个  
二：乾坤五行炉是根据天地间的什么原理而来的？ 答：五行

三：在乾坤五行炉中武器是属于五行属性中的哪一个？ 答：火
