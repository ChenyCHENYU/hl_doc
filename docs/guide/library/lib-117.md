# 兵解攻略

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

然后在 逆之往事 找到魏无崖(64,38),对话后得到魏无崖的信;

再前往吓死人洞窟2找到天机真人(38,64),可以获得兵解所需要的凝神丹(使用高级->仙术->兵解)

兵解的条件：  
1、转世级别散仙以上,兵解前等级**800级**以上  
2、必须是以队长的身份组队,并且队伍中有队员(没有4个队员也能解)  
### 3、必须有凝神丹

兵解的好处：  
1、兵解的玩家兵解后等级将回到1级,同时原来的等级的一半将增加到修行等级上  
2、护法之人可以得到与兵解之人的等级差的十分之一做为奖励;如果护法是兵解之人的好友,将多得到这奖励的十分之一,如果护法是兵解之人的配偶,将多得到这奖励的十分之二

::: tip 玩家提示
注意：兵解的时候,身上除任务物品外所有装备以及物品栏里的物品都会被系统自动回收
:::
