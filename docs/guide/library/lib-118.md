# 鲁班秘籍全攻略

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

**兑卷**：在以下地点右键点击就能获得...该卷使用后+10点锻造经验  
卧佛沙城(92,53)、绿洲东郊(42,5)、情人谷(40,22)、赏月谷(14,38)、银罐谷(19,16)、落雁谷(17,21)、羁马谷(72,42)、沙盗洞口(32,21)、青幽洞(23,40)、镜雪原(14,25)、鸟鸣谷(16[23)、春水桥(54,59)、敕勒川(60,79)、西雪岭(38,49)、浮影水城外郊(31,40)、坠泪岗(32,21)、明月桥(11,15)、闲情园(34,43)、松竹林(27,13)、断壁(25,22)、西码头(36,8)、东码头(24,18)、断魂涯(10,27)、石壁洞口(38,17)、怨灵洞口(65,64)

上面记录的秘方为：  
霸王钳坎水、凤凰羽翼离火、龙鳞艮土、象牙震木、佛经乾金,主炼佛经,即可得到震卷秘录.....

**离卷**：在剑池谷战斗的随机奖励...该卷使用后+20点锻造经验  
上面记录的秘方为：  
人鱼之泪坎水、凤凰羽翼离火、象牙震木、龟壳乾金、水纹坠艮土,主炼水纹坠,即可得到长命锁  
**(长命锁属性**：+生命300  
-攻击50 800级用)

**震卷**：根据兑卷记录的秘方合成而得...该卷使用后+30点锻造经验  
上面记录的秘方为：  
皂角鞋坎水、狼爪离火、霸王钳震木、龙鳞乾金、鳄鱼骨艮,主炼皂角鞋,即可得到狂狼战靴  
**(狂狼战靴属性为**：-生命值100  
+内力1000 -攻击50 +敏捷500 1000级用)

**坤卷**：到水城找蔡参将,如您的偷技在20点之上,通过偷取方式成功则获得坤卷,偷取失败,将被送入监狱牺牲偷值...该卷使用后+40点锻造经验  
上面记录的秘方为：  
玄金镯震木、人鱼之泪坎水、狼爪离火、龟壳乾金、龙鳞艮土,主炼玄金镯,即可得到磐龙樽  
**(磐龙樽属性为**：+生命200  
+防御230 +敏捷200 2万修行用)

**艮卷**：在水城宝洞寻宝随机获得...该卷使用后+50点锻造经验  
上面记录的秘方为：  
正气甲乾金、正气甲兑金、象牙震木、龙鳞坎水、鳄鱼骨离火、霸王钳艮土,主炼乾位正气甲,即可得到正气战衣  
**正气战衣属性**：+生命400  
+内力2000 -攻击100 +防御300 +敏捷100 2万修行等级用(此处用到2件正气甲,不是错误)

**坎卷**：带本佛经,和一件自己锻造的1000修行加敏1000以上的靴子,到凰之谷(42,70)天机星换得坎卷....该卷使用后+60点锻造经验  
上面记录的秘方为：  
龟壳乾金、霸王钳兑金、象牙震木、人鱼之泪坎水、凤凰羽翼离火、龙鳞艮土，主炼乾位龟壳，即可得到宠物[谨慎]技能书

**巽卷**：带着村民衣(九转天心丹任务物品)、白色绣球花(雪狼湖任务物品)、妖怪内丹(名剑山庄除妖任务物品)找山城的巧匠凌风,可换得巽卷....该卷使用后+70点煅造经验  
上面记录的秘方为：  
玄武丹乾金、穿云丹震木、柔肠丹坎水、神凰丹离火、青龙丹艮土,主炼乾位,可得锻造效果相当于五个顶级毒药的蓝水晶

乾卷：在规定时间内去单人天关、夫妻天关、兄弟天关找归隐的将军楚青鸿购买...具体出现地点为单人天关90关(0点－12点), 夫妻天关第25关(12点－18点),兄弟天关的70关(18点－24点) 该卷使用后+80点煅造经验  
上面记录的秘方为：  
紫阳丹放于乾金、无极草震木、冰石坎水、无忧失心草离火、千年灵芝艮土,主炼乾位,可得提升人物功力的升级圣药通玄丹(该物品可以提升人物等级**10级**)

收集齐八卷,放入五行炉中相应位置,主炼乾位,得到鲁公秘录,使用后锻造经验+1000点...

秘方中各个材料来源：  
**龟壳**：坠泪岗战斗掉物品(45,25)(39,8)(37,17)  
**龙鳞**：吓死人洞2层战斗掉物品(11,29)  
**狼爪**：踏雪原战斗掉物品(59,73)  
**凤凰羽翼**：凰之谷战斗掉物品(33,55)  
**鳄鱼骨**：东码头战斗掉物品  
**象牙**：西雪岭战斗掉物品(27,35)  
**霸王钳**：不归海岸战斗掉物品  
**人鱼之泪**：带着"[乒乓鱼](/pets/143)任务"物品的人鱼项链,到海底城找人鱼三公主(34,44)交换得到
