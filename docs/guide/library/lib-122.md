# 醉拳任务

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

先完成逍遥战衣的任务,然后带着逍遥战衣找到浪子剑阿锋,他会给你一把醉龙舞雪剑....

然后到东码头找钓鱼翁(53,65),他会让你拿一只1级[红大嘴](/pets/9)跟他换醉生梦死酒.....

最后到酒鬼冢找到高阳酒徒(**39.24**),把醉生梦死酒给他,就可以学到醉拳....

醉龙舞雪剑  
攻击 +300 防御+100 敏捷-100(除了金光刀,目前最好的武器煅造材料)  
醉拳 使用等级 **600级**  
消耗内力 600 攻击效果1080
