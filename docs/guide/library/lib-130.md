# 御风而行(飞行石)

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

在犁春园(48,18)找到愚公，他会收下这双草缕鞋，提示你可以将他脚下的一簸“王屋之石”送给在不归海岸(93,65)衔石填海的精卫鸟楚云，如果里面有五彩石，便可学会御风而行

带上王屋之石找到楚云，将其交给她，如果是五彩之石(80%的机会)，楚云会赠予你一颗“飞行石”(此飞行石只能使用一次)；如果不是五彩之石，楚云也会将一片金羽毛(0级+防25左饰)赠予你作为礼物

注：御风而行的任务只有二转及二转以下的人才可以做
