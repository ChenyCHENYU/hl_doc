# 雪狼湖(真爱仙履)任务

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

在晚上的22:00-24:00带着真爱花种进入雪狼崖,跟老狼仙对话后,可以进入时间的伤口,跟里面的胡狼(12,11)对话,得到白色绣球花....

在早上的7:00-9:00带着白色绣球花再次进入雪狼崖,跟老狼仙对话后,进入时间的伤口,跟胡狼对话后,到达雪狼湖,跟这里的宁静雪(27,20)对话,得到真爱仙履....

真爱仙履 +200 敏捷  
0等级使用  
火属性任务中的夜晚的时间伤口就是早上7:00-9:00进去的...(必须带有白色绣球花才可以吖)
