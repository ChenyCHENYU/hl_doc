# 除小贼任务

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

到水城找怪老头(40,97)对话,他会警告你要小心小偷...如果向他求助该怎么办,他会告诉你别把钱放在身上,都存起来,同时还要练偷....他还希望你能帮他夺回被逃到山城附近的小偷所偷走的东西....选择帮助他,你会得到物品"物证"....

带着"物证",找到枯井原的笨小偷(38,23)...他提出用武力解决,选择"我可不怕你",就进入战斗...战斗胜利,得到物品"贵重项链",将"贵重项链"还给怪老头,你的敏捷会加10点，等级提高**10级**....
