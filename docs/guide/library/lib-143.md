# 仙魔互转(限制800级以上)

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

到 华山腰道 (68,19)找 采药人朱启照  
拿到两颗无极草,再到武当炼丹房找元元真人,进入战斗(5只**800级**的[刚雷狒](/pets/74)),打赢后得到无极天魔丹(循环2次、打两颗)

再到 逆之往事  
找到魏无崖(64,38),对话后得到魏无崖的信,前往吓死人洞窟2找到天机真人(38,64),可以获得兵解所需要的凝神丹(只换1颗)

带着1颗无极天魔丹和1颗凝神丹到地焰洞找地狱守护MM对话,得到神魔丹

打入地狱,  
在钉床地狱找到噬魔女(14,30), 对话后就由道入魔了

“由魔入道”任务攻略

到 华山腰道 (68,19)找 采药人朱启照  
拿到两颗无极草,再到武当炼丹房找元元真人,进入战斗(5只**800级**的刚雷狒),打赢后得到无极天魔丹(循环2次、打两颗)

再到 逆之往事  
找到魏无崖(64,38),对话后得到魏无崖的信,前往吓死人洞窟2找到天机真人(38,64),可以获得兵解所需要的凝神丹(只换1颗)

带着1颗无极天魔丹和1颗凝神丹到武当练功房内找无极真人,对话后得到脱胎换骨丹

打入天堂,  
在武神殿找擎天子(31,23) ,对话后就由魔入道了
