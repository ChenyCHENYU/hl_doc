# 四转仙魔飞升任务(大罗金仙及魔神)

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

注意以下几点：

1 阿修罗**1000级**以上；在地狱禁区－油锅地狱找相应的NPC飞升  
2 对图鉴的要求如下：  
**水系**：15只 土系：13只 木系：11只  
**金系**：10只 火系：9只  
3 选择其中一种属性飞升，必须分别达到以下要求：  
**水系**：26只 土系：19只 木系：25只 金系：13只  
**火系**：18只  
4 选择哪一种属性的图鉴飞升，就奖励得到该对应属性的终极宠物一只。  
**金系**： [蓝鸟龙](/pets/22) 土系：  
**[蓝发魔姬](/pets/285) 水系**： 敖雪兽 火系： [绿妖](/pets/208) 木系： [至尊林](/pets/81)

四转之转大罗金仙

注意以下几点：

1 天仙**1000级**以上；在天堂禁区－盈露台看守区选择相应的NPC飞升  
2 对图鉴的要求如下：  
**水系**：15只 土系：13只 木系：11只  
**金系**：10只 火系：9只  
3 选择其中一种属性飞升，必须分别达到以下要求：  
**水系**：26只 土系：19只 木系：25只 金系：13只  
**火系**：18只  
4 选择哪一种属性的图鉴飞升，就奖励得到该对应属性的终极宠物一只。  
**金系**： 蓝鸟龙 土系：  
**蓝发魔姬 水系**： 敖雪兽 火系： 绿妖 木系： 至尊林
