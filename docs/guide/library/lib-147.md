# 各级双飞简明攻略

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

到新山城最上面(40,96)找通玄童子说话,进入飞升门,二转到四转的夫妻双飞将在这个地图进行......

1:散仙飞地仙或夜叉,基本要求与单人飞时一样;分别拿两颗仙道飞升药或者魔道飞升药锻造出双飞药...两人组队,队长身上带药找 人和童子  
对话(15,25),如条件满足,对话后双飞....

2:地仙飞天仙、夜叉飞阿修罗,基本要求与单人飞时一样;分别需要两颗天仙飞升药或者两颗阿修罗飞升药锻造出双飞药...两人组队,队长身上带药找  
地利童子 对话(30,25),如条件满足,对话后双飞....

3:天仙飞大罗金仙、阿修罗飞魔神,基本要求与单人飞时一样;双飞时两人必须飞同一系的,飞升丹药也必须是同一系的...将两颗同一系的丹药锻造出双飞药,两人组队,队长身上带药找  
天时童子 对话(21,21)  
(23,21),如条件满足,对话后双飞....

4:五转的双飞在下一张地图通仙之境进行,大罗金仙或魔神双飞,基本要求与单人飞时一样;两人带的必须是同样的守护佩,飞同样一种类型....

身上要留两个宠位  
双飞后系统除了送单飞时送的宠之外,还将多送夫妻双方每人一只 [盈盈](/pets/130)  
,而且盈盈的成长会随着双飞次数的提高逐渐提高....
