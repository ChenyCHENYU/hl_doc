# 投胎转世

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

首先到东码头（10，21）找天闲老人，对话后得到求道介绍信

再到逆之心情（16，36）找抚月仙长，对话后得到天师令牌

到地狱第3层聋耳地狱（45，17）找[红刀](/pets/125)，对话后进入战斗（5只1200的红刀），得到魂玉

带着魂玉到武当炼丹房找元元真人，对话后得到收魂佩，带上收魂佩就能请抚月仙长帮助投胎了。

**单人投胎**：回到逆之心情（16，36）找抚月仙长，对话后就投胎了，投胎后进入逆之轮回，可以选择任何一个人物的形象（不分男女哦），选好后通过地玄真人回到水城

**夫妻投胎**：夫妻俩都有收魂佩后，两人组队，队长和抚月仙长对话后就投胎了，投胎后进入逆之情结,在这里就可以选择人物形象了，（男的只能选男性肉身，女的只能选女性肉身），选好后通过地灭真人回到水城

二转级投胎后修行等级=原修行等级+投胎时的等级

三转投胎后修行等级=原修行等级+投胎时的等级×**1.5**  
四转投胎后修行等级=原修行等级+投胎时的等级×2

五转以上投胎后修行等级=原修行等级+投胎时的等级×**2.5**

投胎增加的永久红利点数不同与飞升的红利点数，这个点数是不会因为飞升或者下次投胎被百分比弱化到最小，而是做为附加点数额外计算的，也就是说如果投胎次数越多，这个点数累计的越多，要是有耐心和毅力，达到2000点都不是问题。

红利点数初始是0，投胎时候得到的奖励点数是红利点数+（地仙级是2，天仙级是3，以此类推）×5，

**修行层次是**：二转是2，三转是3，四转是4，五转以上是5。  
第一次投胎时根据不同修行层次，得到不同点数。

而第一次所得到的点数分别是：  
**二转**：10；三转：15；四转：20；五转以上：25点。

第二次开始，现红利点数=原红利点数+（修行层次）×5
