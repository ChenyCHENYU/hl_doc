# 帮派宠物摆摊,训兽师和护士MM(限制3级帮派)

<TopicHeader cat="玩家文库 · 宠物养成" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

市场管理员:在帮派占领的地图上,双击使用市场管理员,就会出现一个NPC,放了市场管理员以后,该地图就可以宠物摆摊了,收费和税率可以通过点击该NPC修改...收的钱直接进入帮派基金中...(帮派的长老以上的人物可以将一些不遵守规则的摊子踢走)

帮派训兽师:在帮派总坛里双击使用帮派训兽师,会出现一个NPC,这就是帮派训兽师了...放完以后,右键点击训兽师,就可以往里面存放宠物了,存放的宠物同时也是帮派的守护兽,当别人闯入帮派的时候,就会先跟这些守护兽战斗,打赢了才能进入...(宠物在保护帮派跟别人战斗时牺牲对宠物没有任何影响,这里每个人都可以将宠物存放进去,不过不是每个人都能取出来哦,只有长老以上才可以取.)

**帮派护士MM**：在帮派总坛里双击使用帮派护士,就可以放下一个NPC,点击该NPC就可以加血了,加一点血需要一两银子哦(包括人物和出征宠物的)...收入直接放到帮派基金里...
