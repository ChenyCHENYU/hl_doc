# 帮派购买总坛

<TopicHeader cat="玩家文库 · 综合其他" src="幻灵玩家宝典.exe" />

> 来源：《幻灵玩家宝典 V1.0》玩家自制电子书（天下网游论坛精华合集），文字整理保留原意。

通过皇城太和殿内的吴大人(20,20)可以参观帮派总坛的样品房....

每个样品房的入口那都有一个售房NPC,与他们对话后可以购买所在地图的总坛,也可以选择参观下一种帮派总坛.....

花3000W就可以购买总坛(扣出帮派基金),购买后得到"帮派龙虎令",再找售房NPC就可以领取到相应的房产证....  
带着房产证选择一张地图作为自己的帮派总坛所在地之后,只需使用该房产证,放置好NPC就大功告成了!

注意事项：  
当成功占领一块地图后,帮派龙虎令会被收走...如果没有成功占领地图或者将房产证不慎遗失时,只要帮派龙虎令还在,就可以重新向售房NPC领取房产证....如果帮派龙虎令丢失,那...就白白损失3000万了.....

可以占领的地盘的列表如下

浮影水城外郊、青风原、坠泪岗、四桥原、闲情园、松竹林、怨灵洞口、剑池谷、石壁洞口、西码头、枯井原、断魂涯、观日桥头、东码头、断壁、银罐谷、绿洲东郊、金轮谷、落雁谷、羁马谷、华山顶、情人谷、梦佛窟、赏月谷、羁马谷、酒鬼冢、流沙原、净沙原、独孤亭、晚枫林、斑鸠小舍、回首亭、守望林场、暮归道、双印谷、镜雪原、松雪野、踏雪原、斧青谷、犁春原、黄泥岗、鸟鸣谷、羊肠道、独木原、春水桥、雪融谷、炊烟谷
