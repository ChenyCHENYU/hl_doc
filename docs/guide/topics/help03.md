# 保护锁面板

<TopicHeader cat="界面与操作 · 游戏帮助" src="help03.htm" />

> 原文：help03.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

为了进一步保护玩家的资料，在游戏密码之外，我们又设置了这个二次密码的保护措施。

虽然操作起来会有些小麻烦，有时需要打开保护锁，但是对保护你的利益却很有效。

<TermDefs :items="[{term:'加装保护锁',def:'此功能是在游戏密码保护之外的另一道保护措施。可称之为&quot;二次密码&quot;。主要用来保护游戏里对玩家影响很大的重要物品，比如你的宠物、武功、帮派、房屋等，在进行上述相关的操作时，需要输入保护锁的密码（注意不要和帐号密码一致！）。虽然说有点麻烦，但是对于在网吧上网游戏的玩家的却很有必要。点击此键会弹出输入面板，按照要求输入6位或6位以上数字来设定密码。确定后再次输入一遍即可。'},{term:'永久解除保护锁',def:'如果觉得保护锁很麻烦，没有设置的必要，可以点击此键，输入密码，即可永久解除保护锁。这里的永久解除是指在你再次设定保护锁之前，进行相关操作可以不必解锁了。而不是不可再设保护锁。另外，如果你输入的密码不正确，系统会自动断开与服务器的联接，让你退出游戏。'},{term:'打开保护锁',def:'点击此键可以弹出输入面板，输入你的保护锁密码确定后即可打开保护锁。在下线以前你进行和保护锁有关的操作时，就不会弹出面板要求你解锁了。'}]" />
