# 宠物商店面板

<TopicHeader cat="宠物专题 · 游戏帮助" src="help11.htm" />

> 原文：help11.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

进入宠物店，右键点击NPC后可以弹出宠物商店面板，上面有两项服务项目：卖掉宠物和宠物寄存。点选其中一项后点击确定，即可进行相关操作。

<TermDefs :items="[{term:'卖掉宠物',def:'如果你想赚点钱，可以抓野外的怪物来卖掉，当然也可以把自己养的宠物卖掉，不过很少人舍得这么做。'},{term:'宠物寄存',def:'游戏中，人物角色的身上只能携带5个宠物。当你去捕捉新宠物时，宠物栏的空格不够，你可以将宠物暂时先存放到宠物店中。'}]" />

与宠物店NPC对话，选择卖掉宠物选项，之后弹出你的宠物列表，你可从中选择想要贩卖给商店的宠物，然后点击卖掉按键，此时会弹出一个面板提示它可以卖的价格，如果满意就点击确定即可得到银子了。注意：出征宠物不能卖掉。

卖宠物的行为是单向的，即你只能将身上的宠物卖给商店，不能向商店购买宠物。

宠物店收购宠物的价钱上限是一千万，如果你觉得卖给宠物店可惜，可以和其他玩家公平交易。

宠物的价值由宠物的生长率、忠诚度以及宠物等级决定，这三项属性越高宠物的价值越高。明白这点，我们可以解释为什么自己养的宠物会比野生宠物值钱，原因是野生宠物的生长率和忠诚度很低。

与宠物店NPC对话，选择宠物寄存选项，之后弹出一个宠物寄存面板，你可从中左边"你身边的宠物"一栏里选择想寄存在商店的宠物，此时中间"宠物资料"栏就会显示它的图片、相关属性以及寄存费，然后点击寄存按键，就可以在右边的"寄存处的宠物"一栏里看到它，表示寄存成功。不同城市的宠物店寄存的宠物不同，目前幻灵的四大城市宠物店可以寄存三十二只宠物。

宠物的寄存费根据宠物的等级来定，与寄存天数无关。
