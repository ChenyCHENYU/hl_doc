# 宠物图鉴

<TopicHeader cat="宠物专题 · 游戏帮助" src="help12.htm" />

> 原文：help12.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

幻灵世界里有很多可爱的宠物，按照五行原理可以把它们分为金、木、水、火、土五种类型。

对于喜欢宠物的玩家，宠物图鉴就像一个还没有书写的百科全书。如果你把它们带着升过10级登录上去，就可以获得这种宠物的基本资料。

**宠物图鉴的用处**：1、如果某种宠物已经登录图鉴，那么在野外抓该种宠物的时候就很容易了。

点击宠物属性面板的宠物图鉴按钮可以打开宠物图鉴面板。

在该面板上，已经登录的宠物可以在名字前看到一个勾号，点击它就可以在右侧看到该类宠物的图片、资料和介绍。没有登录的宠物则看不到以上内容。

图鉴完成率就是已经登录的宠物占所有宠物类别的比例。可分为本系图鉴和总图鉴两种完成率。

2、在四转飞升的时候，对各个属性的图鉴完成率都有一定的要求。选择哪一种属性的图鉴飞升，就奖励得到该对应属性的终极宠物一只。
图鉴是记录所有类别宠物的，如果遇到图鉴不能识别的宠物，那恭喜你了，你获得的就是幻灵世界里面很稀少的变异品种哦。
