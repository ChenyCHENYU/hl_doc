# 宠物的装备面板

<TopicHeader cat="宠物专题 · 游戏帮助" src="help14.htm" />

> 原文：help14.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

宠物和人一样，也可以按照等级来装备各类饰物来加强自身的属性。这类饰物可以在饰玩店里买到，极品饰物可以通过乾坤五行炉的锻造炼化来得到。

点击"宠物属性"里的某只宠物，再点击"装备"，就会弹出这个宠物装备面板。

和人物的装备面板有些类似，面板左侧部分是物品的显示框和相关属性数值，右侧面板则显示你身上的饰物，左键点击一下某饰物，在左侧就可以看到它的图像和属性了。

再点击"确定"就可以给你的宠物装备上了。你会在"宠物面板"的宠物图像的左上角看到这个饰物。在下面的属性值一栏也有相关的属性值增加显示，如＋16。

如果想给宠物卸下饰物，点选该宠后，再点击"卸下"就可以了。
