# 创建游戏角色

<TermDefs :items="[{term:'如何获得游戏帐号',def:'双击《幻灵游侠》的太极图标，即执行文件\'PLAY\'，之后游戏会自动连接到游戏服务器，弹出游戏登入界面。如果此时你还没有申请游戏帐号，请先在幻灵的官方网站申请一个帐号：点击游戏登入界面中的\'注册新帐号\'，就会连接到帐号注册网址的页面上，按照注册页面上的要求填写相关资料，即可获得游戏帐号。'},{term:'如何给帐号充值',def:'在游戏登入界面的下方，你可以清楚的看见&quot;点击进入游戏卡充值系统&quot;的按钮，点击进入，在弹出的充值页面里将你购买的充值卡\'卡号\'及\'卡号密码\'输入，一定注意字母的大小写和数字0与字母O的区别，申请通过即完成充值操作。接着你就可以进入游戏了。'},{term:'如何创建人物',def:'如果你的帐号第一次进入游戏，点击\'进入游戏\'按钮时会跳出新角色选择界面，在这里有男女各6个人物供大家选择。在2。0的版本将有男女各8个造型。选完人物造型请给你的角色命名并起个绰号，人物的姓名在游戏中无法改变，将终身跟随你的角色，绰号可以随时改动。'}]" />

此后，点击'高级'按钮，进入角色基本属性的设置界面，在这里你可以将游戏给予的20点基本属性点分配给各个属性。如果你跳过属性分配这一步直接进入游戏，则系统将自动设置的你的体力、内功、攻击、防御和敏捷五个基本属性。建议新玩家采用后一种方案。

详情请参看创建游戏角色面板的操作说明。
