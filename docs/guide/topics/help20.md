# 动作

<TopicHeader cat="界面与操作 · 游戏帮助" src="help20.htm" />

> 原文：help20.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

该菜单下有9个不同的动作命令，点击其中的一个动作命令，游戏人物就可以作出相对应的动作来：

坐下(R) F1

招手(S) F2

高兴(T) F3

生气(U) F4

悲伤(V) F5

晕倒(W) F6

半跪(X) F7

投掷(Y) F8

作揖(Z) F9

以西门人物为例

括号（）里的字母是该动作的快捷键。按下ALT＋A会弹出本动作菜单，在键盘上点击R人物就会收到你的命令而坐下，点S就会作出招手的动作……同样，动作后面的F1、F2、F3等，也是相应的动作快捷键，F1就是坐下，F2 就是招手……。

在某些情况下，比如回合制战斗中、使用障眼法、三转后仙魔的驾云飞行等，动作命令的使用会受到一定的限制。

而当人物在正常的状态下（进入游戏时的初始状态），你可以通过快速切换不同的快捷键来做更加复杂、更加滑稽的组合动作，也就是模拟舞蹈了。

如果你的朋友够多，提前约定好，一起按照统一的循序来做动作，那就可以做幻灵世界的第一套广播体操了。
