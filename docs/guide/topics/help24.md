# 队伍

> 原文：help24.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

在打怪练级的过程中， 一个人独自进行毕竟是很危险的，这个时候团队作战就显得很有必要了。

保护好好自己的阵型、阵眼，争取先击破对方阵中的阵眼从而取消对方的阵型作用，是取得胜利的关键。因此必须熟悉每种怪物阵型中不同阵眼的位置。
