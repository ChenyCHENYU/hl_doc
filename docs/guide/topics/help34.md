# 劫富济贫

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help34.htm" />

> 原文：help34.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

所谓的劫富济贫其实就是偷窃。这是一种另类的玩法，虽然许多忠厚玩家对此深恶痛绝，但还是有不少玩家铤而走险，每次都冒着被打得鼻青脸肿，甚至被被抓进监牢的凶险，一而再，再而三地进行，这种惊险、刺激绝对不同于枯燥的练级、打怪的。
