# 快捷键

<TopicHeader cat="界面与操作 · 游戏帮助" src="help35.htm" />

> 原文：help35.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

为了方便玩家更加流畅地游戏，许多功能键特意设置了专门的快捷键。

在某些功能键后面的括号里带有字母的，就说明该项功能设置了快捷键。

**常用快捷键**：F1-F9 9种人物动作F10 聊天记录F11 人名开关F12 截图Ctrl+X 战斗Ctrl+A PKCtrl+I 装备Ctrl+F1 世界地图除了熟练运用快捷键，还有一些小技巧也需要熟练掌握、运用。比如小地图、聊天面板和其他功能面板，在鼠标点住面板上方部分的时候可以拖动到你想要的位置。

游戏界面上方的7个功能键的快捷方式在括号里省略了ALT，比如：交互（G），快捷键就是ALT＋G。

其他功能键则只需点击所标明的键盘按键即可。

在药店买药的时候来回扭动手腕点击30次才可以买完15个药品，其实只需把弹出的购买面板拖到游戏界面上方的合适位置，就可不必移动鼠标连续点击购买和确定，快速买完15个药品。

其他的便捷方法只要你跟游戏里的朋友多多交流，肯定受益匪浅。
