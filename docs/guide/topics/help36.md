# 聊天面板

<TopicHeader cat="界面与操作 · 游戏帮助" src="help36.htm" />

> 原文：help36.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

点击此键即会弹出聊天面板。该面板可以拖动到你习惯的的屏幕某位置使用。

## 该面板有以下功能

**私聊窗口**：点击屏幕最右边的私聊按钮，就可以弹出私聊面板。私聊面板中记录了所有和你聊过天的玩家，你可以对他们进行管理，查询也比较方便。

在你需要跟同屏的某人聊天时，可以右键点击该人，聊天对象就会变成他的名字了。如果你看不到他，也可以在【周围游侠】里找到他的名字，点击一下即可换成聊天对象。

如果某人和你不在同一屏幕，你可以在对象框里键入他的名字或者从聊天资料里复制他的名字。

此面板上有"和我有关的消息"、"系统公告"、"聊天消息"、"完整系统消息"四个不同的消息分类，点击则可以弹出相应的资料信息。

点"自动保存"打勾，可以把上述资料信息都自动保存在游戏目录chat里面。再点即可取消此功能。

传音则需要消耗内力，最少需要200内力。如果超过200，则一次全部消耗完，整个服务器所有地图里的人都可以看到你发布的信息。

私聊、队伍、帮派、夫妻则只有相对应的对象才可以看到你发布的信息。他人无法看到。
