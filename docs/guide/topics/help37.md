# 领奖面板

<TopicHeader cat="界面与操作 · 游戏帮助" src="help37.htm" />

> 原文：help37.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

为了给广大的玩家一个意外的惊喜，幻灵游侠特意根据玩家购买的游戏卡号设置了系列奖品：

<TermDefs :items="[{term:'年卡',def:'500万幻币+1级阿弟达斯（赤龙、幻云兽、火妖精、至尊宝或者红发妖姬，只可选择一种宠物）'},{term:'季卡',def:'小精卫(大头蜂鸟)+升级药100万幻灵币+升级药200万幻币+1级丸子鱼100万幻币+1级小叮当(绿花栗鼠)100万幻币+1级丸子鱼(绿娃娃鱼)150万幻币 +大头蜂鸟300万幻币（以上七种奖项只可选择其一）'},{term:'月卡',def:'根据卡号进行抽奖。奖项为上述13种奖品之一。看看你的运气好不好吧。：）'}]" />

玩家买卡（实物卡、虚拟卡都可）充值之后，进入游戏，如果系统提示你中奖了。那么恭喜你，赶快按照提示到官方领奖页面网页上兑奖，选择好服务器，然后进入游戏，点击"系统"里的领奖，在弹出的面板上填写卡号与卡密码，点击确定就可领奖啦。
