# 其他附属按键

<TopicHeader cat="界面与操作 · 游戏帮助" src="help38.htm" />

> 原文：help38.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

在屏幕上还有一些零散分布的按键，熟练的运用它们对熟悉游戏很有帮助。

此面板上有"和我有关的消息"、"系统公告"、"聊天消息"、"完整系统消息"四个不同的消息分类，点击则可以弹出相应的资料信息。

点"自动保存"打勾，可以把上述资料信息都自动保存在游戏目录chat里面。再点即可取消此功能。
