# 乾坤五行炉

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help39.htm" />

> 原文：help39.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

道家学说认为，世间万物皆由金、木、水、火、土五元素组成，也各自具备独立而又互相联系的五行属性。乾坤五行炉就是根据这个原理，把任意两件或者几件物品在炉内用五味真火进行炼化，就可以得到新的物品出来。

**具体操作如下**：点击此键可弹出乾坤五行炉的炼化面板。左侧是宠物栏和物品栏，左键点击某物，在中间的资料栏可以看到该物品的图像及属性。下方是银两，两边的"＋"、"－"可以用来调整你投入炉内的银两，每次以1000两为基本单位。这三部分东西都是可以用来炼化的。中间部分是选定物品的资料，可以显示炼化前、后物品的属性。

面板右侧是乾坤五行炉，上面有8个位置可以放置物品，从左侧的宠物栏和物品栏点击某物，可以拖到其中任意一个位置上。
按照上述步骤，放置2个或者多个炼化的物品后，用右键点击一个物品，指定它为主炼成份，然后可以点击下面的"预览"，可以在中间部分弹出一个物体栏，显示出炼化得到的物品及其属性。

如果满意，就可以关闭这个物体栏，点击"炼化"后点击确定，此时系统会要求你输入密码，以确认你准备炼化，系统确认密码无误，太极鱼即开始转动，炉内的物品会被炼化，在物品栏里你就可以看到你想得到的物品了。

如果对预览的结果不满意，你可以试着调整一下各炼化物品的位置，再看看预览，说不定会有意外的效果。

详细的炼化方法请参看锻造炼化攻略。
