# 人物角色类型的塑造

<TopicHeader cat="新手入门 · 游戏帮助" src="help41.htm" />

> 原文：help41.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

在幻灵世界里，大家一出生都是平等的，没有阶级之分，没有贵贱之别。

随着各自的修炼，不同性格的玩家就会按照自己的意愿塑造出不同的角色类型。
