# 商店NPC的买卖面板

<TopicHeader cat="界面与操作 · 游戏帮助" src="help44.htm" />

> 原文：help44.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

游戏中有许多可以与玩家进行买卖交易的NPC，例如：药店、武器店、饰物店等商店老板，只要与之对话（记得是鼠标右键点击）就会弹出"幻灵商店"的买卖界面。

买卖面板分成左、中、右三部分。左边部分为"物品列表"，就是该商店NPC可以卖给你的物品。中间部分为"物品显示"，可以看到你选择的某物品的图像及其相关属性值。右边部分为"个人装备栏"，一共15个位置，显示你身上携带的各类物品。

你可以左键点选左边的"物品列表"里某一物品（或者右边的"个人装备栏"），在中间部分就可以看到该物品的图象、相关属性值及其使用等级和价格了。

无物品选定时，中间部分的图片为黑片，下面的属性值都为0。

你可以将身上的物品贩卖给任何一个可以交易的NPC商人，例如将药物卖给装备商，将装备卖给药物商都是被允许的。不过需要注意：你只能以此物品购买时一半的价格变卖给NPC，远不如拿到宠物集市上卖给玩家赚钱。
