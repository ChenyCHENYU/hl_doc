# 五行生克关系

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help45.htm" />

> 原文：help45.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

首先让我们简单了解五行的生、克关系。五行学说也是古人确定的一种物质构成关系，他们认为世界万物都是由金、木、水、火、土五种元素构成的。人们将每种事物的五项内容都分别显示成木、火、土、金、水的五行顺序。五行有生成、相生、相克的顺序。生成的顺序是木、火、土、金、水。相生的顺序是木生火、火生土、土生金、金生水、水生木。相克的顺序是：水克火、火克金、金克木、木克土、土克水。

装备、宠物自身的属性和幻灵世界的各地区里也按照五行原理设置了金、木、水、火、土五种属性，在捉宠和战斗的时候要注意彼此间的相生相克关系，就会得到事半功倍的效果。

另外，宠物的幻化、五行八卦炉的炼化都和五行原理有密切的关系，详情可参看各自的说明。
