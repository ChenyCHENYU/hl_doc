# 修练武功

武功常见问题

武功是什么？

**7、技能经验**：即在打怪物时武功使用的次数，"/"前面的数值是使用次数，后面的数值是升到下一层武功需要的次数。什么样是好武功招数？

武功就是用自己的的内力攻击对方的方式。

武功和普通攻击有什么区别？

在战斗中使用普通攻击，计算伤害值时，要考虑对方的防御力。

用武功攻击敌人时，不考虑对方的防御力。如果对方是宠物或者没有内力，那么对武功就没有防御力。如果对方有内力，内力的一部分会自动用来削减进攻的招数，抵抗不了的，就造成伤血了。内力进攻和防御用的内力都从双方身上损耗了。

武功有什么属性？

好的武功招数首先是要整体攻击效果好，同时消耗的内力小。攻击效果除以消耗内力，定义为攻击系数， 攻击系数一般在1.0到2.0之间。 攻击系数越大越好。

另外越容易施展的武功当然也越好。

武功如何升级？

学习了或者自创了武功，可以通过不断地修炼这些招数，使得招数的熟练程度不断提高。武功的修炼和升级主要是在打怪物中进行，平时PK其它玩家，武功经验不会得到提高。

学会的技能怎样应用到战斗中？

面板下方有两个左、右方向的箭头，新学会的武功技能，可以点击向右的箭头移动到"战斗中使用的技能"一栏。这样在PK战斗时就可以使用了。

同理，向左的箭头可以把"战斗中使用的技能"里的一项移动到左侧栏里，也就是说战斗中不可以使用此项技能了。

武功怎样遗忘？

每个人不可以无限制的学习武功，毕竟精力有限。超过5项武功后，就不可以再学或者再创新的武功了。

我们可以把已经学会的、不好的武功忘却掉，就可以学习新的武功了。具体操作是：先在左侧的"已学会的技能"里点选一项武功，再点击"忘掉"即可。
