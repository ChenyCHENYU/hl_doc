# 自创武功

<TopicHeader cat="战斗相关" src="help47.htm" />

武功自创面板

创招的条件

**简单的攻击效果就是**：攻击效果＝攻击系数 × 所用内力成功率的计算界面上有成功率的估测，是个比较准确的数值。

等级在300以上，飞升的散仙等级100级以上，内力属性100点以上。

如何调整招数

主要是取一个响亮的名字，调整想使用的内力、攻击系数，再选择想要的图像效果即可。具体的数值，请参照武功修练说明，按照个人爱好调整。

可以使用的内力上限

可以使用的内力上限是你的内力属性点。比如您现在在内力属性上分配的点数是180点，那么您想创造的武功招数可以使用的内力就不可以超过180。

可以选择的攻击系数

可以选择的攻击系数主要和你的攻击点数有关系，具体的算法：

攻击系数上限＝[150 +(攻击点数-600)*5/140]/100 
 （有点晕， 不要紧，反正界面上有自动的控制）

攻击效果的计算

真正的成功率计算比较复杂，主要是：

招数设置的攻击系数越低， 成功率越高；

创招经验越丰富，成功率也越高。

攻击效果超过1000的招数

招数攻击效果超过1000的，属于高级招数，无论是否成功，都要损失1级的等级和相应的内力属性点。招数的最高攻击效果是2000，如果你设定的招数的攻击效果超过2000，会提示您错误。

施展系数和使用等级

使用等级是系统自动计算的，主要是针对将武功传授弟子时，对弟子最低等级的限制。

施展系数是创招成功后另外计算的。
