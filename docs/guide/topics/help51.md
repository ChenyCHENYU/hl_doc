# 养宠攻略

<TopicHeader cat="宠物专题 · 游戏帮助" src="help51.htm" />

> 原文：help51.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

宠物是游戏里的关键因素之一，能拥有一只极品宠物是所有玩家都梦寐以求的事情。

所谓的极品宠物，仁者见仁、智者见智，不顾总的来说拥有极高的生长率和血生长率，以及最佳的攻击、防御、敏捷三围分配比例应该是大家公认的条件。

宠物分为可进化宠物和不可进化宠物。一般来说，不可进化宠物的生长率的平均水平在3、8～4、5之间，较好的可以达到5以上，而极品则为6以上。如果通过幻化还能提高成长率。

可进化的宠物可以连续进化两次，这期间生长率可以累计，养的越好，最后进化得到的宠物生长率越好。再结合打造极品宠物的宠物幻化攻略里的高级攻略，就可以练出一只极品宠物了。

现在我们来看看那些因素可以增加你的爱宠生长。

第一、满血升级。

这是养宠最关键的一步。所谓的满血升级，就是在宠物即将升级前，一定要保证它的血值是满的。一般我们把90％以上的血值都可认定为满血。

宠物满血升级可以在生长率上得到相关的奖励。

第二、跟随奖励。

就是你要带着它和你一起战斗、打怪，一起升级。

第三、忠诚奖励。

宠物的忠诚只显示100以内，超过100忠诚的宠物，人物角色每升5级，或者宠物每升5级仍然可以增加一个忠诚度，只是100忠诚以后的部分会变成隐藏属性而起作用。

第四、进化奖励。

你的宠物进化的时候，等级越高，得到的奖励也越高。

与以上四项相反，比如宠物不满血升级，甚至被打晕，在多人之间转手交易，进化的等级偏低，等等，都可以减弱宠物的生长趋势。

这一点对于玩家养宠物很重要，如果你的宠物是水属性的，那么去打火属性的怪物就是最佳的选择（水克火）。而打土属性的怪物则是最危险的（土克水），其他属性的利害关系不大。

一般我们在得到一只一级的宠物时，可以把它满血升级到11级，用上面的计算方法算出一个大概的生长率。但是这只是一个大概，以后的短时间内，它可能会继续提升，也可能会有所降低。但是不会波动很大。这是因为宠物的生长率在100级别以前时，宠物的属性点数由于各种因素多一点和少一点，这都会对你的计算结果影响很大。因此不要因为生长率偶尔的降低而丧失信心，坚持下去，它不会让你失望的。到了200－300级的时候算出的宠物的生长率才最接近它的实际生长率。
