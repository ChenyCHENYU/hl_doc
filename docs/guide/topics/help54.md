# 阵型面板

<TopicHeader cat="界面与操作 · 游戏帮助" src="help54.htm" />

> 原文：help54.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

在组队战斗情况下，可以选择合适的阵型进行战斗。

不同的阵型对于各队伍成员的攻击、防御、敏捷都会有不同的附加效果，战斗中可灵活运用。

<TermDefs :items="[{term:'普通（无）',def:'系统默认的阵型，无附加效果。'},{term:'虎翼（火）',def:'可加强攻击属性。被龙游阵克。被鸟栖阵生。'},{term:'金麟（金）',def:'可加强攻击属性，减弱防御属性。被虎翼阵克。被龟背阵生。'},{term:'鸟栖（木）',def:'可加强敏捷属性。被龙游阵生，被金麟阵克。'},{term:'龟背（土）',def:'可加强防御属性。被虎翼阵生，被鸟栖阵克。'},{term:'龙游（水）',def:'可加强攻击和敏捷。被龟背阵克，被金麟阵生。'}]" />

阵型之间的关系按照五行相生相克原理有：正常、被克、被生、无效四种。被生的阵型，其附加的属性效果会额外加强。同理，被克的阵型，其附加的属性效果会被额外的减弱。

队伍中成员越多，阵型的附加效果越高。

另外，阵型中还有阵眼这一关键性的设置。战斗中，当阵眼被击倒后，阵型自动解散，这对于怪物也是一样的，所以玩家必须先击倒对方的阵眼，这样以后的战斗就轻松多了，不过还是需要考虑五行相克的道理，有时候击倒阵眼反而会有不利效果！
