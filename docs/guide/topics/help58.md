# 服务器组

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help58.htm" />

> 原文：help58.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

游戏服务器是存放玩家资料的地方，目前幻灵共架设了梦幻国度、风之谷、上海电信、17173.com、联通游戏网、广州火狐、重庆力帆、网联、秦皇岛、北京网宿、四川诺亚11组服务器，日后也可能会根据需要增设新服。

服务器组由一台到几台服务器构成，同一组服务器之间玩家资料是共通的，不同服务器组的资料却不是。也就是说玩家在只在梦幻国度的服务器组建立了人物并且升级到了100级，到网联服务器组还是没有人物的。而且如果你在梦幻叫玩家甲，在网联没有建立人物，别的玩家还是可以建立人物叫玩家甲的。

因此，如果不想让别人因此和你起相同的名字，而引发一系列的误会，那就赶快到其他服务器抢注你的人物吧。
