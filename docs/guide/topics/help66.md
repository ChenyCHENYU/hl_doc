# 宠物相生相克

<TopicHeader cat="宠物专题 · 游戏帮助" src="help66.htm" />

> 原文：help66.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

每种宠物都有五行属性，同样遵守五行相生相克的规则，加之宠物特有的天敌相克，构成完整的宠物克制系统。

**下面就宠物相克详细说明**：1、五行属性相克。相克的顺序是：水系克火系、火系克金系、金系克木系、木系克土系、土系克水系。相克的两类宠物如果在战斗中相遇，五行相克优势的一方攻击防御都会有大幅的提升，在战斗中会占尽便宜。因此，如果养宠物的时候，合理的利用相克，可以让你的宠物在实力较弱的时候挑战被克的原本实力很强的怪物，从而达到快速升级的目地。

2、天敌相克。只有可进化宠物的最终形态和超级宠物才有天敌，天敌的种类就是克制它的其他系的所有不可进化宠物。比如地藏是水系的，那么所有土系的不可进化宠物像大刀、阿达等等都是地藏的天敌。天敌的威力更强与相克，如果在战斗中遇到天敌一定要小心，如果实力相当，被克一方几乎没有胜算。
