# 宠物的勋章

<TopicHeader cat="宠物专题 · 游戏帮助" src="help68.htm" />

> 原文：help68.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

宠物的勋章是宠物能力的体现，不同的勋章将对宠物不同方面的能力都有提升。其中：

<TermDefs :items="[{term:'勇猛勋章',def:'每获得一个勇猛勋章，宠物在回合战斗中的攻击力会有5%的提高。'},{term:'冷静勋章',def:'每获得一个冷静勋章，宠物在回合战斗中的防御力会有5%的提高。'},{term:'果敢勋章',def:'每获得一个果敢勋章，宠物在回合战斗中的敏捷度会有5%的提高。'}]" />

目前宠物可以获得勋章的途径有五个：

一、进化时给予的奖励勋章；宠物进化时会获得勋章，进化时宠物的等级越高，得到勋章的机会就越多。进化时获得勋章是随机的，不是给你剩余的勋章，比如你的宠物已经有4个勇猛勋章，5个果敢勋章，5个冷静勋章，1200级进化不一定就是给勇猛勋章，如果给2个果敢，一个冷静，那最终的结果就是你的宠物勋章没有变化，这点大家要注意了。

二、完成任务获得的奖励勋章；随着以后任务的增加，会有这样的机会。

三、战斗中因发生特殊攻防效果，而产生的勋章；不过只有发生超级攻防敏，并且在你的宠物比怪物等级低的情况下才有可能获得勋章。而且组队比单人获得勋章的几率要大的多。

四、宠物幻化后继承的勋章；宠物幻化后可以继承上一代宠物各个级别勋章总数的一半。

五、斗宠时因会获得重大胜利而得到的宠物勋章。
