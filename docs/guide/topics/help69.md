# 武功传授

杀伤力1000以上的高级武功传授时，传授者练习的层次越高，武功损失的效果越小。在5层时传授损失近一半，到第9层就损失为0了。

武功传授者在传授之后，自身的武功经验值也会损失一部分。传给一般关系的玩家损失最大（500封顶），传授给帮众损失次之（100封顶），传授给夫妻损失最少，仅为1％（100封顶）。

新学者的武功经验值从0开始入门，只能发挥原招数的一大半的效果。练到8层才可100％完全发挥出来。

学来的武功练习到8层之后才可以传授给别人，但是武功的杀伤效果会有一小部分损失，10层以后可以完全无损地传授给别人。

武功原创者在遗忘该武功后，可以从其他玩家那里学会来。经验值会继承传授人的绝大部分，武功效果并不受损失。

学徒学习武功后再攻击师父（原创者），只有攻击的画面，但无杀伤效果。
