# 黑名单设置面板

<TopicHeader cat="界面与操作 · 游戏帮助" src="help71.htm" />

> 原文：help71.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

点击此键可以弹出黑名单和脏话管理面板。在游戏里，如果你不想收到某人的传音、动作的骚扰，或者把游戏里一些刺耳的脏话过滤掉，你就可以使用该项功能。

点击黑名单，然后点下方的"添加"键，在弹出的面板上输入你想过滤的某玩家的名字，再点击确定即可过滤掉所有该玩家的消息。点击删除可以把该玩家从黑名单里清除，点击"保存"则是把你的黑名单设置保存在系统里。

同理，点击"脏话过滤"键，按照上述的循序输入你不想听到脏话，点击确定后即可将之过滤掉。
