> 原文：help72.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

幻灵世界是一个神奇的、充满了梦幻色彩的世界。人、宠物、怪物是这个世界的主角。

其中宠物是帮助人来和怪物作战的，就是在战斗中站在你前面和你并肩战斗的。它是人类的朋友。因此，你一进入游戏，系统就会给你一只宠物，这只宠物又称出生宠，一般成长率稍微好一些。你一定要像兄弟一样爱护它，只有把它养的强壮了，它在以后的打怪、升级过程中才会更加勇猛。

宠物分为不可进化宠和可进化宠两类。每种宠物都具有不同的五行属性，并按照五行的生克关系而相生相克。其中可进化宠又分成若干类，每类的宠物都可进化两次，有些甚至可以和主人进行第三次进化。要是和幻化结合，更是能制造出超级梦宠。

不可以进化宠也有几十余种，虽然不能够进化，但却也个个有不俗的特点，有一些更是"超级梦宠"的天敌（战斗时攻击力会成倍增加），决不可小视。

怪物是躲藏在野外的怪兽，人类只有不断地打败更高级的怪物才能不断升级、修炼。人类可以把怪物抓过来，养成自己的宠物，帮助自己作战。也可以抓怪物来卖钱，等级越高的怪物，卖的钱越多。
