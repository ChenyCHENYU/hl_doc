# 人的特点

人物角色有五个属性，分别对应角色五种状态：

<TermDefs :items="[{term:'体力－生命',def:'决定你在战斗中所能损失的最大血值。血值为零人就会被打晕在地。'},{term:'内功－内力',def:'点穴、传音、武功自创都需一定的内力才可以。'},{term:'攻击－攻击力',def:'决定你攻击时的杀伤程度。'},{term:'防御－防御力',def:'决定你在战斗时的防御程度。'},{term:'敏捷－敏捷度',def:'决定你在战斗中的反应速度。'},{term:'血人',def:'就是血值很高的人，把点数大都加在体力上，这类人在游戏里似乎很少见，因为不实用，是典型的PK靶子。'}]" />

<TermDefs :items="[{term:'内人',def:'也可叫大内高手，就是内力值很高的角色，这类人擅长点穴和自创武功。'},{term:'攻人',def:'攻击力很高，杀伤力极强，暗器专家，PK高手必练。'},{term:'敏人',def:'就是敏捷特别高，善于躲避对方的攻击，可以轻易的击中目标。当然，除非很极端的玩家会把点数绝大部分都加到某属性上，一般玩家都要综合考虑，把点数尽量合理化分配的。除了分配升级的点数，角色还可以买来装备、饰物等来加强某方面的属性值。'}]" />

人物通过打怪物，每次升级以后，就会有点数奖励（不同级别的奖励不同，凡人散仙3点，地仙以上的4点），你可以根据你的习惯，以及上述五属性的特点来分配点数。不同的点数分配练就不同的角色：

但是这都要有一定的等级才可以使用。装备可到铁匠那里买，身饰到饰玩店里买。一般来说，衣服是加防御的，武器加攻击，鞋子加敏捷，身饰则五种属性都可以加。
