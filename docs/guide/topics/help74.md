# 宠物的特点

<TopicHeader cat="宠物专题 · 游戏帮助" src="help74.htm" />

> 原文：help74.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

宠物的属性包括攻击、防御、敏捷和生命。前三者一般简称为"三围"，大家常说某宠的三围好，意思就是说它的攻防敏分配比例好。

宠物最重要的一点就是看它的生长率，就是宠物每次升级奖励的点数，点数越多，它的生长率就越高。一般精确的生长率计算，要在培养相当一段时间后（100级），才可以计算出来。

一般我们说的宠物生长怎样，就是问对方宠物的三围生长率。不同的宠物，攻防敏三围的生长率是不同的，也就是三者的分配比例不同。有的宠物防御比较好，有的敏捷高，有的攻击高，这些都需要以后通过宠物的进化、幻化、炼化等方法来改良。

宠物还有一个重要的属性，就是忠诚度。宠物养的不好，低于55的忠诚度，宠物就会背离你逃走。而在刚进入游戏的时候，系统送给你的那只宠物是100忠诚的。一般的，人物每升5级或者宠物每升5级，它的忠诚度都会加一。在超过100以后的忠诚度就不在显示，作为隐藏属性起作用。宠物忠诚度100之后，人物就可以利用障眼法变做它的样子，到处游玩。

宠物也可通过装备合适等级的身饰来加强攻防敏或者生命的属性。如果在战斗中发挥出色，战胜怪物，你的宠物也有可能获得勋章奖励，一个勋章可以提高宠物某属性5％的能力。

详情可参考养宠攻略。
