# 世界地理分布

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help75.htm" />

> 原文：help75.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

幻灵世界是一个美丽的梦幻之乡。按照道家的五行学说，她由五个不同属性的片区组成：中原山水（土）、北国风光（水）、西域大漠（火）、椰风海岸（木）和天空之城(金)。不同的片区分布着不同的怪物，适合不同的玩家打怪、练级。而且地图的属性将在宠物的进化和幻化中起一定的影响作用。

在各个片区和城市之间，设有驿站可以瞬间到达。除了地面和空中建筑，地下还有神秘的洞窟、地狱、仙洞，里面埋藏着珍奇的宝物，等待探险家去探索。
