# 社会关系

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help76.htm" />

> 原文：help76.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

在幻灵世界里，社会关系和现实社会很相似。开始大家都是陌生人，你可以通过聊天、战斗结识许多朋友，比较谈的来的就可以义结金兰，成为兄弟了。游戏里有兄弟名单，方便联系。如果有你喜欢的异性，也可以花钱选择一种求婚方式（买玫瑰花、摆筵席等）来向对方求婚。对方同意后，你们就是幻灵世界里的小夫妻了。夫妻一起练级、打怪就不会枯燥了，而且可以百分百的合击怪物，真的很不错。

如果你的朋友、兄弟很多，你就可以建立帮派啦。大家凑份子买块地皮，建立一个帮派总坛，以后开会就有地方了。帮里兄弟有了困难，大家都会帮助。平常一起练级、练拳，感觉比起独自一人闯荡江湖要爽多了！

当然，你也会遇到恶人。比如小偷、骗子、下毒者、PK狂，须小心提防为是。
