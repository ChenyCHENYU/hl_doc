# 经济活动

<TopicHeader cat="玩法与世界 · 游戏帮助" src="help78.htm" />

> 原文：help78.htm（游戏内宝典，未在官方导航目录中），结构化整理保留原意。

在幻灵世界里，许多事情都要花钱。这里通用的货币是银两。

买药、买装备、买宠物、买房子、建帮派、结婚等都需要银子。这就涉及到怎么赚钱的问题。其实很简单，有很多方法可以致富：战斗打败怪物可以得到奖励银两；抓到宠物卖到宠物店去；作专门的赚钱任务；传授拳法；卖市场上急缺的任务物品（升级药、飞升药等）；帮忙过天劫；卖自己培养的极品宠物或者自己锻造的极品装备。

有些人专门用骗人的法子来骗钱，或者用游戏里的BUG来复制，这都是不好的行为。尤其后者，一旦被系统抓到，就是很严厉的删号等处罚。所以，勤劳致富，依法纳税，这种良好美德一定遵守。

有的东西你可以直接从游戏里的NPC那里买到，但是都是不二价哦，一般的比较贵。

想买便宜又实惠的东西，那就要到城里的宠物集市去看看了。玩家交纳摆摊费后，可以把一只宠物拿出来帮你看守摊位，把要卖的东西放在宠物身上，表明价格，你就可以忙别的去了。如果有人看中了你的货物，还可以通过摆摊的宠物和你讨价还价，直到双方满意。

如果买卖双方都在现场，也可以通过菜单里的交易来进行贸易。但是无论那种买卖方式，一定要看仔细，不少骗子就是利用各种小技巧来骗钱、骗宠的。
