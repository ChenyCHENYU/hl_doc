# 宠物图鉴

按五行、新山宠店或任务锻造查宠物，也可以搜索名称、类型、抓取出处和进化形态。

点卡片直接查看属性、进化链、抓取出处和重塑价格。弹窗内可切换上一只、下一只，关闭后保留筛选和浏览位置。
